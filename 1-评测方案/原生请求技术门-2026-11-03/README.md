# 原生请求技术门：前瞻约束与停止结果（2026-11-03）

> **交付日期2026-11-04，研究与事件日期保留2026-11-03。范围：有界研究先导，不是正式评测扩样。** Codex 首个真实先导被预先声明的仪器协议子集拒绝后停止，DSH 桥接槽未尝试、六个条件确认会话未启动；无有效产品配对。正式 A10+B10+W5、每产品每题 n=1、既有得分与裁定全部不变。整体研究条件仍 incomplete。

## 1. 问题与可解释边界

问题是：能否在不改写客户端原生业务 payload 的条件下，取得 Codex 与 DSH 的两请求、单 fixture、完整来源绑定的客户端输入观察，并在技术门通过后进行独立重复？原生协议和工具菜单不同，**即使技术门全部通过，也只是一项原生客户端输入观察，不是同 schema、同输出预算或同实际推理量的 Harness 因果对照**。

主候选指标为 `B_input = UTF8(canonical(selected_input))` 与前后增量，Codex 的 selected_input 包括 `input` 和 `tools`；还保留 wire body 大小、工具解码文本大小及双键端点。规范化只服务控制指纹，不能替代原字节指标。双键答对只验证指定端点，不证明工具全文无损；技术准入不以答对/机制方向决定。

## 3. 两层技术门及声明的支持子集

1. 每次转发前核对实际版本、来源 pin、序号/预算、模型/low、原生输出政策、工具 schema、Req1 模板、Req2 对本槽实际 Req1 的原样 prefix、唯一 call/return 的 ID 和真实 fixture 来源。严格 JSON 拒绝重键/NaN，类型比较不把 bool 当整数。
2. 整槽结束、继续任何下一槽前，核两份 raw/JSON、响应/元数据哈希、完成状态、工具进程来源、实际耗时、退出状态及上述控制。失败保留原件并停止，不事后放宽。
3. **本代 Responses 支持子集要求第二输入仅追加 `function_call` + `function_call_output` 两项**，并只支持声明的首响应形式；不声称覆盖全部原生 low 响应。额外 `reasoning` 等 item 若不在子集内应拒绝，而不是删去、压缩掉或静默忽略后继续转发。

此次工具门 53 项、会话控制 18 项、分账 37 项与解析复核 16 项均是工程校准/内部复核；不是 124 次模型请求，也不能证明未覆盖的真实原生响应都兼容。旧仪器 v2 源码与历史结果仍冻结；新代的前瞻守卫不倒推为旧代已有的保证。

## 4. 运输与隐私边界

请求实体 ≤131,072 B、响应实体 ≤524,288 B；全缓冲、串行、出站 identity 编码、不重试。上游总 deadline 最多60秒，另外存在本地收尾开销；取消不能证明服务端停止计算/计费。缓冲、头规范化及 SSE 重分帧会改变分块、时延、背压和取消传播，不能作为原生透明或延迟实验。未记录认证头；客户端字节不是服务端最终输入、tokens、cache 因果或成本。

公开材料是明确标注的派生件：私有路径、稳定安装标识（外层及内嵌JSON中的 `installation_id`，统一等UTF8长度I代称）与 opaque `encrypted_content` 等字段按派生映射遮盖，原件与派生字节哈希分开；等长替换/指标一致不等于原文件相同、完整原始轨迹、封印全通过或真人签名。字段映射与最终发布边界以[派生映射](<../../3-表现现场/r20261103-native-input-gated/projection-map.json>)和[公开清单](<../../3-表现现场/r20261103-native-input-gated/publication-manifest.json>)为准。

## 5. 实际停止分支

Codex 先导的首请求真实上游返回 HTTP200，fixture 被真实调用；客户端第二输入原样保留前四项并追加 `[reasoning,function_call,function_call_output]`，4→7 项。因不满足上述两项 suffix 子集，第二请求**转发前**拒绝，客户端409、上游尝试0；首请求上游尝试1，合计1。第二请求并未产生模型回答，不能作为完整两请求有效样本。

最终 `direct_observation_incomplete`：1 live 先导/1 上游尝试、1 DSH 桥接先导未尝试、六会话条件确认未启动、三个条件预留观察块均未启动（不是三次真实失败）、有效块0、0 新正式行。失败属于本仪器声明子集与实际原生输入不兼容，**不是 Codex 能力失败、模型失败或 DSH 胜出**。不放宽本批、不补槽；若未来另有协议修订，应保留本失败、另立前瞻合同和授权。
