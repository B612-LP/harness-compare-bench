# 预注册（PREREGISTRATION）必填模板 v1（L8-B，2026-10-30）

- **立制缘由**: L7-O1——预注册写 `ValueError`、实现实际 raise `GateError`，措辞级偏差
  被审计记 observation；L6 E1/E2——PREREG 未申报的异常路径与现场常量问题两次废封。
  预注册是 D 封印对象，措辞精度=验收锚点精度。
- **适用**: 每个自动循环的 `1-评测方案/自动循环L<N>-<日期>/PREREGISTRATION.md`。
- **纪律**: 本模板仅约束**结构完整性**，不预设选题；D 封印先于实现；模板自身修订
  须走预注册（本文件即 L8-B 交付，自 L8 起生效）。

## 必填字段清单（缺一即验收不通过）

1. **标识块**: `plan_id`（`l<N>-<yyyymmdd>`）；分支名（`loop<N>-<日期>`，注明自哪个
   main/集成点切出及切出 commit）；集成前置状态；D 封印声明（提交后立即执行、
   实现 commit 晚于 D）；验收配置（judge/auditor/reviewer 派谁、零模型环与否）。
2. **选题表**: 遗留池逐项处置（入本环/不入+理由）——不留未处置项。
3. **各主项设计**, 每项必含七要素:
   - **修前**: 现状与缺陷，指向具体文件/行/锚点；
   - **修后**: 目标行为，含 fail-closed 路径；
   - **异常类如实申报**（L8-B 新增条款）: 预注册所写异常类必须与实现实际 raise 的类
     **逐字一致**（如 `GateError`），报错文案含修订标记（如「L8-A」）；实现期 lead
     复核、验收期 judge 抽验；无法预知时写「实现期定，验收以实现为准」——**不得
     猜测类名**；
   - **正例**: 历史复算/复验口径与期望值（冻结基线不变声明）；
   - **近似错误例**: 负例路径逐条列出（缺参/坏参/坏格式/自引/环等）；
   - **影响面声明**: 触及的每个共享工具/现场；历史批零改动红线如何满足；
     documented known-impact 逐条点名；
   - **独立验收**: judge 复跑口径（含至少 1 个 PREREG 未列负例的自构要求）。
4. **纪律承诺**: D 先于实现；历史证据零字节改动；哈希/时刻脚本生成；write-once；
   CHANGELOG 不动；live 台账收尾登记+必跑 work-registry 不变量测试；收尾 PR 合并
   main；结论五段结构。
