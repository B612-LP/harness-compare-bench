# tb-cargo-plan：货运航班计划器排障（长程调试）

## 背景

一家货运航空公司的航班计划工具在最近一次升级后算错了：飞行员反映**燃油估算与手工计算对不上**、**重量检查放行了明显超限的载重**、**进近时的侧风限制被忽略**。工具本体在 `inputs/app/`，数据文件在 `inputs/app/data/`（数据是正确的，**不要修改**）。

## 任务

把计划器修好，并让它算出一份正确的飞行计划：

```bash
python3 inputs/app/dispatch.py --data-dir inputs/app/data --output flight_plan.json
```

要求：

1. 修 `inputs/app/` 下的 Python 代码（`dispatch.py` / `aircraft.py` / `navigation.py`，可新增辅助模块），使上面的命令能跑通并稳定产出 `flight_plan.json`；
2. 计划要覆盖**一次往返**：从 NAN 出发、每个目的地恰好访问一次、回到 NAN，不中途回枢纽；
3. 航路、距离、航向、地速、燃油、重量、侧风、时间、可行性结论都要与数据文件自洽（数据里给了机场坐标/跑道/风向、机型性能表、载货单、航段风与最低航路高度）；
4. 输出**确定性**：同样输入每次跑出同样的计划；
5. `flight_plan.json` 放在运行目录根下（也可以用 `--output` 指到别处，但请保证根目录有一份）。

## 提示

- 代码里既有「数据文件支持但代码没实现」的缺失功能，也有「算错符号/用错口径」的计算 bug，不止一处；
- 航段可能跨越 180 度经线；有的海岛机场**没有加油能力**，燃油规划要连着后续航段一起算；
- 可以自由读代码、读数据、写小脚本自测；**不联网**。

## 环境

- `python3`（3.9，仅标准库）；当前目录可读写。
- 不要修改 `inputs/app/data/` 下任何数据文件（判分会核对字节）。
- 完成后结束，不需要额外解释。
