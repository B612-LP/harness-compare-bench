# 自动化迭代循环（2026-10-29 启动）

用户授权（2026-10-29）：lead 协调 + 子代理分工，**全自动**运行——含真实评测批次（API 消耗）与结论产出；预注册照旧先提交后运行，但无需逐批批准。节奏：**每完成 1 个闭环停止**，交验收报告，用户放行后开下一轮。

**用户保留项（任何一轮不得自动触碰）**：周报只在用户明确叫写时才写；CHANGELOG 不改。

## 角色

- **lead**：选题（池子 = 未知登记/缺陷披露/老师验收要求）、预注册、git 提交/PR/合并、分账、门禁。

- **auditor**：对抗盲审 v2 全交付；只读 + 离线复算；独立于 builder/judge。
- **judge**：验收工具构建 + 对 r1030 自检 → 20 场独立验收 → 五段结论。
- **wb-probe**：WB 请求级补证探针（≤3 机制）。
- scout（只读侦察）：L2 起启用。

## 每轮固定动作

选题 → 预注册封印 → 执行 → 独立验收 → 归档+PR → 停止交报告。

## 不因全自动而豁免

预注册先于运行；无重试；判卷合同冻结；完全分账；五段结构；小 n 只描述不排名；凭据不入库；工作区在仓库外。详见同目录 [PREREGISTRATION.md](<PREREGISTRATION.md>)。
