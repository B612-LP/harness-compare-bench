# 历史封印与复核限制

本页是整理后的说明，不是历史预注册、执行封印、验证收据或其替代品；不能凭本页证明运行前后时序、原封印内容或历史验收通过。

为去除不应公开的内部执行材料，本仓库公开发布历史已重新建立。旧文中的 Git 提交号、分支名、原件路径及 SHA 仅是历史记录，不保证可从当前公开 Git 历史恢复；既有克隆、平台缓存或旧 PR 引用也不因本次整理自动消失。保留的旧锁与原收据没有为了当前通过而回填或重签，验证失败或无法取得原件的情况应如实解释。公开整理版源码与摘要不能冒充原运行时字节；需要原版本或完整环境的重跑不属于当前公开包可直接保证的能力。

不同批次的运行封印绑定了各自时点的程序、配置及文件路径。共享工具后来更新，或历史原件未公开时，使用当前工作树跨批次重跑可能因字节、路径、文件集合或绑定不一致而被拒绝。不得通过更换文件、放宽验证或把未执行说成成功来复现历史结论。

部分历史配置快照还包含用户级全局指令原件，因涉及私人环境与操作规则而不公开，仅保留其存在及影响边界的摘要。全局指令不等于纯评测提示，可能是未控制的背景变量；不能仅因省略了原文就假定无影响、宣称输入完全相同，或据此重新证明同模型 Harness 因果归因。分数和当时裁定不回写，历史绑定与原始指令内容无法仅凭公开摘要完整核验。

历史结果应区分当时的收据、原始现场与后续重新计算。能够独立取得的原始现场、用例和判卷依据可分别检查；需要未公开原件、历史环境或完整封印的项目应明确为无法公开核验，而非已验证或产品失败。有关旧批次的公开设计、结果和限制见[运行设计与证据索引](<运行设计与证据索引-2026-10-29-v1.md>)及[报告索引](<../5-评测报告/README.md>)。
