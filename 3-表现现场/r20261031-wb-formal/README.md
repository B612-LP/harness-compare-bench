## 证据边界

- 每场仅在产品产物冻结完成标记出现后处理，核对全部冻结文件 SHA-256。超时场同样保留，不选择性遗漏。
- 公开轨迹是明确删节的派生材料，**不是完整原始轨迹**：删除私人身份上下文、内部遥测，规范本机路径与账号标识；保留题面、模型标签、工具调用、工具结果和可审查行为。
- 每场派生清单列原件 SHA、派生 SHA、规则、限制及每一原始行至公开行的对应关系。原件私留；哈希不证明真实时间或内容真实性。
- 私人身份注入先逐项审阅是否含跨场答案/评测记忆，再发布不含私密内容的结构摘要、长度、哈希与审查结论。删除不能作为无污染依据。
- 原始任务书保留私有 SHA，公开规范路径版仅替换工作区前缀，题意不改。产物判分字节不美化；任何公开改写须另述其与实际判分字节的差别。

## 离线判卷与裁定

每场使用冻结 checker 的真实调用结果；题库只读。会执行产物代码的用例（Exercism、LCB、cargo）须先人工阅读产物、逐条审查工具调用，再在 OS 隔离中执行。隔离禁止网络、禁止改写题库及冻结工作区，只允许写入判卷独占临时目录；隔离机制有局限，不声称抵御任意主机级漏洞。

产品运行、自测、离线复算、判卷回归、裸模型探针、接口预检分账。每场场级记录使用 schema v2 并执行 strict-evidence 格式校验；格式校验不是独立真实性裁定。全五场事件一起导入，不以分数筛选。

UI 模型选择仅证明界面选择事实，不证明后端身份或同模型控制成立。每场必须保留 `backend-model-unverified` 的精确归因 scope；其他未知、污染、权限及证据闸门不因该例外而豁免。公开基准的预训练记忆无法因未发现外读/联网而排除，不据此作泛化因果推断。
