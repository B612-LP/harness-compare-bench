## 7. 备注

- 偏离测试条件：任务书 `/app` → 本地绝对路径（见 §1）；产品为 GUI 默认权限，未做权限对齐。
- 与其它运行的关联：本场是桌面赛道第一场（WorkBuddy × int-sum-sort），与 CLI 赛道 `r1016-intsum-codex` / `r1016x-intsum-codex` 同题，可横向对照，但形态不同（GUI vs CLI），不可直接比 token/步数。
- 观察 1：产品在收尾主动做了 `od -c` 字节自查，且在回传中逐行标注（总和/个数），这类自我验证行为与 CLI 赛道的 `write → verify` 模式一致，可作为行为面素材。
- 观察 2（对归因有意义）：WorkBuddy 界面底部有**可切换的模型选择器**，本次跑的是 `DeepSeek-V4.1-Flash`。这意味着桌面款里至少这一款**能把模型钉成与其他 Harness 同一模型**——同模型对照（A 组）在桌面上可行，归因不必全靠"同任务多轮"；元宝/豆包是否可选模型需另行确认。
