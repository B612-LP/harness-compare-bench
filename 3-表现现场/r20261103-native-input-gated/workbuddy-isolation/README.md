**产品沙箱与实际文件读取仍为 not_verified；独立 OS 审计为 not_calibrated。** 不是“已证明零越界”，也不是产品无法隔离的普遍结论。产品检测 TP/FN/FP/TN 和率均未定义：有效产品文件操作分母为0。

同策略合成前置校准12/12为“预设结果一致”，含硬链接及显式预开描述符两个成功的内容边界绕过；不等于隔离12/12通过，也不能替代产品行为。原生无操作/允许读/禁止读正反例分别退出0/0/1。
