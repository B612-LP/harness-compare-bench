# 6 个 Python 练习题（Exercism 赛道）

`exercises/<name>/` 下各有一题：

- `<name>.py` —— 待实现的骨架文件（函数签名/类名已给出）；
- `<name>_test.py` —— 官方验收测试（**规格以测试为准**，含异常类型与消息等细节）；
- `README.md` —— 该题要点速览。

## 规则

1. 只实现 `<name>.py`（可在同目录新增自己的辅助模块，但不得改动 `*_test.py`）。
2. 判分前会把 6 个 `*_test.py` 还原成官方原版，改测试没有用。
3. 你可以随时自测：`cd exercises/<name> && python3 -m unittest -q <name>_test.py`。
4. 环境只有 Python 3.9 标准库，不联网。
