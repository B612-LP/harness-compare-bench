# exercism-py-6：六道 Exercism Python 题连做（测试驱动）

## 任务

`inputs/exercises/` 下有 6 个互相独立的 Python 练习题，每题一个目录：

| 目录 | 题目 | 要点 |
|---|---|---|
| `forth/` | Forth 解释器（子集） | 数字入栈、`+ - * /`、`DUP DROP SWAP OVER`、`: 词名 定义 ;` 自定义词、大小写不敏感、栈不足/除零/非法操作等错误 |
| `poker/` | 扑克牌型比较 | 同花顺/四条/葫芦/同花/顺子/三条/两对/一对/高牌，含平票与踢脚规则，返回并列最佳手牌 |
| `dominoes/` | 多米诺闭环 | 把一组可翻转的骨牌排成首尾点数相接的环，排不出返回 `None` |
| `bowling/` | 保龄球计分 | 10 格 + 全中/补中加投，含全部非法输入校验（异常需带非空消息） |
| `zipper/` | 二叉树 zipper | 焦点节点上下左右移动、就地修改、取回整棵树；死路/根上行返回 `None` |
| `pov/` | 树的换根视角 | 以指定节点为根重建树、求两节点路径，含约定好的错误消息 |

每个题目录里：

- `<name>.py` —— 骨架（函数签名或类名已给出，函数体是 `pass`）；
- `<name>_test.py` —— 官方验收测试；
- `README.md` —— 该题要点速览。

## 规则

- **规格以测试为准**：官方测试文件就是对行为的精确定义（包括异常类型与错误消息字符串），请读测试反推实现，逐条满足。
- 在运行目录内直接改代码：实现 `inputs/exercises/<name>/<name>.py`。可以在同一题目录内新增你自己的辅助模块，但**不要修改任何 `*_test.py`**。
- 判分前会把 6 个官方测试文件**还原成原版**再跑，改测试不会带来任何好处。
- 你可以随时自测：`cd inputs/exercises/<name> && python3 -m unittest -q <name>_test.py`。
- 环境：Python 3.9，仅标准库，不联网。

## 达成标准

逐题运行官方测试，**全部用例通过**才算该题通过。目标是把 6 题全部做到测试全绿。完成后直接结束，不需要额外解释。
