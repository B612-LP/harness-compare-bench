# 非特权读取检测：28场合成校准（非产品评测）

## 1. 主张与观察结果

lsof的open-FD瞬时采样与kqueue的vnode变化通知，均不足以作为完整内容读取审计。本次固定28场合成试次中，20场明确执行内容读取、8场未读；它们不是28场产品运行，也不是20次OS read syscall计数。

|被错误当作read代理的观测|TP|FN|FP|TN|已知读取分母|固定样本漏检|
|---|---:|---:|---:|---:|---:|---:|
|open-FD采样|8|12|4|4|20|12/20=60%|
|任意vnode变化/属性事件|1|19|0|8|20|19/20=95%|

未开启任何产品；产品文件读取分母为0、检测率null、隔离not_verified、真人核验pending。无诱饵命中不等于无读取，合成校准不等于产品隔离通过。

## 2. 证据与置信依据

[逐场及逐sample投影](<read-detection.json>)保留固定顺序28行、内容真值字节/hash、每个采样相对起点/调用时长、FD布尔命中、vnode flags、逐场总时长、分层与矩阵。读取真值来自受控合成child实际读取39字节并核对hash；观测来自OS FD/vnode视图，不用child自报生成命中。“独立”仅指观测来源与child oracle分离，不表示独立核验人或真人签名。

open-FD分层：800ms持有读4/4、立即关闭读0/12、50ms持有读4/4；open但不read也4/4命中，idle0/4。唯一读期vnode事件是NOTE_ATTRIB(8)，不是read专属通知。另列的合成追加写正控制命中NOTE_WRITE|NOTE_EXTEND(6)，不并入20读/8非读分母。

lsof命令执行时长中位27.32ms、采样起点间隔中位39.83ms；这些**不是实际文件读取延迟**。逐sample数据允许重算全部时序统计，不只给汇总数字。

## 3. 归因边界

该结果说明本配置下两种非特权传感器作为read代理的盲区：短命FD会漏采，打开FD不代表读过内容，vnode属性/写事件不等于读通知。固定操作序列只包含合成child，未涉及模型、SKILL或任何Harness文件任务，不能归因为五款产品的能力或安全优劣。

“forbidden”只是合成夹具标签，未实施权限隔离；成功读取该夹具不是逃逸真实系统权限的证据。源收据与公开派生hash见[来源映射](<source-map.json>)，只有opaque源ID/hash，没有原路径。公开件是privacy-redacted-derived；派生hash不同于源hash，不声称原件完整公开。

## 4. 不确定性与不能外推的结论

本次是固定顺序、单次实测，未控制缓存/调度/持有时长混合，也未测别名、预开FD、mmap、索引缓存、脱离或委托服务、远端读取与真实产品。60%/95%只描述这一组已知内容读取试次，不能当作产品总体漏检概率或总体置信区间。

没有完整OS-wide read事件真值，无法估计所有真实读取的总体漏检率；零命中不能证明零越界。公开字段的算术一致与hash一致，不能证明未公开源身份、历史封印、完整环境隔离或第三方见证。

## 5. 复核入口与后续关闭条件

[只读复算器](<verify.py>)只依赖Python标准库和本目录公开文件，默认不写文件、不调用子进程/产品/网络、不读取任何私档。运行 `python3 -I -S -B verify.py`；可选 `--output NEW.json` 将结果独占写到本包外的新文件，已有目标拒绝。它重算28行/分母/混淆矩阵/分层/时序，严格拒绝未知字段和状态升级，并核对[文件清单](<manifest.json>)；不能核验未公开源字节或提供签名。复制本目录即可在另一工作目录复核。

若未来要判断真实产品边界，需先有可用的真正受限环境、明确产品本地文件操作入口，以及经读/非读正反例校准且能披露丢失范围的独立观测链；启动失败、空壳UI或helper命中都不进入有效产品读分母。当前产品分母0、率null、隔离not_verified、真人pending保持不变。
