**最新书面报告：[竞品评测报告 v1.2](<5-评测报告/竞品评测报告-v1.2.md>)**。五款产品各五题均有正式产品成绩，分 A / B / W 三轨展示；WorkBuddy 首批判废与唯一替代分开保留，不等于五款同模型排名。

## 阅读说明

- [阶段报告 v4.0](<5-评测报告/阶段报告-v4.0.md>)记录可信冻结、机制实验及独立复核；[阶段报告 v4.1](<5-评测报告/阶段报告-v4.1.md>)是其后续增量，需结合前者阅读。两者的正式表分别对应不同冻结版本，不能把其中某一版本的行数当作所有批次的结论。
- [五款产品逐题历史观察](<5-评测报告/可信冻结-2026-10-29/historical-25-cells.md>)列出各候选的原分与复算分、来源及限制；这些历史候选不等同于新规则下的正式成绩，也不是五款产品的总排名。[首批正式批次结果与现场](<3-表现现场/r1030-formal-a1/README.md>)仅覆盖 Codex 和 DSH，每格一次；未准入不等于产品得零分。
- 正式 A 组仅 Codex / DSH CLI；WorkBuddy 正式成绩位于 W 网关整体产品轨，元宝与豆包位于 B 开箱默认轨。标签相似不证明后端同模，工具、权限、原生上下文与版本差异均须披露；不能把跨组差异直接归因于 Harness。研究变体不混入原版产品成绩。
- 历史候选、正式准入、后续复算及不同时期的冻结表使用不同口径。未知和不满足准入条件的运行不能当作产品零分；小样本观察也不能直接推出普遍排名。部分历史原始封印资料因隐私不公开，公开摘要不能替代对原件的独立核验；各项结论以对应报告中的证据和限制为准，另见[历史封印与公开版本复核限制](<1-评测方案/历史封印复核限制.md>)。
