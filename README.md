# Harness 竞品评测

本项目比较 Codex、WorkBuddy、DSH、元宝专家模式和豆包办公，提供评测方案、用例、实际表现、打分细则和书面报告。评测要求见[课题作业公告](<0-公告原文.md>)。

**当前主报告：[竞品评测报告 v1.30](<5-评测报告/竞品评测报告-v1.30.md>)**。正式 25 格全部 **n=1/格**，A / B / W 只作轨内比较，不合成五款总排名。

对照[第四周反馈](<反馈/2026-11-11-第四轮/README.md>)，优先减少机制与观测的不确定性；[一页结论—提交—复算—缺口索引](<5-评测报告/结论复核索引-2026-11-12/README.md>)给出固定版本入口。

- **输入为何减少：**[源覆盖分析](<5-评测报告/输入源覆盖与机制区分-2026-11-12/README.md>)区分工具正文省略与包装差；捕获区间旧历史保留，但外存实际回读、服务端处理和思考量仍未知。
- **30 次测了什么：**[重复口径澄清](<4-打分细则/机制重复口径澄清-2026-11-12/README.md>)核实 30 槽/10 组，测的是选定观测量重复性而非外溢效果；DSH 4/5 仅为字节子门，完整旧门 6 组不通过、4 组不可核。
- **日志稳定意味着什么：**[计量分解](<5-评测报告/日志计量有效性-2026-11-12/README.md>)发现 15 槽S3合计的 68.49% 是静态声明，R3混合多类追加payload；[条件附证](<4-打分细则/日志代理反证-2026-11-12/README.md>)区分日志、发送变换与body。不能直接当实际请求输入或成本。
- **零命中如何判：**[读取观测裁定](<4-打分细则/读取观测裁定-2026-11-12/README.md>)只支持“在当前检测面未观察到”；WB 1,124 个采样记录不是读取机会，豆包未采不记零，真实漏检上界仍未知。本次不新增产品运行、不改历史成绩。

- **反馈返回后发生了什么：**[闭环再分析](<5-评测报告/反馈闭环再分析-2026-11-12/README.md>)区分grader complete、成功修补回包、后续复验与全局终答；旧F5单例的主体引用链不足，不把已修补写成已至绿，也不改原标签或分数。
- **Cargo三红意味着什么：**[燃油政策与判据辨别](<5-评测报告/燃油政策与判据辨别-2026-11-12/README.md>)在最终储备及简化模型条件下分开两政策与三项点门；不裁定唯一完整合同、不把点门通过当全航段合规，不改旧分。

## 阅读说明

- [阶段报告 v4.0](<5-评测报告/阶段报告-v4.0.md>)记录可信冻结、机制实验及独立复核；[阶段报告 v4.1](<5-评测报告/阶段报告-v4.1.md>)是其后续增量，需结合前者阅读。两者的正式表分别对应不同冻结版本，不能把其中某一版本的行数当作所有批次的结论。
- [五款产品逐题历史观察](<5-评测报告/可信冻结-2026-10-29/historical-25-cells.md>)列出各候选的原分与复算分、来源及限制；这些历史候选不等同于新规则下的正式成绩，也不是五款产品的总排名。[首批正式批次结果与现场](<3-表现现场/r1030-formal-a1/README.md>)仅覆盖 Codex 和 DSH，每格一次；未准入不等于产品得零分。
- 正式 A 组仅 Codex / DSH CLI；WorkBuddy 正式成绩位于 W 网关整体产品轨，元宝与豆包位于 B 开箱默认轨。标签相似不证明后端同模，工具、权限、原生上下文与版本差异均须披露；不能把跨组差异直接归因于 Harness。研究变体不混入原版产品成绩。
- 历史候选、正式准入、后续复算及不同时期的冻结表使用不同口径。未知和不满足准入条件的运行不能当作产品零分；小样本观察也不能直接推出普遍排名。部分历史原始封印资料因隐私不公开，公开摘要不能替代对原件的独立核验；各项结论以对应报告中的证据和限制为准，另见[历史封印与公开版本复核限制](<1-评测方案/历史封印复核限制.md>)。
- 周期进展、逐日变更与各期周报见 [CHANGELOG](<CHANGELOG.md>) 与[周报索引](<6-周报/README.md>)（第1期为[2026-10-17 原文](<6-周报/2026-10-17-第1期.md>)）；发送状态在该索引如实簿记；[第4期周报](<6-周报/2026-11-07-第4期.md>)已由本人提交发送（2026-11-09 确认），当期文件为提交时点定格版本，发送状态以[周报索引](<6-周报/README.md>)期表与 [CHANGELOG 存档表](<CHANGELOG.md>)为准。
