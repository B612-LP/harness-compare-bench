# Harness 竞品评测

课题：独立设计并产出一套 Harness 竞品评测报告，比较对象为 **Codex、WorkBuddy、DSH、元宝专家模式、豆包办公**。

**本阶段口径 = CLI 赛道**：先在有 CLI 的 Codex 与 DSH 上建立可复核的对照链路（自建用例 × 同一模型 × 裸模型基线），把「模型 / SKILL / Harness」的归因链跑通，再谈横向结论。WorkBuddy、元宝、豆包三款桌面端现场属后续计划，本仓当前不含其数据——引用本仓结论时请按此边界理解。

## 贯穿原则：归因定责
