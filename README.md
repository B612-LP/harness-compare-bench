比较 Codex、WorkBuddy、DSH、元宝专家模式和豆包办公。当前为第三周：**可信冻结、机制干预与独立复核**，不提供混合模型、混合形态的五款强弱总排名。要求以[公告原文](<0-公告原文.md>)及[第二轮老师反馈](<反馈/2026-10-28-第二轮/README.md#L34-L42>)为准。

1. [阶段报告 v4.0](<5-评测报告/阶段报告-v4.0.md>)：本轮执行状态、冻结规则、机制研究及独立验收。只有实际收据落盘的结果才算完成。

3. [机制实验入口](<1-评测方案/机制实验-2026-10-29/README.md>)与[五段结论](<1-评测方案/机制实验-2026-10-29/RESULTS.md>)：6场真实运行、12次官方调用；研究变体不混入原版产品排名，技术修订及首次失败均保留。

## 历史覆盖与当前准入是两件事

历史五款×五题已收满可用候选，WorkBuddy×LCB 已有网络级隔离干净场，见[检索口径最新追记](<4-打分细则/检索口径-2026-10-27-落表.md#L70-L77>)。旧污染场、失败场及替代关系保留，不恢复旧污染成绩。

**新版[严格正式主表](<5-评测报告/可信冻结-2026-10-29/official-main-table.json>) A=0、B=0**：没有倒填历史当场配置或预注册，也不拿研究变体凑分；这不是产品得0分。[25格有限历史观察](<5-评测报告/可信冻结-2026-10-29/historical-25-cells.md>)仍完整保留。

- **A 组**：Codex CLI、DSH CLI、WorkBuddy 桌面，同模型标识；不能假称系统提示、工具、权限及交互全部相同。
- **B 组**：元宝专家模式、豆包办公，默认模型的整栈观察；不能把跨组差异归因纯 Harness。
- **研究组**：技能、模型、隔离与工具输出保留等消融/干预，单独列出，不作为未经修改的官方产品成绩。
- **证据边界**：历史候选完整不等于当场版本/配置/规则已完整冻结；原始分、后续复算、准入裁定分别保存。n 小的观察不证明普遍稳定性，同错不证明模型上限，token 分解不证明机制因果。
