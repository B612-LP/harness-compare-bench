## 覆盖与边界

| 对象 | 已有形态与证据 | 当前口径 |
|---|---|---|
| Codex | CLI；当前五题与重复样本 | A 组，同模型标识；见[现场入口](<3-表现现场/README.md>) |
| DSH | CLI；当前五题与重复样本 | A 组；不宣称全部变量同构 |
| WorkBuddy | 用户手工 GUI；轨迹与产物 | A 组；LCB 命中官方题解为 suspect，主表 excluded，不补0 |
| 豆包办公 | GUI；对话导出、TASK、产物，无截图为既定取证口径 | B 组默认模型；不能将与 A 组差异归因 Harness |
| 元宝专家模式 | 尚无本轮可纳入结果 | paused，不记失败或0分，不等待新 GUI |
| 裸模型基线 | 历史 C 组，不属于产品 | 方法史料，不等于当前五题的因果消融 |

A 组 Codex/DSH CLI 与 WorkBuddy GUI 同模型，不等于联网、系统提示词、SKILL、权限、工具和交互形态都相同。n=3 只描述三个观察样本，不证明无噪声；同错不证明模型上限；仓外工作区+软约束是组合干预，不写成单因素验证。旧[四维评分草案](<5-评测报告/评分方案-v2-草案.md>)仅保留历史探索，不作本轮主排名。
