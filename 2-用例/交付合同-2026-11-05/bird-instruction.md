## 任务与输入

`inputs/questions.json` 包含针对加州学校 SQLite 数据库的15道问题。请为每一道题写一条只读 SQLite 查询，在当前运行目录交付 `answers.jsonl`。数据库包含 `frpm`、`satscores`、`schools` 三张表。

以下输入均可读、不得修改：

- `inputs/db/california_schools.sqlite`：完整数据库。
- `inputs/schema.sql`：表、字段、类型及连接键。
- `inputs/sample_rows.json`：每表前三行样例，用于判断字段和取值形态。
- `inputs/questions.json`：`question_id`、中文题面 `question_zh`、中文口径提示 `evidence_zh`、要求的结果列顺序 `answer_columns`，以及仅作溯源的英文原文。

以中文题面和中文口径提示为准，英文不覆盖本地要求。每题必须遵守 `answer_columns` 的列顺序和列数；结果列名不参与判分。

已有两项口径在这里完整说明：

- q26 的“免费或减价餐”使用 `FRPM Count (Ages 5-17)`，年龄口径为5–17，阈值严格大于800；不是仅免费餐的列，等于800不满足。英文旧年龄表述只作来源记录。
- q27 使用原始键 `schools.CDSCode = satscores.cds` 的等值 LEFT JOIN：保留题面日期条件命中的所有学校，包括无 SAT 记录者，其分数保留 NULL；不对键做前导零归一，不将同名异校去重。这里规定连接与实体保留口径，不提供查询答案。

## 交付硬约束

- `answers.jsonl` 使用 UTF-8，恰好15个非空行，每行一个 JSON 对象；不要放 Markdown 围栏、解释、状态行或其他非JSON内容。
- 每行恰好两个键：`question_id` 和 `sql`；不得增加 `status`、`verified` 等任何其他键，不得缺键。
- `question_id` 推荐使用题集中的整数编号；判卷按字符串化并去首尾空白后的编号识别，不额外将整数类型设为评分硬门。15个编号与题集一一对应，不得缺失、多余或重复。
- `sql` 必须是字符串，内容是一条可直接在给定库执行的只读 SQLite 查询；不得写入数据库，不要多条语句。
- `sql` 禁止单引号字符串字面量之外出现 `--`，包括行尾注释。单引号字面量中的 `--` 允许；SQL单引号转义写作 `''`。不要用注释添加完成或验证声明。
- `inputs/` 下所有文件保持原字节。允许只读查询自测，禁止修改输入。

## 完成条件与判分

交付格式、题号覆盖或输入完整性硬门不通过时，即使部分查询正确，整场仍不通过。格式和覆盖通过后，以每题查询的结果集与该版本冻结的评测结果集比较：NULL归一，浮点数四舍五入至6位小数，字符串去首尾空白；按列序比较，行顺序不敏感，但重复行敏感。不能用SQL文本相同与否代替结果集比较。

至少12/15题结果集一致（准确率≥0.8）才通过；得分率为准确率×100。同结果的等价SQL写法可以得分。
