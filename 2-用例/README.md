# 用例

每条用例必须规定三件事（公告原文要求）：**任务、输入、完成条件**。

## 用例模板

```markdown
# 用例 N：<一句话任务名>

- **任务**：让 Harness 做什么（指令原文）
- **输入**：给它的初始文件/环境
- **完成条件**：如何客观判定"做完了"（文件存在？内容正确？可机械校验优先）
- **考察点**：打算观察 Harness 的哪个能力
- **分层**：基础 / 进阶 / 归因消融用（三层用例框架）
```

## 约定

- 五款 Harness 跑**同一批用例**，输入一致。
- 桌面端口径：任务是桌面可完成的，证据 = 录屏 + 产物文件校验。
- 旧仓库的 Harbor CLI 用例（int-sum-sort）如保留，只作方法论补充，不算五款对比证据。
