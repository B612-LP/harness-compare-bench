# 引用回读与已知读取正控（2026-11-13）

> 2026-11-13 新增预注册最小实验与正控（本窗 Ring 1–3）。**新产品运行：DSH 机制实验 10 会话、WorkBuddy 正控 3 会话、豆包工作正控 3 会话；均不入正式 25 格，不改历史分数与冻结原件。** 目的：回答[老师第四周反馈](<../../反馈/2026-11-11-第四轮/README.md>)两项 P1——①外溢/截断/重组如何用最小对照区分；②真实产品"零读取命中"如何裁定。

## 一、问题与设计

正式批次的捕获显示：DSH 在工具结果超过外溢阈值时把正文替换为短预览加引用路径（bounded），同一产品内联模式（inline）则全量携带。旧批次的合同禁止额外工具，因此**"模型能否顺着引用把全文读回来"从未被测试**——这是输入减少机制三分（工具外溢 / 旧历史截断 / 消息重组）里唯一可实测的缺口。同时，真实产品此前 0 读取命中是"检测面未观察到"，缺已知内容正控来排除"读取路径不可达"这一竞争解释。

设计（预注册后执行，同版本 DSH 0.2.0-rc.2 + deepseek-flash、思考档 low）：

- **C1×2 复制门**：逐字复刻 2026-11-03 bounded 条件（无 read 工具、外溢阈 512），先跑，作为漂移门。验收：首请求输入 1124B±8、bounded 增量 2382B±64、两请求完整。
- **RB×6**：bounded + 工具菜单新增 `read(path,offset,limit)`（512 阈）。提示词只要求三键 JSON，**从不提 read**——测模型是否自发使用恢复路径。键值：HEAD=夹具头尾观测值、MIDDLE=noise-0210 的 checksum（sha256("fixture-v1-210")）、TAIL=尾观测值；MIDDLE 位于预览截断区内，只能经 read 恢复。
- **IMK×2**：同菜单、阈值 1,000,000（等 inline 全量），作成本对照。
- 预注册或有臂 rb-nudge×3（提示词追加 read 提示）：仅当 RB 六场全部未调 read 才发射；实际未触发。

## 二、结果（数值见 [result.json](<result.json>)，[verify.py](<verify.py>) 一键复算）

| 臂 | 场次 | 关键结果 |
|---|---|---|
| C1 复制门 | 2 | delta=2382B，与 1103 冻结基线**完全一致**；门通过，无漂移 |
| RB 引用回读 | 6 | **6/6 自发调用 read**，MIDDLE 6/6 恢复正确（Wilson95 [0.610, 1]）；HEAD/TAIL 全对 |
| IMK 内联对照 | 2 | 三键全对（基线能力确认） |

**结论：引用⇒全文可回读在该机制面上实证成立**（分支 recovered_via_read）。成本结构（客户端组装 UTF-8 字节，描述性）：RB 三请求会话总输入中位 12,293B vs IMK 内联末请求中位 38,435B，**省约 26,142B（≈32% 的内联成本）**；bounded 相对 inline 的字节优势大部分可以在会话内被自发恢复路径兑现。

**真实产品已知读取正控**（探针=同一 422 行夹具，要求读文件后报三键）：

- **WorkBuddy**（5.9.3，原生桥，模型档位未控、如实披露）：3/3 恰一次 Read、结果 38,332 字符全文内联（行号格式）、无截断/无分页引用、三键全对。
- **豆包工作**（2.35.19，原生桥，用户已选 DS Flash + Low）：3/3 恰一次 Read、结果 37,367 字符全文内联（制表符行号）、无截断标记、三键全对；**本地轨迹无任何 usage/token 字段**（如实记录）。

对老师不确定性②的含义：两款真实产品的读取路径在探针条件下**可达且回读全文**；此前被动采样 0 命中因此不能归因"读取失效"，但**不构成**漏检上界（FN bound）——正式报告"在当前检测面未观察到"的裁定维持不变，只补充"读取路径可达"这一正控事实。
