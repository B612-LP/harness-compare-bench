# 同对象、同窗，还不能把一次读取归给某一臂（2026-11-29）

[第五周反馈第 4 条](<../../反馈/2026-11-18-第五轮/验收条款-公开版.md#L38>)要求同对象、同时间窗有真实的正负例。本页只重算[既有非产品校准的公开派生](<../同对象同窗读取检测校准-2026-11-19/evidence.json>)，并用匿名逻辑对照问：如果保留对象级读事件和持有区间，去掉谁执行读取的独立证据，还能判什么？**已知目标被读、知道谁读、知道对侧只打开，是三个不同的结论。**

## 两个旧窗：只撤掉生产者证据，不改原裁定

下表时间均为各对相对自身起点的毫秒。X、Y 是两臂，表中的候选只表示时间上可由其持有代产生，不是判定。原试验另有独立动作记录，两窗均记录 X 真实读取、Y 只打开；以下去信息检验不使用该角色记录来判候选。

| 旧窗 | 确有读取的时间段 | 去掉生产者后，对内时间可行臂 | 原检测配对 |
| --- | --- | --- | --- |
| 长 | `34.021–34.030` | X 或 Y，两臂此前都已核到持有 | 采样 `125.037–142.443` 全在计划截断的读后共同持有窗 `35.020–650.000` 内，原 FD 观察两臂均见，只能说明该次 FD 有无不能区分读与仅开 |
| 短 | `4.877–4.882` | 只有 X；Y 从 `5.048` 才开始打开 | 不准入。Y 超过开端容差 `3.000` 共 `2.048`，较晚的持有核对比首个动作晚 `0.219`；采样 `7.462–16.413` 又超过计划右端 `12.000` 和第一个实测关闭起点 `13.023`，命令退出 1。不能算负臂未见或正臂漏检 |

短窗“只剩一个对内候选”也不证明来源封闭。如果没有另证事件只能由这两臂产生，长窗与短窗都仍要允许对外来源。计划截点不是实测关闭时点；本页也不把命令的整个采样包络压成一点。

## 匿名对照：什么时候才有真阴性

以 `10` 表示 X 至少有一次合格读、Y 没有，`11` 表示两臂均有，其余类推。合格读的整个正长度操作须落入声明的半开窗口，且命中同一对象版本、已核持有代和指定读取路线。`0` 不排除跨窗操作在窗内读到的字节，也不排除未纳入的路线。这里的“完整”不是 FD 在场，也不证明产品使用或物理介质读取。

| 输入条件 | 仍可成立的结果 |
| --- | --- |
| 有一个独立锚定到 X 的目标读；Y 只有 FD 观察，或尚有可读区间未被读取记录覆盖 | `10 / 11`，不能判 Y 未读 |
| 同一 X 目标读；Y 的目标读取路线独立证实全窗覆盖且无目标读 | `10`，可在这个属性和范围内判 Y 阴性 |
| 一个独立目标读能由 X 或 Y 产生，对内来源已封闭，双臂全覆盖；同一发生锚的记录出现两次 | `01 / 10`，副本仍是一次读取 |
| 两个独立目标读，时间与可行持有代集合恰好相同，其余条件同上 | `01 / 10 / 11`；按窗口或持有代集合去重会错误删掉 `11` |
| 一个独立目标读，在两臂里只有 X 时间可行，未排除对外来源，双臂全覆盖 | `00 / 10`；`00` 不否定该对象确实被读 |

实际接入时，发生锚要能追到源记录，既能区分不同发生，也能把同一次发生的多个副本归并；角色、同一时刻、同一 FD 编号都不能代替它。还须核对时钟、对象版本和持有代。输入没有收录某个旧代是**未知**，不是已证该代在读前关闭的**冲突**。已有对象见证也不因另一条臂归属有冲突而消失。没有同域完整的负臂证据，结论保留未知，不从“当前检测面未见”改报“没读”。
