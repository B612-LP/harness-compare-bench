## 五段结论

**观察**：两轨 30 个判分槽的加权分波动全部可分解为「少数翻转断言 + 确定性稳定失败核」：豆包 dabstep 60×3 的 4 个失败断言三轮逐字节稳定（零翻转）；豆包 lcb 的 100→75→75 波动带 = 单一断言 `abc389_g` 的翻转；两轨 bird 各只有 1 个翻转断言（W `q62`、豆包 `q25`）解释 93.33↔100；tb 是唯一多断言波动题（W 稳定失败 6 + 翻转 3；豆包稳定失败 4 + 翻转 5）。

**证据**：逐槽 checks 明细（含 checker SHA256 与 execution 收据 SHA256）见两份 JSON；分析器为确定性脚本（L22 PREREG 封印 297f66ac… 后落盘，异常类 FileNotFoundError/ValueError(L22-A) 申报在案）；30/30 槽 ok、unanalyzable=0。

**解释**：V/F（reward 达标线）三轮一致的重复性结论之下，加权方差并非不可解释的噪声：未达标题存在确定性的断言失败核（能力缺口的稳定部分），翻转断言（1–5 个/题）才是采样方差的全部来源——「跨批比较应看 V/F 格局与分布而非单点分」的既有口径在断言粒度得到机制解释。

**未排除因素**：断言级 pass 仍由冻结 checker 判定，checker 本身的判定边界（含 q26/q27 类语义尖角）不因本分析改变；两轨 checker 合同相同（wb-v2）但会话上下文、时间窗不同；翻转断言的「翻转原因」（产品行为随机性 vs 判定边界敏感性）本分析不区分。

**可复现实验**：对任一槽用其 execution 收据 SHA256 对账后重跑集合运算脚本即可复现（脚本与 PREREG 封印在私档 L22 目录）；或按[报告 §6.4](<../竞品评测报告-v1.3.md>)对任一槽以冻结 checker 原字节重判后对照 checks。
