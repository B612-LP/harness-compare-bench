# 单变量干预两臂：同输入重复与单字符标记差（2026-11-19）

第五轮反馈第 2 条要求机制研究只选一项可控干预、两臂其余一致。此前[统一观测规范](<../../4-打分细则/Harness统一观测规范-2026-11-19/README.md>)第 4 节记录过两个自然运行首任务请求相同、本地记录 18/18 不同，但明确其为**非可控对照**。本页补上受控版本：在同一隔离发射环境（独立配置根、无个人注入、固定模型/档位/工作区）下，对同一 CLI 产品连续发射 8 次（两臂 4+4 交替），唯一变量是用户提示里的一个任务标记字符（`ARM-A` ↔ `ARM-B`，两版提示除该字符外逐字节相同，发射前以 SHA-256 锚定）。捕获层为本地事件账（L1），本环无客户端请求捕获（W），如实声明。

## 不变量（8/8 成立）

- 事件骨架一致：会话 → 轮开始 → 步 1（思考 → 读文件 → shell 计算摘要）→ 步 2（思考 → 答复文本）→ 轮结束 → 终局；8 次中 7 次精确同构，1 次（b2）在步 1 内多一段文本（16 对 15 事件）。
- 8/8 终局答案报告正确摘要；8/8 工具选择同为「读 + shell」；8/8 工作目录精确绑定各自副本，无跨跑渗漏。
- **步 1 请求侧 token 总量恒等**：输入 + 缓存读 = **5,636，8/8 完全相同**。首两次运行的拆分（388+5,248）与其余（260+5,376）相差的恰是 128，为缓存热度造成的「新鲜/缓存」记账拆分差；总量不受单字符标记或重复发射影响。

## 基线非确定性（同臂、逐字节相同输入的重复之间）

- 会话 ID、调用 ID、用量拆分与**全部自由文本**（思考/答复/终局）每次不同。
- 结构性偏移在基线内也出现：b 臂内 1/4 次出现步 1 多段文本；a 臂内 0/4。跨臂结构差 0/4 对同臂基线 1/4，精确检验 p≈1.0，无臂关联证据。

## 跨臂裁定

- 骨架对齐的跨臂对，其差异路径全部落在同臂基线已出现的类别内：**单变量涟漪集为空**——一个标记字符在本地事件账层没有引起系统段、工具段、行为参数或请求侧 token 总量的任何新差异。
- 事件账**不含用户输入的确定性回显字段**：8/8 无提示词回显，臂归属只能依赖运行器元数据。标记在账本中仅出现 1/8 次，是模型在思考文本里自发提及（归属正确，属自由文本类，非回显）。

## 结论与边界

受控对照把旧观察分离成两层：**请求侧稳定**（同输入下请求 token 总量逐次恒等，且对单字符干预不敏感）与**轨迹侧易变**（本地自由文本必变、偶发结构偏移约 1/8）。「同首包相同但本地记录不同」因此获得机理解释：差异主要产生在模型输出轨迹层，而不是请求装配层。限制：仅 L1 层、样本 4+4、缓存热度影响用量拆分、结构偏移表明采样级方差存在——「其余一致」指不变量层，不指逐字节轨迹层。发射器、原始事件账与预注册在私有档案留存，不在公开仓发布；本页不改正式 25 格、不外推其他产品或召回。
