# 同一普通文件、同一时间窗：读与仅打开的 FD 观测校准（2026-11-19）

针对第五轮反馈第 4 条，本次在本机由同一非 root EUID 的父进程与 worker 实跑一次**非产品**本地夹具：同一个普通文件，长窗和短窗各安排一对真实读取／仅打开。长窗得到一对合格观测，两个 FD 都出现；短窗的两个动作均有独立记录，但无法成立同窗检测配对，报 `unknown`。不重算 11/04 的合成比例，也不把本次证据拼入 11/14 未配对的产品支持集。

## 如何配对

- 父进程独占创建一个 `0600` 普通文件，写入预先确定的 512 字节并关闭写 FD。两对按顺序执行，每对启动两个新的自有 worker，分别 `O_RDONLY` 打开同一文件，分别从 offset 0 起步；不共享或继承目标 FD，上一对回收后才启动下一对。父进程创建时取 `fstat`、清除前核对路径元数据；两臂各自在打开后和动作后取 `fstat`，核对设备号、inode 和文件类型等是否一致。两个 worker 只在同对刻意并行。
- 双方就绪后通过管道发布同一 `CLOCK_MONOTONIC` 起点 T；同对的计划内容动作、FD 持有时长和采样相位一致，不假定两个系统调用同一纳秒发生。封存参数均为相对 T 的毫秒数：

| 对照 | 计划持有 D | 计划动作 | 计划采样启动 | 允许延后 |
|---|---:|---:|---:|---:|
| 长 | 650 | +30 | +120 | 15 |
| 短 | 12 | +4 | +7 | 3 |

- 内容真值独立于 FD 观察：正臂对目标 FD 调用一次 `os.read(fd, 512)`，检查实际长度、实际字节的 SHA-256、初末偏移；负臂按独立动作分支只记录无读取 marker，不调用目标内容读取、不执行映射，核对偏移仍为 0；字节数和摘要字段留空，不是“调用 read 但返回 0”。偏移只是辅证，不单独证明不读。目标字节来自预先固定的合成内容；同 inode 可能共享 OS 缓存，本实验不主张物理介质读或冷缓存。
- 观察侧每对最多一条同次 `lsof` 命令，以自有 PID ∧ FD 筛选（不做全系统检查），按每臂 PID、FD、`REG`、设备号和 inode 精确判定，不用路径猜测。须退出 0 且 stderr 为空。保守地用父进程启动命令前至回收后的完整时间包络，而非臆造一个原子采样点。要求两臂在较早动作前都已完成目标 `fstat`，且命令包络完整落入对内读后持有窗：`[max(T, 两臂后置 fstat 时点), min(T+D, 两臂开始关闭的时点)]`。如果缺对象或时间证据，或者命令输出不可用，结论是 `unknown`，**不是未检出**。

## 实际记录

下列时间为每对各自相对 T 的毫秒，不用于跨对绝对对齐。两次正读均返回 512 字节、摘要等于事先计算的预期，offset `0→512`；两次负臂均记录仅打开和 marker，offset `0→0`，无读取长度或摘要。没有失败后补测或替换样本。

| 对照 | 内容与窗口证据 | `lsof` 命令实际包络及结果 | 裁定 |
|---|---|---|---|
| 长 | 正读 `+34.021–34.030`；负臂已在 `+5.080` 完成前置 `fstat`；合格的读后共同持有窗 `[+35.020,+650.000]` | `[+125.037,+142.443]` 全在窗内，退出 0，stderr 空；两臂均精确匹配目标 | `matched_same_fd_visibility`：FD 有无不能区分这一次已实际读和仅打开 |
| 短 | 正读 `+4.877–4.882`；负臂到 `+5.048` 才开始 open，超过 `+3` 容差且正读已结束；`[+5.179,+12.000]` 只是事后持有时段的交集，不是合格配对窗 | `[+7.462,+16.413]` 越过计划窗右端 `+12.000` 和第一个开始关闭的时点 `+13.023`；退出 1，stdout/stderr 均空 | `unknown`（不纳入同窗观察），不能叫短读漏检 |

## 如何离线复核，以及复核不到什么

[证据派生](<evidence.json>)保存相对时间、两臂真值记录、精确匹配判据的布尔摘要和原件摘要承诺；真实路径、PID、FD、UID、设备号、inode、全量原始 `lsof` 字节及绝对时点不公开。用预置 Python 3 标准库运行 `python3 -IB verify.py --self-test`（在本目录），[核对器](<verify.py>)可重算时间与判定一致性，并检查无可用同窗样本、缺精确匹配、对象错绑等分支仍是未知。这些检查不运行夹具，也不是额外样本。该派生不允许公众独立核验原始 PID/FD/设备/inode 绑定、封存时间链、负臂源码或原始字节；摘要本身不代替查原件。

**范围**：1 对合格、1 对未知，非产品运行，不是读取普查、读取召回率或污染率的分母；不给产品读取真值、召回率或污染上界。未验证别的观测器、缓存、`mmap`、代理代读或实际生产负载。本次只说明一次局部的“同 FD 可见性但内容行为不同”，与一次无法判定的短窗。
