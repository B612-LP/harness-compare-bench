# 单变量机制干预：DSH 溢出策略 maxInlineTokens（2026-11-20）

第五轮反馈第 2 条的机制干预发射资格在[统一观测规范](<../../4-打分细则/Harness统一观测规范-2026-11-19/README.md>)冻结 v1.0 后达成（第 4 节门控句：规范冻结 + 通过含两臂等控证明的独立预注册）。本页登记首个满足该资格的机制干预：同一 CLI 产品、同 fixture、同提示词、同模型路由与档位、同隔离发射环境，**唯一变量 = 溢出策略插件的一个配置值 `maxInlineTokens`：12500（生产值）→ 500**。两臂等控证明：双隔离配置 `--dump-config` 全量 diff，唯一值差异为该配置行（12500 vs 500）。预注册（含两臂等控清单与停止规则）于发射前写定，双臂冒烟符合口径后发射 a1..a5 与 b1..b5 串行各 5 跑。

## 干预的机制含义

该配置值控制工具输出进入模型上下文的呈现方式：值足够大时输出**内联**完整进入上下文；值足够小时超出部分**溢出**——呈现为头部+省略注记+尾部，完整文本另存本地文件并在注记中给出路径（模型需自行 follow-up 读取）。fixture 为 16000 字节确定性构造文本，末行嵌 32 hex 标记（远小于 bash 执行器自身的 64,000 字节输出上限，避免共同路径混淆）。

## 结果（5+5，全部完成）

| 臂 | 工具链形态 | 首工具输出呈现 | 标记可达性 | 终局真值 |
|---|---|---|---|---|
| A（12500，内联）×5 | 恰 1 次工具调用（4 跑 bash cat、1 跑 read 工具） | 无省略注记 | 预览层 4/5 直接可见（1 跑 read 输出带行号前缀，标记落在预览窗外） | 5/5 报告正确标记 |
| B（500，溢出）×5 | 恰 2 次工具调用（bash cat → 对原文件 grep） | 有省略注记+完整文本另存路径 | 首输出 0/5 含标记；经第二次工具 grep 原文件 5/5 恢复 | 5/5 报告正确标记 |

- **呈现确定性翻转**：5/5 对 5/5，方向与机制文档一致；任务完成两臂均不受损（溢出臂模型经第二次工具对原文件 grep 恢复信息后正确作答；5 跑均未读取注记给出的另存文件，恢复路径是重读原文件）。
- **工具链形态翻转**：内联臂单工具直答；溢出臂两步链（先读、再补救检索）——配置值翻转改变了 harness 的呈现与随之而来的工具编排行为，同输入同提示词。

## 仪器边界（如实登记）

本环捕获层为本地事件账（L1），无客户端请求捕获（W）。事件层对工具输出有 8192 字符预览上限；**1/5 内联臂跑次用 read 工具（非 cat），输出带行号前缀使标记落在预览窗外而模型仍单工具直答正确**——模型上下文（W 层）与事件预览层非同界、内联臂的完整载荷进入模型上下文为真（作为工件支持的推断登记）；超出预览窗的字节分账需请求捕获，不在本环仪器范围。另存文件（stored 通道）终态：溢出臂 6 跑注记指向的本地文件经事后按工件记录路径复核**全部存在**——各恰 16,000 字节、含标记、SHA-256 与原 fixture 逐字节一致，为第三方可复核证据（此前一版「跑末被选择性清除、不可复核」的判读系按未入索引的路径检索所致，已更正）；溢出臂模型行为不依赖该文件，结果不受影响。独审发现本页与内部裁定初稿存在表述错误（检出相位、恢复路径），已按独审更正——本页为更正后版本。

## 检出探索性附注

同窗 kq 采样器（1 ms）对夹具的持有检出：内联臂 0/5、溢出臂 1/5——该唯一检出发生于溢出臂**第二次工具（对原文件的补救 grep）阶段**，而非受干预的首读阶段：内容被溢出挤出首轮工具结果后，模型的恢复重读成为被检出的相位。n=5 仅登记，不作检出率结论。

单个配置值翻转 → 呈现与工具链形态**确定性**翻转、任务完成保持：这是该 harness 该配置值下的呈现行为证明（机制存在、方向与文档一致、单变量因果成立）。反目标守约：不入正式 25 格、不外推其他配置值/产品、不折算召回或污染上界、不声称读完/没读（检出为 FD 持有证据）。发射器、原始事件账与预注册在私有档案留存，不在公开仓发布。
