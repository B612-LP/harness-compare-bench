# 读取采样：允许速率差后，短窗是否仍装不下？

**仍装不下，若只允许示例的 ±1% 速率差。** 四份既有非产品派生（五组观察）中，短窗的采集包络为 8.951 ms，可用窗 6.821 ms。只有把采集时间跨度缩放到至多 `6821/8951`（约 `0.762038`），几何上才可能平移放入；与 1 相差至少 **约 23.7962%**。这不是测到的时钟误差。原短窗的配对、采样健康仍分别不合格，原判定仍 `unknown`。

**怎么比较。** 继[固定时差](<../读取采样时差边界-2026-11-19/README.md>)，将整个采集包络的端点 `t` 映到 worker 轴 `T + α(t−T) + δ`。`T` 是各次第一采集的起点；只允许正有理 `α`，各组有一个自由有理 `δ`；严格端点采用明确 1 ns 裕度。间隙前后两次采集必须共用同一对参数。对每个候选 `α`，取所有 `δ` 下界最大值和上界最小值；每对上下界的相容性给一条 `α` 的线性约束。`α=1` 的五组结果与固定时差逐值一致。

| 原派生 | 存在相容 `δ` 的 `α` | 示例 ±1% 内 |
|---|---|---|
| 长对照 | `(0, 307490/8703]` | 每个 `α` 各自有 `δ` |
| 短对照 | `(0, 6821/8951]` | 无 |
| 采样间隙 | `[122070001/287163000, 576997999/308345500]` | 每个 `α` 各自有 `δ` |
| 单次偏移 | `(0, 316803999/18809000]` | 每个 `α` 各自有 `δ` |
| 文件映射 | `(0, 323086499/17857500]` | 每个 `α` 各自有 `δ` |

若把间隙的两次采样分开配 `δ`，仅保持 `α` 相同，可行区间扩到 `(0, 216795499/12356000]`；例如 `α=0.1` 或 `α=2` 会被这个放松条件接受，却不能用同一校正同时保留目标完整生命周期与见证窗关系。反过来，“示例带内每个 `α` 各有一个 `δ`”也**不等于**有一个 `δ` 对整个带通用；独立复算用合成反例确认两个量词不可互换。

**复算。** [公开数值](<evidence.json>)保留有理界、限制约束和 `α=1` 的整数端点。仓库根运行 `python3 -IB '5-评测报告/读取采样速率敏感性-2026-11-19/verify.py' --check-sibling`（也可加 `-O`），只读固定提交的四份公开派生并检验平移、边界和合成反例。非作者从同一范围独立复算；无新夹具、产品或模型运行。这些数不校准真实时钟，不给产品读取真值、召回、污染上界或原短窗的补判。
