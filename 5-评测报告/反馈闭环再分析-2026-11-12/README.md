# 反馈闭环与评分字段主体：两条历史轨迹的事后重分析

## 1. 结论：原标签、证据支持、无法判定分开

旧分类中 F5「迭代自纠缺失」只有 **1 条正式案例**。该案例所引用的 `completion.complete=true` 来自 **trusted runner 的测试遍历完成回执**，不是 agent 说“所有题已做对”。它可与 15 项测试、3 项失败、退出码 1 同时成立。因此分层记为：**旧标签 1；本项证据支持的 agent 虚假全局终答 0；原 F5 归因证据不足 1**。这不是把产品全部历史虚报率判成 0，也不修改原始分类记录或成绩。

正式轨迹实际上出现了诊断和成功编辑回包，只是未观察到之后的复测与全局终答；更窄的表述是“**已尝试修补，闭环未观测到**”，不能写成“完全没有自纠”。另一个特意选取的旧 r1 轨迹呈现完整修补闭环，说明解析器能识别正控制，而不是只会找失败。

## 2. 证据层与覆盖缺口

[派生事件表](<events.json>) 记录来源摘要、原始记录行号、主体、调用/回包顺序和版本摘要，不发布原始私有轨迹、工具调用标识或工作区路径。正式轨迹全读并解析 **65 条**（23 assistant、42 tool），正控制 **78 条**（29 assistant、49 tool），现有 42/49 个调用与回包均一一配齐。

“全读”仅指这两份已保存导出文件的全部记录：**两者均无 user/system 记录，也无逐条时间戳**。因此不能补出完整模型输入、后台上下文、精确耗时或缺失尾部的原因。此前 Zipper 的局部“全绿”和创建任务时的未来成功目标，都不算 pov 的全局完成终答。终答的语义范围经全文人工判读并留行号/摘要；解析器本身只识别位置与主体，不是通用自然语言真假分类器。

字段来源静态链：runner 第 53 行调用测试套件，第 55 行写 `complete=True`；checker 第 168–191 行读取 runner 回执、复制完成字段，并额外要求退出码、计数、身份与失败数等条件才判通过。runner 当前字节 SHA 与冻结配置所列值相同，checker 当前字节 SHA 与正式评分收据所列值相同；均只做静态解析，没有执行旧 runner/checker。

## 3. 两条反馈修补链

| 案例 | 可见本地 pov 反馈 → 修补 → 复测 | 可见终态 |
|---|---|---|
| 正式案例 | 行 60→61：15 项、10 失败；行 62→63：微型诊断；行 64：父子包裹方向诊断与 Edit；行 65：成功回包 | 文件到此结束：没有编辑后 pov 复测，也没有 agent 全局终答 |
| 旧 r1 正控制 | 行 63→64：5 失败；行 65→66：诊断；67→68：方向修补；69→70：2 失败；71→72：链构造顺序修补；73→74：15 项通过 | 行 75→77 六题逐项汇总显示 OK；行 78 明确全局成功终答 |

两个案例均可见“方向诊断→改动”的同类修补意图，不能据此宣称改动的独立因果效应。r1 的 5→2→0 来自同一可见本地命令；日志内未见测试文件改写，但这仍是历史工具回包，不是本次重新执行或完整运行时安全证明。六题汇总用了 `tail` 管道，外层 exit=0 **单独不足以证明成功**，这里同时保留每题显示的测试数与 OK；最后一次独立 pov 命令也显示 15 项通过。

正式案例的“本地 10 失败”与历史外部评分的“3 失败”不被视为同一套件下的干预前后差，不估算修补效果，也不推断模型、Harness、进程、网络或用户导致了尾部缺失。

但 **当前工件相同，不等于原评分时工件已经认证**。已检视的正式冻结事件 9 项来源没有提交解答的逐文件 hash；冻结配置中的 pov hash 是运行前输入桩，不是提交解答。r1 有独立执行收据的摘要标识和初始 size/mtime 元数据，但检视源未提供该收据正文与评分解答逐文件绑定。两案原评分解答版本均保持 **unknown**；仅限本次列明的检视范围，不声称所有私档都不存在相关证据。

## 5. 复算能力与报告影响

```sh
python3 -B verify.py
python3 -B -O verify.py
```

[验证器](<verify.py>) 校验冻结派生表的字节摘要、事实层次、计数与顺序，再运行 **52 项自有合成边界测试**；[解析与回放原语](<core.py>) 和[测试](<test_core.py>) 均不执行历史实现。公开入口只能检验派生表自洽及原语边界，**不能在缺少私有原始轨迹时认证其真实性或独立重建历史解答**。私有全量解析、编辑回放和原文件比对由另一路审阅，不以公开 PASS 替代。

这是探索后透明锁定问题与范围的事后重分析，不是盲预注册、新产品运行或新的重复样本。两案为目的性选择：一个旧 F5 单例、一个已有成功正控制，不估计产品频率、普遍能力或因果优势。当前主报告未直接断言 F5 数量；本项适合补充字段主体和反馈闭环边界，并给旧分类学增加后续重解释指针，**不推翻其正式 83.33 分、历史正控制报告的 100 分或正式 25 格**。以上分数保留为历史记录，不由当前文件摘要补认证。
