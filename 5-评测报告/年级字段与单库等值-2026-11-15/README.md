# 年级字段与单库等值：q83 的条件辨识

**结论（事后离线分析）**：正式批的 Codex、DSH 两个答案都按 `GSserved = 'K-8'` 筛选，而现有 gold 使用 `GSoffered = 'K-8'`；两场公开判分记录均显示该题匹配、一行通过。对公开 canonical 库的成员级复核显示，其他筛选条件全部生效后，两种字段各选中同一所学校，双向差集均为零。这个实例上的相等既不能证明两个筛选在所有数据库上等价，也不能证明题目唯一要求哪一个字段：中文操作题面只说 K–8，没有指定这两列。**不据此改判任何场次、gold 或产品能力。**

## 反例与边界

一个**自造、仅内存、未声称真实存在或业务合法**的字段分叉例：满足其余条件的学校 offered 为 K–12、served 为 K–8，则两筛选的命中不同；反向使用 offered 为 K–8、served 为 1–8 亦可。它们满足 schema 的文本类型，但尚未建立历史业务跨字段约束，不能据此估计真实发生率或回填历史分。该反例只证明在所假设输入空间中谓词可区分；如果合同没有指定字段，也不能把另一种选择一概判错。

早期[语义复核](../复算/2026-10-24/bird-semantic-review/independent-review.md)已指出单库执行等价不等于逻辑等价，既有 DSH 轨迹也已比较过本题多个字段：r1028 已记下目标条件只剩同一所学校，r1109 也报告相同的城市聚合；本次增量仅是绑定两个正式 A 场、核查外围分母及双向集合，并给出条件性合成反例，不声称首次发现一般原理或这所目标学校。后续若要测试判据覆盖，应先冻结明确的字段合同和可接受的数据约束，再另设多样且对称的反例、空值及同城抵消，不改旧成绩。
