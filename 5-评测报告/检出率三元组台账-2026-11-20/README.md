| 豆包办公 × 摘要 × 同上 | 3/10 = 30% | [10.8%, 60.3%] | 10/10 | 0 |

登记规则与已知解读：

- **三元组缺一不可比。**同产品同提示词换采样根可从 0% 翻到 40%（WB 内容臂），
  同产品换提示词可双向翻转（Codex 内容 80% ↔ 摘要 0%；DSH 内容 30% ↔ 摘要
  65%；WB 内容 40% ↔ 摘要 50%）。统一律：可检性由所选读实现的 FD 持有时长
  决定；检出信号是持有时长的仪器量，不是内容获取的语义量。
- Codex 摘要 0% vs 同产品内容 80%：区间不重叠（Fisher 双侧 p≈0.025），唯一
  变量=提示词——「提示词≠读取实现」在产品内成立。
- 豆包两跑答案层滑移（hex 报错但对象引用可证读目标）按「未读自述／滑移不可
  分辨」分账，不计入检出，也不虚填真值。
- 采样节奏与采样根一并登记：同仪器放宽 roots（全进程扫描）会把 pass 周期从
  ~0.9 ms 拉到 ~12 ms，亚 12 ms 持有可整体逃逸——检出率是「产品×提示词×
  采样根×采样节奏」的函数，比较时四维须对齐。

## 同对象同窗读取配对（真实阳性/阴性准入）

- **DSH（2026-11-20，经独审更正）**：同一 512B 夹具、同窗串行、双采样器
  （进程闭包账 + 全进程账）。P 臂（真实读取；真值=答案含预登记 offset 字节）
  5/5 真值成立；N 臂（仅 `exec 3<` 打开持有 2s、禁读禁猜）5/5 真值成立
  （答案仅退出码）。**按采样闭包归属：模型子树口径 P 1/5 vs N 5/5**
  （Fisher 双侧 p≈0.048，阴性臂点估计反更高）——真读的短持有（bash 工具链，
  亚采样周期）大多逃过检测，仅开的 2 秒持有全检出；并集口径 4/5 中 3 次为
  系统索引器（Spotlight 类）噪声，已按归属剔除。**FD 持有检出的二值判定
  不区分（甚至反向于）「真实读取」与「仅打开不读」——检出信号由持有时长
  决定，与读取语义无关**，该律由机制推断升级为受控测量。方法学登记：检出
  主张必须按采样闭包归属分账，无闭包约束的全进程检测面会被第三方系统进程
  污染，只能作「某进程曾持有」的存在性陈述；DSH read 工具对二进制内容拒读，
  本环实际测得面为 bash 工具链持有检测（如实声明）。命中计数层（N 臂 ~3850
  vs P 臂 0–1）与持有时长一致，但不作读取召回解释；读取检测面维持「在当前
  检测面未观察到」表述（规范反目标的配对直接支持）。
- **WB（2026-11-20，经独审判 FAIL 后整改重发）**：同设计换 WorkBuddy
  桌面端（Electron 主进程 + sandbox-center 闭包账 + 全进程双采样）。首轮
  序列因 runner 臂映射缺陷，阳性提示词从未发射（独审逐跑证实十跑全为阴性
  形态），首轮报告作废；整改加入「臂↔提示词哈希交叉校验」后重发 P 臂。
  更正后：P 臂（真读）5/5 真值成立、检出 4/5 [37.6%, 96.4%]（Electron
  主进程亚 2ms 短持有，单次采样 pass 偶然捕获，概率性）；N 臂（仅开 2s）
  10/10 真值成立、检出 10/10 [72.3%, 100%]；Fisher 双侧 p=0.333，区间
  重叠——**判据层面「FD 有无不区分实读与仅开」在 WB 同样成立，方向
  P<N 与持有时长律一致**。修正早先「WB 应用内读=秒级长持有」的失实
  推断：实测为亚 2ms 概率性检出（4/5 中 1 跑读持有未落任何采样 pass）。
  方法学固化：阳性/阴性配对的发射必须带臂↔提示词哈希交叉校验，防止
  「跑了但跑错臂」类缺陷逃过完成信号。
- **Codex CLI（2026-11-20）**：同设计换 Codex CLI（自身进程树闭包账 +
  全进程双采样）。P 臂 5/5 真值成立（读命令=单次短读 shell 工具链）、
  检出 **0/5** [0%, 23.9%]；N 臂 5/5 真值成立（仅退出码）、检出 5/5
  [56.6%, 100%]；Fisher 双侧 p≈0.008——**显著反向**：真读整体低于 1ms
  采样地板，仅开 2s 持有全检出。与昨日 Codex 内容臂 80%（8/10）的张力
  如实登记为开放问题：两环提示词/命令形态/采样配置存在差异，本环仅主张
  本三元组下 0/5，不外推「Codex 内容读恒不可检」；「同产品检出率随提示词
  换读取实现大幅变动」本身再次支持三元组登记律。
- **三产品合观**：真读检出 DSH 1/5（模型子树口径）、WB 4/5（概率性）、
  Codex 0/5；仅开 2s 持有 DSH 5/5、WB 10/10、Codex 5/5 全检出。A 组三款
  产品的配对共同支持：**FD 持有检出二值判定不区分读取语义，检出概率由
  持有时长决定**；「按检出推断读取发生与否」不成立，读取检测面维持
  「在当前检测面未观察到」表述，不折算召回率或污染上界。
