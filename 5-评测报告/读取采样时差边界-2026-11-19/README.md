# 读取对照：完整采样包络可容忍的固定时差

**已知同窗，不是采样开始落在窗里就够。** 用四份既有非产品派生包重算：如果采集钟相对各臂的共同时间基准有一个未知但固定的偏移，四项原有合格观察的几何支持各有明确余量；原短窗的包络比可用窗长 **2.130 ms**，即使只看几何、允许任意平移，仍不能装入。原短窗的独立配对和采样健康也各自不合格，继续为 `unknown`。

## 固定反事实

原试验用共同单调钟。这里每次只给该试次的整个采集包络加同一个整数纳秒 `δ`；间隙对照的两次包络也同移，所有 worker 标记保持原值。`δ` 是**加到采集标记以投到 worker 时间轴的校正**，不是实测时钟差。只比较表中时窗几何，不重新执行旧时相、健康、对象绑定或读取真值准入；不容许移动一个端点、缩短命令，亦不假定不同试次共用绝对原点。若时差不可估，不知道它是否落在区间内；不能直接给有效结论。

| 原观察 | 约束采用的端点 | 可支持几何的 `δ` 闭区间（ns） | 含零对称余量（ms，约值） |
| --- | --- | ---: | ---: |
| [同窗长对照](<../同对象同窗读取检测校准-2026-11-19/README.md>) | 最晚动作后 `fstat` 与计划持有或实际关闭较早者；含两端 | `[-90017000, 507557000]` | 90.017 |
| [同窗短对照](<../同对象同窗读取检测校准-2026-11-19/README.md>) | 同一几何规则；6.821 ms 可用窗、8.951 ms 命令包络 | 下界 `-2283000` 大于上界 `-4413000`，空区间 | — |

计算例：要让 `[s,e]+δ` 严格在 `(a,b)` 内，整数下界为 `a−s+1`、上界为 `b−e−1`；对多条约束取最大下界与最小上界。间隙的见证窗这里保守要求严格在内，历史见证内部允许等号；见证端没有成为本结果的约束，最终区间不受该差异影响。所有非空区间都含 0；端点再向外 1 ns 就不再满足至少一条几何约束。具体到这批记录，长、短对照均由仅打开臂的动作后 `fstat` 决定左界，计划持有截止（比实际关闭早）决定右界；偏移对照由 D 臂动作结束决定左界，共同持有已确认时刻不是生效的左界。公共时钟原点一致偏移对这些差值没有影响。
