# A 轨权重敏感性：三组历史同标签未反转，固定正式格改权重可反转

对 Codex 与 DSH 的五个任务做历史复算。**保持原来的五任务等权，三个同标签差值依次为正、零、正，没有出现 DSH 领先。保持正式 r1 的十格不变、只改变两产品共同使用的任务权重，则可以翻转。** 前者比较既有重复标签，后者改变汇总公式；不是同一种证据。不新增实测，不改正式分数。

## 1. 固定等权：同标签与任意配对分开

逐格从公开矩阵读取通过数和分母，先用精确分数算通过比例，再以同一权重相加。五任务顺序为 Bird、Dabstep、Exercism、LCB、Cargo，分母依次为 15、10、6、4、27。r1 的 10 行与 A v2 正式名单完全对应；r2、r3 的 20 行仅作描述性对照，不回填正式 A 轨。下文差值均为 Codex 减 DSH。历史口径是五个 0–100 子分的和（满分 500）；归一化均分是该和除以 5，差值用百分点表示。

| 公开重复标签 | 历史总分差：精确值（显示到小数点后两位） | 归一化均分差：精确百分点 | 已记录二元计数：Codex / DSH |
|---|---:|---:|---:|
| r1（正式） | +20/27（+0.74） | +4/27 | 3/5、3/5 |
| r2 | 0（0.00） | 0 | 3/5、3/5 |
| r3 | +470/27（+17.41） | +94/27 | 4/5、3/5 |

r2 的五个逐任务比例均精确相同，不是四舍五入造成的并列。三条同标签差值从大到小为 r3、r1、r2。在本数据上，两种取位方式都不改方向：r3 若先将两产品归一化均分取到两位再相减，差为 +3.49 百分点；若先求精确差再取位，为 +3.48 百分点。历史总分尺度上，两种方式均为 +17.41。二元计数是矩阵已记录的奖励位之和，不是加权分、不从加权分反推，也不是重新验收的判定。

若解除标签限制，把三条 Codex 总分与三条 DSH 总分任意组合，会得到以下九个**重用同六条总分**的算术差值（历史总分点；粗体为同标签）：

| Codex ＼ DSH | r1 | r2 | r3 |
|---|---:|---:|---:|
| r1 | **+20/27** | +40/9 | +20/27 |
| r2 | −100/27 | **0** | −100/27 |
| r3 | +470/27 | +190/9 | **+470/27** |

任意配对区间为 [−100/27, +190/9]；两个负值均来自 Codex r2 对 DSH r1 或 r3。由此可见，两个产品的边际范围有重叠，不等于同标签出现反向。九个差值不是独立样本；即使标签相同，也不代表该对照控制了其他条件。这里不估显著性、未来翻转概率或总体排名。

## 2. 固定正式十格：只改变共同任务权重

r1 的五维比例差向量为 `d = (−1/15, 0, 0, 0, +2/27)`。若删一项、对其余四项等权，权重移动量均为 `1/5`（20 个权重百分点）；按上述任务顺序，归一化均分差为 `+50/27, +5/27, +5/27, +5/27, −5/3` 百分点。**仅删 Cargo 翻转 r1。** 同样的逐项删除在 r2 全部打平、在 r3 全部保持正值。

令 `u=(1/5,…,1/5)`，在五维非负、和为 1 的单纯形上取共同权重 `w`，用 `TV(w,u)=½ Σ|wᵢ−uᵢ|` 计移动量。把加权差写成 `g(w)=d·w`（0–1 比例尺度）。移动量为 `δ` 时，减掉的权重和加上的权重各为 `δ`，所以

`g(w) ≥ g(u) − δ(max d − min d) = 1/675 − δ·19/135`。

只把权重从差值最大的 Cargo 转给差值最小的 Bird，在 `0≤δ≤1/5` 都能达到该下界。因此 **TV=`1/95`（移动 `20/19` 个权重百分点，约 1.053）是最小打平距离，不是已经翻转**。此时权重为 `(4/19, 1/5, 1/5, 1/5, 18/95)`。严格翻转的距离下确界也是 `1/95`，但在此距离无负值；例如移动 `2/95`，归一化均分差为 `−4/27` 百分点。任意权重只用于测量对汇总设定的敏感性，不是新的官方得分、推荐权重或产品改进。

另一个取位对照：仍从 Cargo 向 Bird 移权，令 `δ=1/95−1/100000` 或 `δ=1/95+1/100000`，归一化均分差分别为 `+19/135000`、`−19/135000` 个百分点。两种取位方式都显示 `0.00`；显示为零不等于精确并列。这项边界算术可以由上式复算，不列入紧凑的机器汇总。

## 3. LCB 诊断冲突及本复算的范围

原严格复算要求各项诊断一致。六条 LCB 记录均为 4/4，已记录二元奖励为 1，阈值诊断却预期 0，因此原严格复算因冲突停止，没有产出通过严格门槛的结果。这里单独复算加权算术，并照录二元计数；不消除原冲突、不重判 LCB、不修改正式格，也不对历史验证的其他检查作通过或失败判定。

静态查看所钉的公开代码，可解释该冲突的形状：公开验证器把通过**比例**与阈值相比，在此为 `1 ≥ 2`，结果为假；公开 LCB 检查器的阈值 2 用于通过**个数**，且奖励还要求输入完整性守卫成立。`4 ≥ 2` 只满足计数这一条件。矩阵记录的历史验证器指纹与所钉公开文件不同，不能断定历史运行使用的是这份验证器代码；本复算也没有独立验证同次运行的完整性守卫。
