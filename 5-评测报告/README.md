## 本轮不可省略的边界

1. A 组为同模型标识的 Codex/DSH CLI + WorkBuddy GUI，但联网、工具、系统提示词、SKILL、权限与交互未完全同构，不能只归因 Harness。
2. B 组豆包为默认模型整栈观察，不能据其与 A 组差异排纯 Harness 强弱。
3. WB×LCB suspect 单列 excluded，不补0、不进有效分母；元宝 paused，不记失败、不虚构完成五款覆盖。
4. 结果按冻结修复版逐题报告，DAB 双轨；历史值、重复样本与 strict 首跑不混加。不用四维综合分作正式主排名。
5. CLI/GUI 的耗时、工具步数、取证便利度不能不加口径合成产品分数；并发耗时不可作速度排名。
6. n=3 只描述三个样本，不证明无噪声；同错不是模型上限；仓外工作区+软约束是组合干预。
7. 每条结论都应能追到规则、输入、配置、现场、产物及判断理由。补录当前原工作区代码不等于证明历史归档完整或当时哈希一致。
