# 固定十五对，哪些缺失证据会改变方向？

[旧裁定研究](<../裁定窗口与重复对照-2026-11-19/README.md>)已说明：不完整的比较范围不足以认定固定十五对的方向，后来公布的全表净差来自 Cargo。这里用[同一份历史公布结果和裁定](<../../3-表现现场/r1109-mech-n3/README.md>)回放另一件事：**如果先不看某些槽的分数，后来要确认多少个，才能让 DSH−Codex 的二值差在其余未知任意取 0 或 1 时仍严格为正？** 同场同重复号是配对标签，不代表随机配对或两臂等控。

## 1. 保留已经准入的单臂成绩

P0 仅按原有效状态纳入后来公布的分数；P0′ 另排除 DSH Bird 三个明确未出分的槽。两者都是用同一份后来公布的数字做的观察视图，不是当时的分数快照。下表全部是固定十五对的**净差分子**，除以 15 才是奖励率差。

| 历史视图 | 起始可行范围 | 只恢复 Cargo 的缺槽 | 严格正所需最少缺槽（可行最小集合数） | 按整场恢复的最少场 |
| --- | --- | --- | --- | --- |
| P0 | [−1, 7] | [2, 7] | 2（6 套，都含 Cargo） | 1，只有 Cargo |
| P0′ | [−4, 7] | [−1, 7] | 5（21 套，都含 Bird 和 Cargo） | 2，只有 Bird + Cargo |

区别不在于每补一条就多一票。缺失 DSH 槽恢复为 1、或缺失 Codex 槽恢复为 0，才会把下界上移一；反过来的结果只把上界下移一。用实际公布值回放，P0 的四条下界增量来自 Cargo 三条和 Exercism 一条；P0′ 另多 Bird 的三条后来判卷记录。若只要排除负差，最少分别为 1 和 4 槽；下界零还不能判正。P0′ 即使收齐除 Bird 或除 Cargo 以外的全部缺槽，下界也只到零。这里是不恢复该场的缺槽，不是把该场从十五对里删掉。补齐全部后才回到已公布的 `3/15` 确切差。

## 2. 一开始就丢掉半对，会损失已准入的单臂信息

作反事实对照：起点只保留在各自口径下两臂二值分数均可用的配对标签，其余配对暂遮住两格，再按整对恢复。P0 与 P0′ 的起始范围分别扩大到 `[−8,8]`、`[−9,9]`；只恢复 Cargo 时下界仍分别是 −2、−3；严格正需至少恢复 **6 对**或 **7 对**。其中有些是原已知但被丢掉的槽，这不是六次或七次新增判卷的成本估计。旧 7/6 个完整标签的可比均值仍原样，不拿它代替固定总分母。

## 3. 这些是回顾式充分集合，不是下一轮补证承诺

从[固定批次公布表](<../../3-表现现场/r1109-mech-n3/README.md#L13-L33>)的二值列和原裁定重建两份遮蔽表；校验后来收录的八个槽确有[逐槽复核](<../../3-表现现场/r1109-mech-n3/reviews/lead-integrity-review.json>)，另外三处明确未出分只作后来分数，不能凭 `valid` 当成运行时成绩。对未恢复的 DSH 槽取 0、Codex 槽取 1 即达最不利下界，反着取达上界；在这些固定记录上枚举恢复的子集。把所有未知同时取为最不利值，可让任何恢复顺序都不升下界。故上面的套数不表示选中某个缺槽就保证有利，也不表示概率、稳定排名或 Harness 效应。未新增运行、未执行判卷，历史裁定、正式 25 格和旧评分均不变。
