## 五段解释

### 1. 观察：哪些条件确实有记录、哪些不同

- 30 次尝试含 25 个正式标签、5 个作废父场。正式仍为 A10 / B10 / W5、每产品×用例 n=1；六代正式数量为 10 / 8 / 1 / 1 / 2 / 3。分数及 3/5、2/5 等结论从已有闭合入口读取并复核，不改判卷。
- A 十行记录 `deepseek-flash` / `low`，但 route/protocol 是 Codex `responses` 与 DSH `anthropic-messages`。A 五对公开 TASK 的原始字节差异只在第 1、3 行，计算使用 `read_bytes().splitlines(keepends=True)`（LF/CRLF 不归一化），不删除或归一化任何比较条款。计算后仅对第 3 行展示的 home 前缀替换为 `[HOME]`，不是原 TASK 字节，也不是提示语义归一化或请求等价证明；原 source SHA、原行定位与比较分类不变。
- 豆包 cargo 父→子：case/checker/truth SHA 相同，版本却为 2.33.7→2.34.12；实际公开 TASK 还插入工作区边界硬条款，另有路径及尾部文本差异。不能用同 case pin 抹掉这些变化。
- WB 三次替代同样保留可定位文本差异；父场公开材料是明确的 `TASK.public-derived.md`，子场是公开 `TASK.md`。可以比较这些公开字节，但其原件表示域不可直接等同。

### 2. 归因：视图能回答什么

只回答“哪些**公开记录值**相同、不同、未知或不可直接比较”。模型标签、route 声明、权限与 skills 声明都不独立认证实际后端、真实可访问范围或物理隔离。所有行的后端模型身份和实际思考预算保持未知；`low` 只归入声明 effort。封闭产品的标签不洗成已知模型，元宝及豆包 exercism 父场未披露构建号也不成为可直接比较的版本。

### 3. 排除替代解释：不能由一个相同字段推全条件相同

同 case/checker/truth 只能支持相应冻结字节一致，不能替代实际 TASK、系统提示、工具 schema、请求内容、缓存或实际 reasoning 控制。父子版本与提示可同时变化；不同协议也可能包含产品默认项差异。本视图不把替代后分数变化归因于某一条款、模型或 Harness，不合并三轨做总排名，不新增 n。

### 4. 可复核边界：固定公开锚，不是原私档认证

[复核器](<verify.py>) 在执行唯一复用的、已经审定只读的正式闭合代码**之前**校验固定 SHA-256 `661c4aa0ac48d5a80231ab05a3943a49f332d624c848e744f0d7c2ce24ef7480`，执行同一份已核字节且不写字节码缓存。该库继续从代码内固定 ledger/v1.8 锚遍历来源；不以可随篡改更新的 manifest 自封信任。新 JSON 与紧凑表都须等于重建结果，重封新输出不能放行错误。

397 个现存历史来源须匹配，5 个已知历史缺件、40 个 B 观察版本未知原样保留；正式表 15 行至少有一份计分收据无身份信封，可信分配锚不等于独立认证原件。TASK 公开派生件不能认证私档原提示；源锚也不是第三方签名。新增视图不会将历史 `incomplete/unverifiable` 改成全链封印通过。展示脱敏不修改旧公开 TASK 或其 pins，也不声称平台及历史副本的隐私已全部清除。

比较状态为 `same_recorded_value` / `different_recorded_value` / `unknown` / `not_directly_comparable`。记录值相等使用排序键的规范 JSON 表示，保留布尔/数值及嵌套类型，不用 Python 的 `True == 1` 规则；两个 null 不能成为“相同”，不同表示域不假定可直接比较。状态只修饰对应字段，不是能力等级。

### 5. 下一步：先使用视图解释，不借此增加预算

读分轨差异和替代场时先对照版本、实际 TASK 与记录控制字段；有新的授权与可辨别假设后才另作前瞻设计。当前不启动产品复测、模型调用、候选/checker/SQL/旧 runner，也不补写未知字段或回改历史成绩。

## 离线复核

在仓库根执行（也可给任意公开克隆的绝对路径）：

```sh
python3 -B 5-评测报告/控制条件差异-2026-11-05/verify.py --root .
python3 -B -O 5-评测报告/控制条件差异-2026-11-05/verify.py --root .
python3 -B 5-评测报告/控制条件差异-2026-11-05/test_verify.py
python3 -B -O 5-评测报告/控制条件差异-2026-11-05/test_verify.py
```

成功仅说明公开记录一致；stdout 含重新派生的完整 `view`。不写仓库、不自动修复或重封输出。JSON pointer 为空表示非 JSON 文件整份字节，或明确记录字段缺失的元数据根；缺失声明另附 `absent_field`，不是虚构一个可解引用的不存在指针。

当前 43 项测试（含 `True/1`、`False/0`、嵌套布尔/数值直接语义反例，以及展示脱敏与原始计算分离、缺脱敏标签/冒称原字节的负例）在普通及 `-O` 模式执行。测试分两层：生产固定锚拒绝改源/缺源/换依赖；合成夹具中仅测试代码临时禁用字节锚，另验 effort 变化、同分源调包、错误身份、删除边界文字等语义或重建差异。该绕过没有 CLI/运行时开关。输出层另拒绝模型/实际预算洗白、case pin 冒充 TASK、错误指针、遗漏差异、假等价、换父场、历史未知洗白、重复键、非有限数与自加封印。测试仅临时复制公开材料，不执行候选或判卷。
