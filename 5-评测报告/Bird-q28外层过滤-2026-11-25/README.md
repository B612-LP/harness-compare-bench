## 离线复算与近错

从仓库根目录运行：

```bash
python3 -B '5-评测报告/Bird-q28外层过滤-2026-11-25/verify.py'
python3 -B -O '5-评测报告/Bird-q28外层过滤-2026-11-25/verify.py'
python3 -B '5-评测报告/Bird-q28外层过滤-2026-11-25/test_verify.py'
python3 -B -O '5-评测报告/Bird-q28外层过滤-2026-11-25/test_verify.py'
```

[复算器](<verify.py>)以仓库相对路径和内置完整 SHA-256 绑定 11 个公开输入：题面、参考答案、truth、数据库、checker 与三槽答案和三槽判卷输出；读取前后均复核，输入缺失、错绑或数据库旁存在 WAL/SHM/journal 即拒绝。数据库以 `mode=ro&immutable=1` 打开、设置并回读 `query_only`，仅执行研究者编写的固定 SELECT；不执行归档 SQL 或 checker，不写数据库，不输出学校名、键或个人明细。`immutable` 不是操作系统写锁；前后散列及 sidecar 检查也不能排除检查之间的并发改写。固定哈希只证明当前字节与声明一致，不认证历史来源或实际加载字节。

9,986 个连接投影的 SQLite 类型仅 `(NULL, text)` 45 行、`(text, text)` 9,941 行；复算器对这两类对齐判卷归一，不声称对 bool、bytes、NaN/Inf 等其他类型实现通用等价。此判卷归一把 SQL NULL 和字面文本 `<NULL>` 映为同一字符串，这一限制保留。测试覆盖固定结果、缺源、错误哈希、三种 sidecar、异常聚合、非支持值类型、相同行数和相同去重集合但多重集不同、NULL 与字面值冲突、不同均值改变成员、拨款 NULL 未知；合成测试不计作产品样本。

这是内部离线重建与非作者独审的有限结果，**不是老师要求的受控第三方原档核验**，不改冻结合同或历史分数。
