## 三、解释

这一负结果支持的判断是：**该冻结仪器声明的支持子集不足以接纳此次真实原生客户端续接形式，且转发前 fail-closed 实际生效。** 不能泛化为所有原生响应都不兼容，更不能说 Codex 无法正确使用工具。首请求真实上游与工具已发生，后续未完成则没有双键最终回答可检验。

既有正式25行A10+B10+W5仍逐格 n=1、旧得分与历史裁定不变；此前 DSH 六对受控仪器观察仍是原范围方向性观察，不和本次先导拼配。新前瞻守卫不追认旧v2合同已具备同样保护。本交付落实“技术门失败也保留、明确报告无有效比较”，而不是达成新的机制独立重复或整体研究完成。

## 四、未排除因素

- 固定 alias、low 和输入不等于 actual reasoning、cache、服务端最终输入已控制；Codex没有显式输出cap，DSH为1024，原生schema/工具菜单不同，不作同预算因果比较。

- WorkBuddy仅一场直接二进制启动失败（-6/0.28141秒），真实产品文件操作分母0，矩阵/率null；无法证明GUI隔离或OS审计。synthetic检测已知有hardlink/preopened-FD内容旁路。
