## 桌面隔离与检测：已测和未测

[公开工程校准](<access-calibration/calibration.public-derived.json>)为 macOS Seatbelt **19 类合成测试 × 无沙箱/有沙箱 = 38 次**，均按预设条件执行。其范围是新起的 Python helper，不是已经运行的桌面产品、其 helper、IPC、缓存或既有索引。

对 12 个“禁区内容应被阻止”的工程案例，10 个阻止、**2 个漏阻**：允许区内预先建好的硬链接，以及进沙箱前已打开并继承的文件描述符，都能读取同一合成禁区内容。直接路径、子进程、枚举、Unicode/相对路径、符号链接等案例已测不代表所有变体覆盖。该非随机异质工程样本不能估总体漏检率。

协作 trace 的读取尝试矩阵为 TP15/FN1/FP0/TN1，**静默读取可漏检**；这是协作日志，不是独立 OS 审计。OS 级审计链 **not_calibrated**，真实产品隔离 **not_verified**；全盘权限、提示词边界、判卷执行沙箱都不等同桌面产品环境隔离。

[公开清单](<access-calibration/manifest.json>)分列文件 hash/大小；[公开 schema](<access-calibration/public-manifest.schema.json>)与[私档 schema](<access-calibration/private-manifest.schema.json>)分开。schema 只提供字段约束，不替代访问控制、实际见证或签名。
