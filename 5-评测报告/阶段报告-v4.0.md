## 3. 冻结后的证据纪律

- **档案**：每项事实记录状态、值及证据定位；未知、补录与当场记录不能互换。当前版本指纹不能倒填为历史版本指纹。

## 5. 机制实验：原生内联保留预算如何改变下一次模型输入

### 观察

固定 DeepSeek 官方 `deepseek-flash`、low、同一 prompt 和唯一观测工具，只把 DSH 原生 `spill-policy.maxInlineTokens` 从12500改为512。实际完成6场、12次真实模型请求，四场大输出组成两对交错顺序，另两场为小输出负对照，六场两端观测值均回答正确。按该协议互斥字段 `input_tokens + cache_read_input_tokens + cache_creation_input_tokens` 汇总，总输入46081 tokens；不直接解释为货币成本。

| 对照 | full 第二调总输入 | bounded 第二调总输入 | 证据边界 |
|---|---:|---:|---|
| 大输出 pair1 | 19697 | 1509 | 首场 raw SSE 采集缺口，使用持久化 provider 解析流恢复 usage；首调 thinking 另有差异 |
| 大输出 pair2 | 19697 | 1492 | 两臂完整 raw SSE；归一动态 tool ID/signature 后，第二请求只有 tool_result 文本不同 |
| 小输出负对照 | 504 | 524 | 工具结果逐字一致、均不 spill；第二请求另有首调 thinking 差异，不声称 usage 完全相同 |

### 证据

[预注册](<../1-评测方案/机制实验-2026-10-29/PREREGISTRATION.md>)及其逐版技术修订在对应调用前冻结，原版脚本及首次失败不覆盖。实际请求、HTTP状态、模型名、effort、原始 usage、工具完整输出、答案与逐文件指纹在[现场](<../3-表现现场/r20261029-mechanism/>)；[分析明细](<../3-表现现场/r20261029-mechanism/analysis.json>)给出每场来源、请求差异路径与四版冻结源校验。所有首请求 JSON 完全一致。pair2 同一35767字节工具原输出，full模型可见全文；bounded模型可见1981字节的两端内容与外置路径，中段噪声不再进入下一请求。两场 large/full 的 CLI stdout 工具事件只展示8192字符前缀；完整输出依据独立工具输出文件、进程/工具记录的 hash 及实际第二请求核对，不把展示前缀当作完整工具结果。

### 解释

本实验直接操纵原生保留阈值，并在实际出站请求观察到预期中介变化（完整工具结果→spill两端/路径），不是从最终 token 数倒推原因。证据最完整的 pair2 中，第二请求除该工具结果外相同，总输入从19697降至1492，少18205（约92.4%）。因此可以支持：**在本隔离任务与版本中，该原生保留策略确实改变模型收到的工具结果，并显著降低该次调用的输入量。**

### 未排除因素与适用范围

只验证 DSH 的这一机制，不解释 Codex 与 DSH 历史总量差的全部来源，更不证明五款产品强弱。只有两对合成大输出，目标特意位于保留的两端；全部工具能力被共同限制为唯一观测工具，模型不能读取 spill 文件。这是实验人为控制，不是 DSH 原生不能恢复文件。pair1 取证降级及 thinking 差异完整保留；负对照也如实保留20 tokens的反向差异。缓存、服务端状态、随机生成及其他真实任务的质量/总成本变化仍需另行实验，6/6不外推一般能力。

### 可复现实验

公开原始请求与响应可在无网络、无登录态环境离线复算，以核对阈值、tool_result、usage、答案及冻结源。再次真实调用模型需要预装相容 DSH 和已配官方认证，必须新建批次并预先固定顺序/预算，不覆盖本次证据。既有[token 算术分解](<复算/2026-10-27/token-cause/decomposition.md>)仍只作历史假设线索，其中探索及污染批的汇总不进入正式效率比较。
