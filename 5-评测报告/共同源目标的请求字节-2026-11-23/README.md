# 按相同源覆盖比较请求字节（11-23）

同一条完整校验值不是同等源覆盖。本次复用 14 个固定组内比较的既有派生，先指定共同覆盖目标，再比较首次有合格证据的客户端主请求端点及其累计正文字节。两臂达到同一个目标，不表示完整已见覆盖集合相同。这里的「首次」限既有合格端点，前端未知不以较晚端点回填；比较共享运行，不是新运行或单变量干预。

| 比较目标 | 双臂可比 | 离线复算 |
|---|---:|---|
| 指定连续 39 B | 14/14 | 6 个内联运行都在较早端点有证据，8 个短回包运行都在较晚端点有证据。短回包侧减内联侧：完整累计请求多 6,551–61,736 B，剔除会话日志整个成员（含键与结构分隔）后多 17,297–57,550 B；主历史数组值差为 −10,324 至 +25,751 B（9 正、5 负）。 |
| 完整 16,000 B | 0/14 | 内联侧 6/6，短回包侧 0/8 获得可核完整覆盖；没有双臂都达到这个目标的比较。 |

另把两个端点的四种对照按实际主包序号组合去重，28 个点比较中，内联侧在不降低已确认源覆盖的同时、累计字节不更大且至少一项严格更好，按完整、去会话日志、主历史数组口径分别为 15/28、15/28、9/28；其余是覆盖与字节的取舍。**重复端点不是独立样本**。数字不表示实际读取范围、服务端摄入、费用或 Harness 优劣。参见[校验值与源覆盖](<../../4-打分细则/校验值与源覆盖-2026-11-23/README.md>)和[端点支持与请求字节](<../../4-打分细则/端点支持与请求字节-2026-11-23/README.md>)。
