# 旧读取对照的保守时间包络互不相交：同步同窗读法被反证

本轮（第五周）反馈要求读取检测"先构造同对象、同时间窗的真实阳性和阴性，配不上就报未知"（[验收条款](<../../反馈/2026-11-18-第五轮/验收条款-公开版.md>)）。此前[读取证据与 FD 复核](<../读取证据与FD复核-2026-11-22/README.md>)已说明判分轨迹面、不把串行两臂当同一墙钟窗；更早的[读取正例与检测支持集](<../读取正例与检测支持集-2026-11-14/README.md>)所依据的九对旧对照，一直缺一次正式的时间窗投影。本页对这批旧档案做离线投影：零新增运行、零模型/产品接触，用保守时间包络逐对检验"正负两臂是否可能处于同一读取窗口"，结论是**八个完整配对的包络全部不相交**——旧对不能继续按"同窗阳阴配对"读，只能作摘要见证与命中方向证据。

## 样本与仪器

固定作用域是 2026-11-19 的九对读取对照档案：18 个运行列（17 个配对臂＋1 个旧方案仪器史独立列，后者不充作配对）、26 个封印锚点（18 份原始采样：17 个配对臂＋1 份仪器史列采样、4 份 VERDICT、两份 verdict-rows、两份 PREREG）、112 个唯一源文件。投影器每次运行强制复验全部封印锚点，通过即锚点未变；复跑输出与发布投影逐字节相同（确定性）。三套时钟分账：墙钟采样（pass 行时戳写在扫描窗之前）、kq 相对钟（无共同零点，任务窗只用 Codex 隔离 CLI 原件里显式 UTC 的起止标记，不为 FD 行造绝对时间）、以及只并入保守并集的第二套进程钟。

外包络取保守口径：正负两臂各自"发出意图→完成读取→采样收尾"的并集；个别臂无原始收尾标记的，窗口记为未知，不补估计。逐臂命中数、pass 数、读源形态与执行记录逐格一致；独立非作者复核已对封印锚点、独立复跑、命中抽查与两对 gap 复算给出 AGREE。

- **8/8 完整配对不相交**，最小 gap 只有 68 毫秒（DSH a7/a2）——相邻采样 pass 也补不出同步；按预登记规则，可信外包络不交叠即反证"同步任务"。旧九对的判分口径收窄为：**摘要见证＋命中方向**，不再是同窗真值配对。
- **旧命中方向控制（正臂只见 a、负臂只见 b 且负臂不见 a）只成立 2/8**。分母如实：豆包 a8 的负臂从未发射；Codex 仪器史列不计入。
- 竞态：Codex 负臂 a3 有 1 条命中缺路径记录（fd 竞态；设备/结点号仍与对象 b 匹配），按竞态计数，不并入路径可证子集。
- 终答绑定 17/17：每个配对臂的终答都含本对象摘要（≥16 位）且不含对侧摘要——但见下面反例 C，终答不能单独证明读取来源。
- 拒读行：DSH 6、WorkBuddy 2、豆包 3、Codex 0（Codex 用 bash 取摘要）。读源形态：`shasum -a 256` 直读 13 条，另有 openssl、cut 前缀、cat 管道各 1 条。
- FD 命中数（a/b）：DSH a6 2/0、a8 1/0、a7 0/0、a1 0/0、a2 0/1、a3 0/1；Codex 六臂全 0/0（除 a3 负臂 0/1）；WorkBuddy 正 1/0、负 0/3；豆包全 0/0（负臂 a1 0/1）。

## 反例

- **A｜FD 命中≠读取行为**：DSH 负臂 a1 的 FD 命中全为零，却有两条已绑定的 bash 摘要读；Codex 三个正臂 FD 命中全零而各有一条绑定摘要读。FD 采样面与读取行为分离。
- **B｜命中方向可以反转**：DSH 正臂 a7 命中为 0，其负臂反而见到对象 b 一次；豆包正臂 a10 也是零命中。
- **C｜终答≠单条消息**：WorkBuddy 负臂的原生回复是分支内两条 assistant 消息按换行连接（前导语＋终答），单取终端消息不等于原生回复。
- **D｜同步配对假象**：上表 8/8 不相交本身就是这一类。

## 它不能说明什么

- 不给产品读取率、召回率或污染上界，不给风险排序；窗口配不上就维持"未观察到"，不估计。
- 不归零、不改写旧 VERDICT；本页只收窄旧对的解释口径，不否认摘要见证与命中方向证据本身。
- 豆包 a8 无读取保持窗证明，按未知分类，不补值。
- 本环的内部非作者复核不构成反馈所指的受控外部第三方核验；仪器史列不证明传感器身份。
