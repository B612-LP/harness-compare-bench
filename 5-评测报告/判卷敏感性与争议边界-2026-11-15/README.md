# 争议题判卷与阈值敏感性（2026-11-15）

> **性质**：对既有数据与两份正式收据的**事后探索性离线分析**，不是预注册实验、产品重跑或新判卷。冻结的 gold、checker、正式 25 格、历史得分与 [q2697 生效裁定](<../../4-打分细则/裁定-2026-10-26-dab-q2697.md>)均不变。该题继续退出能力归因；以下只研究评分口径和结论对假设的敏感性。

## 1. 纠正“精确字符串判分”

[11 月 11 日的复算说明](<../派生分析-q2697gold复算-20261111/README.md>)第 11、40 行把 q2697 官方兼容评分说成字符串精确匹配，**该表述错误**。实际应以生效裁定 §3.1 和 [checker](<../../2-用例/dabstep-payments-10/checker.py>) 为准：对于本题的常见 `无数字前缀:数值` 形态，提取第一个数字后比较；字母前缀/负号被忽略（若前缀本身含数字则可能先被提取），较少小数位的舍入可能令不同数字通过，随后还有数值容差。它并不检查 ACI 与符号。比如相对于 `E:13.57`，`NexPay:13.57`、`E:-13.57`、`E:13.6` 均兼容通过；严格轨有不同合同，不可混同。先前的判卷并非因此发生改变，而是对旧文字做纠偏。

## 2. 已枚举语义在兼容 scorer 下怎样？

旧复算枚举 capture 映射 3 × 多规则处理 3 × 欺诈档 3 × 三个空列表开关 2³ = **216 组**。沿用原函数与输入，将每组 A–F 的费值格式化为 `ACI:两位小数`，分别传给现行兼容 scorer：**216 × 6 = 1,296 个候选中 0 个通过**；仅 E 为 0/216，旧算法选出的最低值候选也是 0/216。E 离 13.57 最近为 16.63（差 3.06）；全部候选中最近为 F:14.49（差 0.92）。该结论是逐个调用兼容 scorer 的结果，而不是由字符串不相等推断出来的。注意 `13.60` 解析为浮点 13.6，输出格式写了两位并不保证 scorer 以两位精度比较。

这 216 组只是**明列假设空间**，不代表所有合理业务解释；沿用的计算把未匹配交易记 0，以便比较旧枚举，**不代表未匹配交易免费，也不能据此宣布 E 是完整交易集的业务最优**。生效裁定明确要求披露覆盖并禁止静默将未匹配计零后宣称最低。原 `first_by_ID` 实际取输入顺序中的第一个：本数据规则 ID 递增，故本次与最小 ID 一致，但代码未做排序。费值先舍入再选最小，216 组中有 162 组并列；代码以字母顺序选一个，不证明唯一最优。旧文根据数值巧合推断模型采用特定算法、用 11 次相同结果排除采样方差或断言确定性，均超出证据；[原裁定](<../../4-打分细则/裁定-2026-10-26-dab-q2697.md>) §8 中“全部合理组合”“穷举级”和由数值对应推断模型行为的表述亦须按本页边界收窄。这里补充证据解释、不改旧裁定的历史原文及其归因退出、分数不变的决定，也不证明金标错误或任何替代答案正确。

## 3. 正式收据的两个不同反事实

来源为 [Codex](<../../3-表现现场/r1030-formal-a1/runs/codex__dabstep-payments-10/checker.stdout.json>) 与 [DSH](<../../3-表现现场/r1030-formal-a1/runs/dsh__dabstep-payments-10/checker.stdout.json>) 的逐题收据；两场收据均记录格式门、输入完整性门为通过，原 q2697 均失败；该门状态不等于逐项认证实际输入副本，旧 checker 在未附副本时也可能通过。假设仅供数学敏感性：保留其他题原逐题标记及原门状态，阈值仍为 ≥80%。

| 产品/轨道 | 原始正确数 | 不计 q2697：比例 / 是否达阈值 | 假设 q2697 通过：比例 / 是否达阈值 |
|---|---:|---:|---:|
| Codex / 兼容 | 7/10 | 7/9，否 | 8/10，是 |
| DSH / 兼容 | 7/10 | 7/9，否 | 8/10，是 |
| Codex / 严格 | 6/10 | 6/9，否 | 7/10，否 |
| DSH / 严格 | 7/10 | 7/9，否 | 8/10，是 |

Codex 两轨相差的 q1871 是带符号数值差异；DSH 两轨逐题相同。**“不计该题”与“把该题设成通过”不是同一干预**：前者在这两场不翻转阈值判断，后者会使两条兼容轨翻转；严格轨须单独看。各轨假设独立翻转相应标记；兼容通过不蕴含严格通过，`E:13.57` 只是同时通过两种单题格式的示例，不表示已找到可用的替代 gold。移除答案行会触发原有十题格式门，因此删题列不是原 checker 可直接执行的重判。此表没有改变成绩，也不用于为该题赋予能力归因。
