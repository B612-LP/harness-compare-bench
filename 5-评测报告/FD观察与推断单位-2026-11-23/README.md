# FD 观察计数、检验单位与读取证据（11-23）

复算[旧台账](../检出率三元组台账-2026-11-20/README.md)的四组 FD 观察计数。表中 Fisher 双侧按固定边际，把概率不大于实表的所有表相加；右列是**假定**存在等臂、可交换配对时的双侧符号检验，不是原档已配对的 p 值，也不是一个更合适的替代检验。

| 档案产品 | 旧正臂/负臂 FD 命中 | Fisher（算术复算） | 假定配对时 |
| --- | --- | ---: | ---: |
| DSH | 1/5、5/5 | 1/21 | 1/8 |
| Codex | 0/5、5/5 | 1/126 | 1/16 |
| WorkBuddy | 4/5、10/10 | 1/3 | 5 对 10 不可直接配；任取五条全阳负臂的假设下为 1 |
| 豆包 | 0/5、5/5 | 1/126 | 1/16 |

三个 5 对 5 的小值在假定配对时都跨过 0.05；这**不证明**应选右列。WorkBuddy 的 252 个子集彼此重叠，不是 252 次复样。旧台账另一行写 Codex 内容 8/10、摘要 0/10 的 Fisher 约 0.025；按所写分母及同一算法精确复算为 **3/4199 ≈ 0.000714**，不能复现旧数，但不改变方向或 5% 分类。旧分母以外未经证实，不猜一个新列联表把数字凑回去。
