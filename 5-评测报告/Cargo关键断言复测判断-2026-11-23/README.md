## 下一次只回答一个问题

若相关观测口径达到本次取证要求，且另获发送授权，首选**一次元宝专家模式 × 11-05.1 Cargo**，只问「本次能否拿到身份可追的产物，并由冻结判卷器给出完整五项向量」。发前先校验实际题面及七份输入、隔离答案和判卷材料，确认原生会话→请求→回包→产物可绑定，准备独立隔离判卷。预检失败不发；发出后效果不明只对账原请求，不重发、不代补产物。拿到全向量即回答当次可判性；停在结构门或缺原生证据时，未评估项保持未知。

一次不测重复性；至少两次独立、同条件、有效的新运行才可讨论复现，仍不能直接解释旧新差异为合同或 Harness 因果。本轮只做离线验收，不预留已获准的发送名额，不回填正式 25 格，也不把 Cargo 当办公能力补测。
