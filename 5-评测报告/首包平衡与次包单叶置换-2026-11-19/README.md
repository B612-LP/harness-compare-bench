# DSH 历史六配对：首包平衡与次包单叶置换

**结论：** 2026-11-03 同一 DSH 的 6 个既有 inline／bounded 配对，首个捕获请求完整正文 **6/6 逐字节相同**。第二个请求即使只置换已绑定的工具文本，再置换两个同调用 ID，仍然各 **0/6** 能得到对臂的完整规范 JSON 值。再加上各臂首次 SSE 回包有原值证据的字段，才 **6/6** 闭合。三个配对的工具文本置换解释了**全部字节差**，但不能解释**全部值差**。这是旧请求的离线分解，不是新干预或对 Harness 效果的估计。

## 1. 问题与样本

[原批 6 个确认块](<../../3-表现现场/r20261103-input-bytes/README.md>)报告的是指定输入投影和请求字节，不能由此认定两个完整请求只差工具结果。本次固定原有 6 对／12 槽，分别检查首包完整 raw 与规范 JSON 值；再问第二包的差异是工具文本、调用身份，还是来自两臂首次响应的实际内容。与[同臂输入驻留检查](<../输入源覆盖与机制区分-2026-11-12/README.md>)分开：这次是同一块**跨臂**逐字段置换，不重新计算旧分。

## 2. 可见平衡，不是运行时控制

- 180 份固定槽位原件及辅助收据与旧的**事后**清单相符。首包每臂 1,244 B，完整 raw、完整规范值及旧选取投影均 6/6 相同。排除预定 inline cap（1,000,000 对 512）后，可重算的本地控制项 6/6 相符；12 份控制核对收据均在进程退出后记录。它们不是发射前核验，也不证明实效配置、缓存、网络、实际 reasoning 或模型端摄入相同。
- 12/12 槽把各自首次完整 SSE 的调用 ID、工具名及参数与次包中的助手调用、同 ID 的工具结果和本地成功执行记录关联。采集到的工具结果在实际格式由 `role=user` 的 `tool_result` 承载；未改角色参与比较。本地执行记录本身不带调用 ID，不能单独充当绑定。

## 3. 判定：逐步编辑后比较完整规范值

以下为 bounded 减 inline，单位 B。`raw` 是捕获实体；规范值对严格 UTF-8 JSON 拒绝重复键，统一对象键顺序、转义与无关空白后比较，不靠大小相等判断同值。工具叶的原文本长度差为 −33,786 B，JSON 序列化贡献是 −34,181 B；两者不可混用。

| 配对 | 次包完整 raw Δ | 次包完整规范 Δ | 工具 JSON | 两个绑定 ID | 首次 SSE 证实的重放字段 |
|---|---:|---:|---:|---:|---:|
| b01 | −34,181 | −34,181 | −34,181 | 0 | 0 |
| b02 | −34,194 | −34,194 | −34,181 | +6 | −19 |
| b03 | −34,194 | −34,194 | −34,181 | +6 | −19 |
| b04 | −34,181 | −34,181 | −34,181 | 0 | 0 |
| b05 | −34,181 | −34,181 | −34,181 | 0 | 0 |
| b06 | −34,355 | −34,355 | −34,181 | +6 | −180 |

双向顺序均为：只换已绑定工具结果文本（0/6）→ 加上两个已绑定 ID（0/6）→ 再换可逐值连回各臂首次 SSE 的字段（6/6）。后者含 6 个 `signature` 和 3 个可见 `thinking` 字段；最后一步没有剩余可见正文差异。b01、b04、b05 的 SSE 字段差为 **0 B 但值不同**；完整尺寸账合上不能替代完整值闭合。反向变更各列符号反转，不改变三阶段判定。

## 4. 正反例与限制

同值重编码不改变规范值；工具结果 ID 换成同长度错误身份，绑定失败。等长非工具字段变化仍是值差。内部非作者从同一批原档独立投影后另做反例：仅改一次次包的签名值，保留工具关联和长度，无法再归给真实 SSE，归为额外非 ID 差异，而非差值零就忽略。副本未发射，也不是独立新场。

原来选择的 cap 是设计因素；次包已有独立响应差异，不能只凭首包平衡把完整结果归因于这一个变量。使用的是客户端捕获正文；不据此报 token、成本、服务端实际输入、读取真值、召回或污染上界。正式 25 格、历史计分及旧门不动。[第五周要求](<../../反馈/2026-11-18-第五轮/验收条款-公开版.md>)中的受控第三方原件核验仍未完成。

## 5. 复核入口

[公开派生数据](<evidence.json>)仅含集合、长度、计数及裁定，不含正文、签名原值、ID 或私档路径。`python3 -B verify.py --self-test` 核算表格、双向字节账和判定字段的一致性；**不能**从公开派生数据重新认证原始 SSE/工具链，也不能用旧公开脱敏副本冒充原档。内部已有两份独立原件投影，逐方向对齐阶段摘要、差异路径和结论；不等于外部复核。
