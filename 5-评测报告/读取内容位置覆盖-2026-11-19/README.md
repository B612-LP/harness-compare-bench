# Week 5 #17 §4｜读取内容交付的位置覆盖

这是一份对[第五周第 4 条验收](../../反馈/2026-11-18-第五轮/验收条款-公开版.md#必须修改与验收)的**公开派生重投影与纯合成例**，不是新实测。读取调用、句柄可见、位置变化、应用收到内容是不同证据；对象或时间配不上就不能用来判定目标对象在目标窗内的读取，不填召回率或污染上界。

## 判据

查询先固定任务、文件对象及内容版本、共同单调时钟下的动作窗 `[w0,w1)`、源位置坐标系和目标区间。只纳入正长度内容返回，要求实际内容计数/摘要的独立收条与同一次动作、对象/版本、源字节位置绑定，且**整个动作包络**在窗内（开始 `≥w0`，结束 `<w1`）。摘要相同、路径相同、FD 快照或偏移都不能替代这些绑定。无法确认对象、动作窗、位置或来源时不计入覆盖；明确错对象/窗外也不计入，但均不等价于“没有读”。

位置覆盖量是合格源区间的**并集**与目标区间的交集长度，不累加重复位置；只有覆盖目标区间才称该范围完整。部分见证不表示余下从未被读。分母不明时只保留已报告的位置。映射 view 有自己的坐标；若无独立、同一次映射世代的源对象/版本、原点与有效窗证据，不把 view 相对位置或长度当作文件范围。收条、身份、时间及映射关系的独立绑定是证据前提，不是程序凭布尔标签或 SHA 自动认定。

## 旧公开字段：分开内容动作、采集和覆盖

以下时间是**各材料内部**的相对毫秒，不跨组对齐。分子/分母为位置字节，不是请求、token 或试次。仅开、不取内容等对照是源报告中的受控动作，不从空收条倒推。

| 旧材料 | 公布的动作/位置 | FD 或 offset 对照 |
|---|---|---|
| [同对象同窗读取检测校准](../同对象同窗读取检测校准-2026-11-19/README.md) | 长窗正臂实际动作 +34.021–34.030 ms，报告 512/512 B；短窗单臂也报告返回 512 B，但旧比较配对仍未知 | 长窗 FD 采集 +125.037–142.443 ms，是后续持有窗，两臂均见同对象 FD；短窗采集 +7.462–16.413 ms 超出预定 +12 ms，且首动作前两臂条件未齐 |
| [采样间隙](../读取探针窗口空隙-2026-11-19/README.md) | +345.227–345.231 ms 内容动作，公开字段报告 `[0,512)`；无整文件分母 | 两次 FD 采集 +34.830–52.483、+626.809–651.521 ms，目标持有生命周期在两次之间；采集时点不能替代动作时点 |
| [单次偏移](../读取探针单次偏移-2026-11-19/README.md) | `pread` 和 `read` 正臂各报告 `[0,512)`/1024 B，不能相加；仅开、仅 seek 各为受控无内容动作 | `pread` 与仅开同为 offset 0，`read` 与仅 seek 同为 512；+430.116–467.734 ms 的采集在动作后 |
| [文件映射](../读取探针文件映射-2026-11-19/README.md) | +257.739–257.763 ms 复制动作，512/16384 B **仅相对于映射 view**；公开字段无文件原点、整文件分母 | +406.502–442.217 ms 两臂各见 `txt`，均无数字目标 FD；这些行不能判应用是否取得内容 |

单次偏移 A 臂的文件起点 0 来自[已公开材料明确记载的 `os.pread(fd, 512, 0)` 第三个参数](../读取探针单次偏移-2026-11-19/README.md#结论)，加上匿名数据的已报告返回长度；不是从工作者的 FD 游标或采集偏移 0 推回。`pread` 不改变该游标，二者不等价。D 臂普通 `read` 则使用报告的动作前游标与返回长度。A 的起点是固定夹具的文本来源，不是从匿名 JSON 独立取证调用参数。

[证据数据](./evidence.json)分别记录 4 份旧匿名 JSON 与 1 份已公开配套说明的路径和 SHA-256，以及 `prior_public_fields_reprojection` 内的 12 个既有臂，保留旧裁决。这里仅重投影公开字段，不访问、不重建或复审私有原档，也不补验文件号、动作包络或接收收条的原始来源。

## 本文新增：明确构造的合成反例，不是采集结果

- **计数/摘要不等于位置。** 用两个相同的 512 B 段构成 `X‖X`。读前段两次与前后段各一次，逐次、合计长度和 SHA-256 一致，但文件位置覆盖分别为 512 B 和 1024 B。
- **同内容不能救错绑。** 同字节的另一对象、同一对象但完整动作在另外一个不相交的窗，均应排除；排除的是证据，不是宣称没有发生读取。
- **零长与无操作分账。** 已绑定的零长读取收条只报告零长返回；仅有计数声明则未知。经独立控制确认的仅开才可称该受控动作无内容传递。
- **映射坐标。** 无转换证据时，view 的 `[0,512)` 不是文件的 `[0,512)`；若在构造中给定可靠原点 +512，转换后为文件 `[512,1024)`，仍不能凭此得到整文件分母。不同映射世代不合并。

## 离线复算与适用范围

[复算脚本](./verify.py)只校验上述 5 个固定公开输入文件的精确字节、重投影预定字段，并输出上述固定元组的例子；部分例子分支是定义演示，不是通用判卷器的测试覆盖。本包只验固定输入和可重复使用的元组，不为生成器、一次性迭代器或可复用库 API 提供行为保证。可在同一公开仓库的本地 checkout 从本页所在目录运行（Python 3 标准库）：

```sh
python3 -IB verify.py --repo /path/to/local/public-checkout
```

整区间位置覆盖不等于一次有序全文返回、磁盘 I/O、后续模型是否摄入或使用。未做新夹具或产品测量，不推断真实产品的读取真值，不改旧裁决、排名或正式成绩。这不是对原始日志的第三方核验。
