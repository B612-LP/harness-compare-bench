# 读取探针：文件映射与内容消费（2026-11-19）

**一个本地非产品配对中，两个进程都持有同一个普通文件的只读映射，且已关闭目标文件描述符；只有一方实际复制了 512 字节。** 同一次 `lsof` 对两方都报出同一目标的 `txt` 非数字行，没有目标数字 FD 行。这次观测能区分“有目标行”和“有目标数字 FD 行”，但不能区分两方是否消费了映射内容。`txt` 仅为本次原始行的标记，不据此定义 `txt` 的通用含义。

## 问题和对照

[同对象同窗读取校准](<../同对象同窗读取检测校准-2026-11-19/README.md>) 的合格长窗对在采样中持有目标 FD；[采样空隙反例](<../读取探针窗口空隙-2026-11-19/README.md>) 的目标生命周期在采样包络之外；[单次偏移反例](<../读取探针单次偏移-2026-11-19/README.md>) 则对比采样内仍有数字 FD 的情形。这里新看的是：**同窗、同一对象仍有有效映射，但已无目标数字 FD**。不补跑先前短窗未知，也不改判任何既有结果。

事前锁定一个试次。两位自有非 root 进程各自对同一普通文件建立一页只读映射（本次 16 KiB），随后显式关闭各自的原目标 FD。映射后、动作后、解除映射前分别核对自身 FD 表以及已知地址的区域元数据：原 FD 已关闭、没有多出目标数字 FD，区域地址、页长、只读权限和文件偏移吻合，区域返回的文件设备号／inode 和最初目标一致。映射由单独的自身元数据核查，不由 `lsof` 标签推断。另一独立普通文件的 FD 全程保留，作为每个进程的采样见证，不承担内容真值。

两个进程都有同一 `CLOCK_MONOTONIC` 原点和预定相位。阳性把映射前 512 字节复制到缓冲区，并对实际缓冲区计算 SHA-256；阴性建立并保留映射，但不触碰目标内容。两方动作区间分别为 `+257.739–257.763 ms` 和 `+257.557–257.557 ms`（后者两个时间戳是同一时钟刻度，不表示数学上的零耗时）。阳性读出 512 字节，SHA-256 为 `110009dcee21620b166f3abfecb5eff7a873be729d1c2d53822e7acc5f34eb9b`；阴性没有内容操作、字节或摘要。这个对照是**应用层是否实际获得目标内容**，不测读 syscall、缺页、预取或磁盘 I/O。

## 唯一实际观测

- 两臂首次映射自查结束与解除映射前标记所界定的共同窗为 `+104.659–904.282 ms`；采样准入采用更保守的上限 `+904.244 ms`（任一臂最早开始最终自查的时点）。收齐两边动作后，限定两个自有进程和两份夹具的一次 `lsof` 完整包络为 `+406.502–442.217 ms`，严格位于两边动作及确认之后、上述保守上限之前；不把不同进程的返回行当作同一个精确瞬间。
- 采集退出 0、stderr 空；两个进程各有一条精确见证行、零条目标数字 FD 行、各一条精确目标 `txt` 行。同对象绑定用类型、设备号及 inode，不用文件名判断。两位进程和一个采集直接子进程均已回收，两份夹具删除，没有重跑。
- 预定准入是两臂映射、内容、身份、时钟和完整采集包络都合格；不健康、绑定不明或覆盖不足就报未知。特别是按两个文件精确筛选时，找不到一个搜索项可能导致 `lsof` 非零退出；即使有见证也不能把非零退出改称“健康零目标”。这一分支在本次未发生。

## 可复核范围

[evidence.json](<evidence.json>) 是最小安全派生，不包含原始地址、文件路径、设备号、inode、进程号或完整轨迹。`python3 -B verify.py --self-test` 复算可见时间、内容摘要预期、派生标记和反例规则；只校验派生，哈希承诺不证明未公开的原件或预先登记时间，原始绑定需在受控范围从原件复核。离线反例不计入这一个物理试次。

仅说明这一次本地普通夹具中，**同样的目标非数字行会和不同的内容行为同时成立**。不外推所有映射、其他选择开关或传感器，不把仅映射称为应用读取，也不据此断言真实产品是否读、是否隔离，或估计 FN、召回率、污染概率／上界。正式评测不调整。
