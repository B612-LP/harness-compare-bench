## 同对象同窗读取配对矩阵（四产品 × n=3）

每产品 3 对（P 臂=真实读取并抄录真值；N 臂=仅打开持有不读），同窗串行；
证据面分离与 FD 面登记值如下（n=3，不折算检出率）：

| 产品（环） | 证据面 P 臂 | 证据面 N 臂 | FD 面 P | FD 面 N |
|---|---|---|---|---|
| DSH CLI（R84；首证 R72） | 请求面分离 3/3（P 轮恢复轮请求含对象内容+marker；N 轮 9 请求双域零） | 同左 | 0/0/0 | 441/425/427（bash+sleep 双 pid 均分，持有≈1s（设计值）） |
| Codex CLI（R85；首证 R74→R75） | 请求面分离 3/3（恢复轮 function_call_output marker=1） | 同左（6 请求零） | 1/0/0（登记，恢复命令窗 comm 不可辨） | 990/995/987（comm=bash+sleep，覆盖 99.2–99.4%） |
| 豆包办公（R86；首证 R82/R80/R60） | 轨迹面分离 3/3（dd/xxd 读链 vs os.open；真值 hex 3/3 vs done 零泄漏） | 同左 | 0/17/0（17 hits=cat 30.4ms 读窗×登记 1ms 网格（实测中位 ≈1.66ms）重叠，登记不主张） | 1842/1813/1936（pid=python3） |

登记规则与解读：

- **证据面与检测面分账。**读取的语义证据=请求面（CLI 请求捕获）或轨迹面
  （桌面端导出轨迹）；FD 面=持有覆盖检测，与读取行为无关（见下节）。
  四产品在证据面均为 3/3 分离、在 FD 面均呈「N 全检出、P 近全逃逸」镜像，
  与 2026-11-20 台账的「检出由持有时长决定」律一致。
- **一致性强度登记：**每环 3 对全部分离的零模型概率 P(3/3|p=½)=1/8，
  四环联合 (1/8)⁴=1/4096；此为一致性登记，不作检出率主张（n=3 每臂）。
- 仪器失败逐件归档、零产品接触：R85 p-1（home 残留死端口）、R86 release
  连锁拒绝 5 件、R87 两轮 12 件（cp 源解耦前）——重发前偏差注记先于发射。

## FD 面语义收口（网格 × 覆盖）

- **零模型受控核验（R73）**：四合成读者对同一探针——持有不读 83/100 连续
  命中（P1）；EOF 后持有仍 84/100 连续命中=常规文件恒报可读，「读掉消灭
  信号」证伪（P3）；覆盖混杂（P2）与连续态不可分辨（P4）如实登记。
  统一语义=**pass 抽样网格 × fd 打开态覆盖，与读取行为无关**。
- **镜像证据链**：DSH 0/141（R72）、Codex 1/1003（R75）、豆包 2 hits/全零
  （R60 窗口放大）+1842/1813/1936 vs 0/17/0（R86）、WB 0/461（R79）+
  0/0/0 vs 437/452/932（R87）。WB 第二轮定位教训=采样根须覆盖应用主进程
  与 prewarm 池（Electron 主进程+任务时即时 fork，pgrep 模式失配即漏）。
- **pass 预算须按会话墙钟估算**：Codex 启动 fork/exec 唤醒触发 burst 自旋，
  300 pass 在命令窗前耗尽（R74 NOT_EVALUATED，不冒充 0 命中）→50000
  pass 重测（R75）。命中计数用增量口径（cum 会误计后续 pass）。
- **豆包读取工具面守卫**：256 KiB 大小上限拒绝大对象直读（R82 登记；
  与 DSH 二进制守卫 R72 同为读取工具面守卫形态）。

## 元宝（第五产品）结构性不可实施定界

零发射定界环（R83）：上传即复制（对象绑定破坏）、无本地工具轨迹、无本地
fd 面——读取配对三检测面结构性缺失；反例搜寻零命中+独审 presence 强化
（8 份 detail API 快照均无事件面）。**五产品读取配对矩阵=4+1**：四产品
受控收口+元宝结构性边界（形态变化即失效）。
