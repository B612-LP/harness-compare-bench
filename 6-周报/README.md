## 后续归档约定

- 每周六独立保存为 `YYYY-MM-DD-第N期.md`；邮件正文、标题及发送状态以当期文件为准。
- 已发送周报保留原文；后续发现错误时另列更正，不静默覆盖历史邮件。
- 新的一期必须包含本周进展、难点突破、最多三项可验收计划，并链接对应现场/规则/证据。
- 收件人以[公告原文](<../0-公告原文.md#L15-L20>)为准。只有本人确认实际发送后才记录已发及时间；本索引不自动发送邮件。
- 新候选与正式版本必须区分。本期[补充材料](<../5-评测报告/补充材料/2026-10-24/README.md>)是候选/审计附件，不覆盖正式题库、原始现场与分数。

```bash
python3 -B 6-周报/verify_archive.py --through 2026-11-07
```
