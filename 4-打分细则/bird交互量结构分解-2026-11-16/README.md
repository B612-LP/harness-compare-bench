## 2．定义（冻结，执行前写定）

- 数据源：真身归档轨迹（本批 README 记载的换回真身口径；capture 错配件不入账）+ 三槽公开 score-receipt（含 bird 判卷事故披露的 retro-judge 终值）。
- 逐轮观测：以 step/start→step/end 为一轮窗口；每轮 S4 轮字节 = 窗口内 assistant/message 与 tool/call 载荷 canonical 字节和；工具名从 tool/call 载荷 name 字段读取；轮内按事件列出（工具名+字节数，不展开内容全文）。
- 指标（逐 rep）：轮数、轮字节序列、top-5 轮占比、按工具名的字节合计表；三 rep 结构对照：tool/call 名称序列的公共前缀长度与首个分岔轮、逐名字节并排矩阵。
- 判卷对照：三 rep 的 retro 判卷终值与 S4 总量并排（只并排，不做因果断言）。

## 3．反证分支（冻结）

- **集中（H-A）**：任一 rep top-5 轮占比 >50% → 交互量由少数大参数工具调用（如整文件写/读）承载；列出这些轮的工具名与字节，并定位三 rep 字节差主要来自哪些同名/异名轮。
- **弥散（H-B）**：三 rep 均 <50% → 交互量差由多轮中等体量累积；按轮序列给出分布形状。
- **结构对照**：名称序列公共前缀长 → 分岔越早，路径自由度越大；若首分岔轮即伴随量级差，如实指出「首次分岔即分途」；若前缀长而后段重合，如实指出「后段收敛」。
- 轮数/工具名读取失败、窗口错位或判卷终值缺失 → 校验报错 exit 2。
