# 归因定责（2026-10-15 定调；2026-10-22 更新统一模型与 A/B 组口径；2026-11-03 增时点更新注记）

评测主体是 **Harness**，模型与 SKILL 是必须控制和披露的变量。本文保留 2026-10-24 时点的限制说明；例如当时“元宝暂停”不代表后续未运行。后续产品覆盖、路由可观测性和证据限制以对应批次记录及[报告索引](<../5-评测报告/README.md>)为准。即便使用相同模型标识，也不能单凭消融分数认定全部差异由 Harness 导致；工具、权限、提示、路由及其他未排除因素仍需逐项说明。

## 三层定义

| 层 | 定义 | 控制手段 |
|---|---|---|
| 模型 | 底层 LLM | A 组三款钉 **DeepSeek V4.1-Flash（`deepseek-flash`）**；B 组（元宝/豆包）模型封闭，不参与同模型排名，差异只作观察 |
| SKILL 内容 | skill 的具体提示词/资产 | **独立变量**：做"剥除 skill + 统一 skill"消融对照 |
| Harness | 加载器与执行机制 | 用控制实验和过程证据调查；消融差值不自动等于 Harness 的因果贡献 |

## 四值状态列

每次现场记录给每个观察项标四值之一，禁止含糊：
` Harness 造成 | 模型造成 | SKILL 造成 | 无法归因 `

## 本轮证据强度限制（2026-10-24）

- 同模型是必要控制，不代表工具集合、默认联网、权限、提示前缀、采样及 CLI/GUI 形态全部同构；A 组同分或同错，不能直接归因为模型能力上限。
- B 组默认模型封闭，结果只反映产品组合的本轮表现，不与 A 组混成纯 Harness 排名。元宝当前暂停，未运行不补零。
- 将工作区移出仓库并追加工作纪律属于组合干预；重跑中未观察到越界，只支持该组合下的现场观察，不证明单个因素的唯一因果或硬隔离有效。
- 三次重复仅报告本样本的达标序列、错项与波动，不能写成排除随机性或证明 Harness 导致波动。
- 已验证的 token 口径假象与尚未验证的真实编排成本原因分开。复算说明见[旧阶段报告 §5.2](../5-评测报告/阶段报告-v1.0.md#52-token-差异现象--线索--验证--未排除变量)，当前边界见[阶段二报告](../5-评测报告/阶段报告-v2.0.md)。
