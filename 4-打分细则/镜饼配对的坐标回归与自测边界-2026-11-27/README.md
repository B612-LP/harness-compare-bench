# 镜饼配对：坐标错误可以复核，自测的独立性要另判

四份 `abc388_g` 归档共享同一极值配对归约，不是四套独立算法证据。Codex 的一份早期草稿把全局窗口右端当相对距离上界，两组公开样例中有 **4 个窗口高估**；可见修订补上左端偏移，下一次样例回包本题两组均通过。这里复核历史回包和源码，不重跑归档，不产生新分数。

## 1. 共同数学条件

读[题面与样例](<../../2-用例/lcb-recent-hard-4/inputs/problems.json#L82-L111>)：在有序正数窗口中找最多的互不重用的大小配对，底部至少是顶部的两倍。若有任意 K 对，将顶部和底部分别排序为 `t_i,b_i`；尾部的 K−i 个顶部各有一个不同且 ≥`2t_i` 的底部，故 `b_i≥2t_i`。窗口中前 K 个是任意 K 个顶部的逐项下界，后 K 个是任意 K 个底部的逐项上界。于是当 `2K≤窗口长度` 时，直接配前 K 与后 K 等价且位置不重用。

对 0-based 闭窗口 `[l,r]`，设 `m=r−l+1`、`J(i)` 为全数组第一个能容纳 `A_i` 的下标（正数保证 `J(i)>i`）；定义 `D_i=J(i)−i`，无后继时数学上记 `+∞`。每个顶部 `i` 的候选底位置是 `i+m−K≤r`，因此条件为 `max(D_l,…,D_(l+K−1))≤m−K`。四实现的哨兵不同（DSH 用 `n` 作未命中下标，元宝用 `N+1`，另两份用超出有效距离的大值），都在这一合法窗口比较中拒绝无后继情形。K 增大时左侧不减、右侧下降，能二分最大 K。K=0 按空匹配处理。

| 归档 | 采用的条件 |
| --- | --- |
| [Codex](<../../3-表现现场/r20261125-five-lcb/codex/solutions/abc388_g.py#L13-L55>) | 最大 K；阈值 `right−K+1−left` |
| [DSH](<../../3-表现现场/r20261125-five-lcb/dsh/solutions/abc388_g.py#L16-L58>) | 最大 K；把同一 max 移项成为 `r≥l+K−1+mx` |
| [豆包](<../../3-表现现场/r20261125-five-lcb/doubao/solutions/abc388_g.py#L12-L58>) | 最大 K；阈值 `m−K` |
| [元宝](<../../3-表现现场/r20261125-five-lcb/yuanbao/abc388_g.py#L13-L63>) | 最小 `s=m−K`；1-based 查询 `rmq(L,R−s)≤s`，空前缀单独处理 |

## 3. 自测通过能排除什么

[Codex 自写参照](<../../3-表现现场/r20261125-five-lcb/codex/stdout-r2.jsonl#L56-L57>)用掩码递归，允许弃用一个位置或与每个可用对象尝试配对，没有预设两端极值规则。它报告本题随机检查通过，后在另一题兼容性失败；不是外部独立验证。[DSH 自写参照](<../../3-表现现场/r20261125-five-lcb/dsh/stdout-r2.jsonl#L35-L36>)虽写了 brute matching，实为枚举 K 并直接检查两端。它能与索引、RMQ、二分实现对照，但与被试共享极值假设；本题 `ok` 后的兼容错误来自另一题。[后续本题样例](<../../3-表现现场/r20261125-five-lcb/dsh/stdout-r2.jsonl#L70-L71>)不算又一次随机参照。

构造反面：把「所有 K 对都满足」误改为「任一对满足」，`[1,2,2,3]` 会假报 2 对；无重配对枚举得 1。共享变异的两个实现可以同错。这只是检验能力校准，**不声称归档用了 `any`**。
