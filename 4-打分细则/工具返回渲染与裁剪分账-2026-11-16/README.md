## 1. 问题与事后分析身份

[既有 R3 分解](<../R3不稳定来源分解-2026-11-16/README.md>) 将 exercism r1/r2 净差31,431B中的27,406B分到 function_call_output（87.20%）。这证明载体族差额，不自动证明工具执行正文更大、工具非确定性或模型实际接收更多输入。

立题前已对同5槽做有界探索：112条槽内对应，去包头body与CommandExecution.aggregated_output有93条相同、19条不同；exercism r1/r2 的payload为68,188/40,782B、body为59,641/35,849B、aggregate为68,705/77,930B，比较方向反转；完整参数跨槽对应仍为零。**这些汇总不是本页的新独立预测**，本页冻结在19条逐项转换见证与四项差额分解计算之前；后续是事后解释性分析，不把同数据重算当新增重复。

## 2. 样本单位、源链与硬验收（冻结）

范围固定：[工具下游包 verify.py 的 ARCHIVE_SOURCES](<../工具结果下游性判定-2026-11-16/verify.py>) 中5个完整SHA原件：Codex exercism r1/r2/r3、dabstep r2/r3。源映射及原R3逐型/总字节须双向硬等；任何少/重复/错源 exit 2。只读解析，不执行归档中的命令或代码。

单位是**槽内一次完整call_id对应的工具输出发生项**。联结 function_call、function_call_output 以及 CommandExecution 的唯一最终聚合事件；每个联结必须带相对源路径、完整源SHA、三方行号及输出哈希，不以跨槽call_id或位置猜配。预期112条是已知先验，仍须全分母复核；缺失/重复/非字符串正文不得静默忽略，单列unknown或fail-closed，不造body。重复槽参与旧4对的146个两侧发生项不是112个独立槽内输出，也不是146对已确认差异。

四观测面：

- P：完整 function_call_output payload 的 canonical JSON UTF-8 字节。
- O：该 payload.output 字符串直接 UTF-8 字节。
- B：严格识别以下完整前缀后余下的body；不 trim、不规范化换行/Unicode。
- A：同call_id唯一 CommandExecution.aggregated_output 字符串直接 UTF-8 字节。这是该日志字段，不称工具全部原始输出、工作量或后端摄入。

包头仅接受已知结构：`Chunk ID: <单行>\nWall time: <十进制> seconds\n`，接 `Process exited with code <有符号整数>\n` 或 `Process running with session ID <单行>\n`，可有 `Original token count: <非负整数>\n`，最后 `Output:\n`。不认识则unknown，不把整个O冒当B。工具token标签不当模型usage，不换算token/费用。

canonical固定 `json.dumps(ensure_ascii=False,sort_keys=True,separators=(',',':'),allow_nan=False)` UTF-8。原始字符串的字符索引与字节计数分开，所有相等由实字符串/字节验证，不由长度代替。

## 3. 转换分类及反证（冻结，不事后补规则追全解释）

顺序固定：

1. **EXACT**：B与A字符串逐字相同。
2. **MARKED-BOUNDARY-CROP-WITNESS**：B可选择仅去掉一个开头 `Total output lines: <非负整数>\n\n`（存在则单列为添加字节），其余恰含一个显式标记；标记仅接受 `…<非负整数> tokens truncated…` 或 `...<非负整数> tokens truncated...`。标记前全部文本必须是A的精确前缀，标记后全部文本必须是A的精确后缀，保留首尾不重叠、至少保留一个字符，且A确实删掉非空中间段。逐条保存首尾字符数/UTF8字节、删除与插入段字节/hash、显式标记格式及添加包字节。此为**字符串转换见证**，不是认证产品运行算法、token数或因果。
3. **UNEXPLAINED**：其余所有非原样情况。含标记但首尾不匹配、多标记、无删除、非边界变化或无所列标记都不能算已解释裁剪。可以另列最大不重叠公共前后缀的长度诊断，但这种恒真分解本身不是裁剪证据。

19个残差发生项的主要终点是上述精确见证分类的分母闭合与unknown数量，不预设全19可解释。若任何一条不满足，即反驳“所冻结规则解释全部”；不得暗中扩正则/删字段/替换正文来变绿。新增规则须另版本并保留旧裁定。

## 4. 四项字节恒等分解（冻结）

逐发生项/逐槽均定义：`J=P−O`（JSON/其他payload字段表示差），`H=O−B`（包头），`T=B−A`（可见转换残差），故严格有 **`P=J+H+A+T`**。T只有具备上节见证的逐项才能标记为已解释转换，否则保留unknown；不把全部T提前称“裁剪”。J也不是纯JSON转义，含payload其他字段。

主要比较固定为 exercism r1 **减** r2：`ΔP=ΔJ+ΔH+ΔA+ΔT`，并全列5槽及112条。符号不可翻转，负项/抵消/超过100%如实保留，不宣因果贡献、不以A作受控反事实。区分“表示层差支撑/反驳哪种解释”与“命令流程、环境和输入状态未等控”。
