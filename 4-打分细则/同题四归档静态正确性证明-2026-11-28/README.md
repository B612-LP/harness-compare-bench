## 题意与证明骨架

计数 x ∈ [1,M]^N 满足对每个 i 有 x_i ≤ x_{A_i}，模 998244353；约束构成泛函图（每点唯一出边 i→A_i）。

- **引理 1（合法表征）**：x 合法 ⟺ 每个环上取等，且非环节点满足 x_u ≤ x_{par(u)}。
- **引理 2（悬挂森林分解）**：非环节点按首次到达的环点归类为以环点为根的不交森林。
- **引理 3（计数公式）**：W_v(t)=Π_{c∈children(v)} P_c(t)，P_c(t)=Σ_{s≤t} W_c(s)；答案 = Π_环 Σ_{t=1}^{M} Π_{v∈环} W_v(t) mod p。

四份归档是同一公式的四种实现（Kahn 剥离×2、灰黑染色+递归、Kahn+后序计数器）；静态证明对每份归档逐行映射到引理 1–3 并核终止性与取模精确性。**主张（限定范围）**：对全部契约合法输入（1≤N,M≤2025），四归档程序终止并输出真值 mod p。不主张：运行时/超时表现、隐藏测试内容、模型或路由归属、其他题目。
