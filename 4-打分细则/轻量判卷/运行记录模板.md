### 5.1 机器可读（schema v2，2026-10-30 起新记录强制；必须与上表一致）

> 聚合/周报只认这段 JSON；与上表冲突时以 JSON 为准（同时回改上表保持一致）。
> 校验：`python3 validate_run.py <本文件>`；`--strict-evidence` 额外校验证据路径存在。示例见 `运行记录-示例.md`。
> **v2 修订（老师 2026-10-28 反馈第①条）**：运行留痕十字段成为强制——唯一 ID、题目版本、产品版本、模型、工具、权限、技能状态、运行时间、证据等级、最终裁定。每个 provenance 值必须是**实测值**或**披露值**（写明承载位置，如「产品封闭，批级 disclosure 字段」）；不允许裸写「未知」。CLI 运行填实测值；桌面封闭字段填披露值。2026-10-30 前创建的 v1 记录按 v1 校验、原样有效，不回填。

```json
{
  "schema_version": 2,
  "run_id": "<题号>-<slug>-<产品>-run<N>>",
  "case": "<题号>-<slug>>",
  "spec_version": "v0.1",
  "case_version": "<判卷合同/题目版本，如 checker 1.2-q26-frpm>",
  "product": {
    "name": "<产品名>",
    "version": "<版本；产品不披露时写 披露：<承载位置>>",
    "model_shown": "<产品界面显示的模型；未显示写 披露：<承载位置>>",
    "form": "GUI | CLI | 其他"
  },
  "provenance": {
    "model_resolved": "<实际模型 id/alias；封闭产品写 披露：closed，<证据/披露位置>>",
    "tools": "<工具开关实测清单；或 披露：<承载位置>>",
    "permissions": "<权限/联网设置实测；或 披露：<承载位置>>",
    "skills": "<技能/技能包状态实测；或 披露：<承载位置>>",
    "started_at": "<ISO 8601 开始时间>",
    "duration_s": "<数值，秒>"
  },
  "evidence_grade": "<如 original-contemporaneous-full / derived；等级定义见运行总账 scope>",
  "status": "valid | failed | invalid | unknown",
  "verdict_basis": "<最终裁定依据，一句话并指向证据>",
  "behavior": [
    {
      "item": "交付完整性",
      "score": "<0–3 整数，或 \"N/A\">",
      "reason": "<一句话，指到具体证据；N/A 也要写原因>",
      "evidence": ["<相对本文件所在目录的路径>"]
    },
    {"item": "回传说明", "score": "N/A", "reason": "自动批跑无过程观察", "evidence": []},
    {"item": "异常/边界处理", "score": "N/A", "reason": "自动批跑无过程观察", "evidence": []}
  ],
  "unknowns": [
    {
      "item": "<未知项>",
      "impact": "<影响哪些观察项/结论>",
      "next_step": "<下一步怎么查>",
      "stop_condition": "<什么条件下停止追查并保持 unknown>"
    }
  ]
}
```

- `status`：`valid` = 条件成立且结果可判断；`failed` = 运行/环境失败；`invalid` = 条件被污染；`unknown` = 证据不足以下结论。**不允许用 0 或满分代替 unknown。**
- `score` 只允许 `0`–`3` 整数或字符串 `"N/A"`；`N/A` 必须给 reason。
- `evidence` 路径相对运行记录文件所在目录；`--strict-evidence` 下必须存在。
- `unknowns` 与第 6 节表格一一对应；没有未知写 `[]`（并说明为什么没有）。
- **v2 provenance 纪律**：`provenance.*`、`case_version`、`evidence_grade`、`verdict_basis` 十字段缺失或不合格即校验失败；值分「实测」（CLI 可测）与「披露」（桌面封闭字段，写 `披露：<承载位置>`）两类；`duration_s` 必须是非负数值。历史 v1 记录不回填。
