# abc389_g：两份终版程序为何是同一递推、两种表示

对象：[固定题面](<../../2-用例/lcb-recent-hard-4/inputs/problems.json#L117-L145>)、[Codex 终版](<../../3-表现现场/r20261125-five-lcb/codex/solutions/abc389_g.py>)、[DSH 终版](<../../3-表现现场/r20261125-five-lcb/dsh/solutions/abc389_g.py>)。此前的可见写入和自测回执能连接版本，但不回答数学递推是否贴合题目。本页只分析这两个源码的数学逻辑，未运行或编译它们，也不把两份实现当成相互独立的判卷依据。

## 1. 每张图恰计一次

按从顶点 1 出发的最短距离分层。每个非根顶点至少有一条边通向前一层；不允许跨两层的边，否则较浅顶点会提供更短路径。**同层边任意**，奇偶数量相等不等于图必须二分。反过来，前驱边保证根可达，而每步最多改变一层，故距离恰等于层号；由图恢复的有序标号层唯一，不因最短路多条重复计数。

若已用 `m` 个标号、末层 `t` 个顶点，新层选 `s` 个，标号选择系数为 `binom(N−m,s)`。令 `x` 标记边数，乘上

```text
H(t,s) = ((1+x)^t − 1)^s · (1+x)^(s(s−1)/2)
```

前一因子是每个新顶点到前层独立选取非空邻集；后一因子是新层内部任意边。根层状态 `m=t=even=1`，多项式 1。状态只需末层大小、已用标号数、累计偶层顶点数和末层奇偶；累计不下降，已超半数的状态可以剪枝。到 `m=N` 仅计 `even=N/2`，末层的两种奇偶都允许。

## 2. 同一项的两种系数

- **Codex** [转移与换基](<../../3-表现现场/r20261125-five-lcb/codex/solutions/abc389_g.py#L17-L104>)：令 `y=1+x`，在 `y` 幂基存 `Σ (-1)^(s−j) binom(s,j) y^(s(s−1)/2+t·j)`，用位移合并系数；最后用 `[x^r]y^k=binom(k,r)` 换回边数。每轮层深固定、奇偶交替。累积次数上界是已用顶点的 `binom(m,2)`，因为新增次数不超 `binom(s,2)+m·s`；存了日后互消的项也不越界。
- **DSH** [边数系数与打包](<../../3-表现现场/r20261125-five-lcb/dsh/solutions/abc389_g.py#L29-L123>)：直接把相同展开写成 `x` 系数；按已用总数递增合并同末层大小/奇偶、同偶顶点数的状态。未来不需要层深绝对值。用大整数乘法做系数卷积，乘标号选择系数，最后读取 `N−1` 至 `binom(N,2)` 的系数。

区别是**幂基与算术表示**，不是两种独立图计数机制。两者都只能支持同一数学解释，不能由此比较速度、可靠性或 Harness 因果。

## 3. 72 位槽不能只查乘法

在题面 `N≤30`、`10^8≤P≤10^9` 且 `P` 为素数的范围内，打包底数为 `2^72=4722366482869645213696`。先保证原始槽不进位，才能按掩码取位再模 `P`。

| 环节 | 每个槽的严格上界依据 | 在 `P≤10^9` 时的上界 |
| --- | --- | ---: |
| 一次卷积 | 两操作数每系数已归一，旧层尚可新增至少一顶点，最多 `binom(29,2)+1=407` 对 | `407(P−1)^2 ≤ 406999999186000000407` |
| 累加到同一目标状态 | 目标决定来源人数、奇偶和旧偶数，只有末层 `t` 可变，至多 29 来源，各贡献先归一 | `29(P−1) ≤ 28999999971` |
| 汇总最终状态 | 最多两种奇偶各 15 个末层大小，未必已归一，沿用上一行界 | `870(P−1) ≤ 869999999130` |

三者均低于底数。转移组合数的 `K` 不超 435，初始化阶乘的实际最大下标 1340，均低于 `P`，故费马逆元链成立。**仅说 `P` 是素数不够**：域外 `N=2,P=3` 的初始化会遇到零阶乘，不能用来声称对任意素数仍成立。

## 4. 对照和能改变的判断

[纯数学校准](<calibration.py>)独立做小图 BFS 枚举与有序层大小的系数卷积；`N=2,4,6` 的逐边数无模计数相等，如 `N=4` 为 `12,9,3,0`。用 Python 3.9+ 运行 `python3 -B calibration.py` 即可复算。脚本不读取或运行产品源码、轨迹命令、参考解或 checker；没有拿校准值打分。

项目内非作者复核了数学链、槽界与源码身份，并检查反面边界：若错误禁同层边，`N=4` 计数会变成 `12,3,0,0`；例如 `{12,13,24,23}` 含三角形，但从 1 出发仍是奇偶各两点。玩具小底数还表明，进位后再取模不能修复原槽。核验只支持**这两份终版在题面域的静态数学链**；不认证执行瞬间文件身份、隐藏测试、评分、时限、产品归因或外部第三方核验，不改变判卷隔离结论和正式成绩。
