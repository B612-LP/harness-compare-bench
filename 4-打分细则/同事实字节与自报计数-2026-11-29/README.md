# 同一事实首次送达：请求正文增，自报输入计数反而减

在同一批旧 DSH 捕获中，取短回包侧减内联侧：**四条旧比较边到同一校验值 E2 时，累计主请求正文字节全增，响应自报三个输入计数字段的算术和全减。** 因而不能用这组字节方向替代自报计数方向，也不能用任何一栏替代真实计费或服务端摄入。

## 同一批、同一前缀、两本账

按[旧公开逐包账](<../端点支持与请求字节-2026-11-23/evidence.json>)锁 R38 既有 6 场、23 对原请求及响应；匹配两体摘要及请求原长，先核压缩原体，再读闭合流。本页继承旧 E1、E2、E3 标签，不再认证现场事实或首发历史；**4 场主比较、2 场冒烟**，17 主包、6 标题，标题不计主账。四条 A×B 边复用了运行，不是四个独立重复，也不是新实验。

- `W`：从启动到对齐请求（含该包）的累计主请求原始正文字节。`M/R/C`：同一前缀内绑定响应的自报 `input_tokens` / `cache_read_input_tokens` / `cache_creation_input_tokens`。同一个响应首、末快照三字段均有值且相等，**每个字段只计一次**；23/23 包的 `C` 都是显式零，不当成因缺而置零。输出计数按末快照另列，不加进输入和。
- E1 是旧账指定的首次成功目标读取结果进入的主请求，E2 是同一对象的成功新绑工具结果首次携带对照所需完整校验值进入的主请求，E3 是最后**可见主请求**。6 场的 18 个运行×端点中 17 个有证；一场冒烟的目标首读失败，旧账 E1 保留未知而非填零，后来仍核到 E2。E2 同值不证明整个源文件送达或物理实读，E3 不等于独立任务终局。绑定响应的自报数在请求之后才有，不是 E2 发生前的测量。字段冲突、缺值或流不闭时，跨该缺口的累计字段未知；不拿尾包快照、标题或另一次请求补。

## 在哪个端点会翻向？

| 固定端点 | `ΔW`（B） | `Δ(M+R+C)`（自报字段和） | 四条边的方向 |
| --- | ---: | ---: | --- |
| E1 首目标结果 | −31,240…−30,220 | −8,480…−8,462 | 两账均减 |
| E2 同一校验值 | +8,033…+10,226 | −1,302…−1,272 | 字节全增，字段和全减 |
| E3 最后可见主包 | +8,033…+51,086 | −1,276…−1,272 或 +6,123…+6,127 | 字节全增；字段和两减两增 |

E2 四条边的 `ΔM` 为 −8,214…−8,184，`ΔR` 都是 +6,912，`ΔC=0`；末快照输出计数累计差 **+114…+225**，分开报告。下表用于复算 E2 及尾端：

| 场 | E2：`W / M / R` | E3：`W / M / R` |
| --- | ---: | ---: |
| A1 | 126,423 / 9,755 / 11,264 | 同 E2 |
| A2 | 127,293 / 9,759 / 11,264 | 同 E2 |
| B1 | 135,326 / 1,571 / 18,176 | 同 E2 |
| B2 | 136,649 / 1,545 / 18,176 | 177,509 / 1,802 / 25,344 |

E3 两条翻正边**都复用同一次 B2**，仅该场在 E2 后多一个主包（+40,860 B；该包自报 M=257、R=7,168）。把这包提前算进 E2 就会误报两条 E2 边的输入和为正；其新结果只有计数，旧历史仍含校验值，不是首次送达。

另作一个不带实际单价的算术敏感性问题：同一权重 `0≤w≤1` 下 `ΔM+w·ΔR` 符号怎样？E2 四条全域为负；E3 的 B1 两条也全负，B2 与 A1、A2 的比较分别在 `w=723/1280`、`7957/14080` 恰为零，各自在零点下负、上正。`w` 不是估出来的缓存折扣、命中概率或费用，公式也不含输出或其它收费项。

## 结论边界

这是固定旧原档的两种**观测**，不是缓存干预或计费审计。哪怕 E2 已对齐，包历史差异、缓存状态、服务端 token 化及实际计算仍未等控；保留请求字节、自报分量、是否回流和独立终局各自的证据，不能只选方向方便的一栏。[字节载体](<../外溢请求的载体与事实共现-2026-11-29/README.md>)另有原体分账；[M1 后继备稿](<../外溢单变量实验后继备稿-2026-11-29/README.md>)仍未注册或发射。固定旧双体与累计分量由项目内非作者独立复算，不是外部第三方核验；旧冻结、观察门和正式成绩不动。
