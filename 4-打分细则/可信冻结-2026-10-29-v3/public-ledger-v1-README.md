# 活动台账公开投影 v1（2026-10-30）

这是从旧活动台账历史快照提取的类别计数，不是新的活动台账、正式比较表或产品运行证据；旧账原字节保存在仓外私档，不在公开仓库。旧 JSON 收据与冻结锁未重写。原账 22 条；旧对账收据所称 21 条是登记最后事件之前的时点，两者不能混为同一快照。

[公开投影](<public-ledger-summary-v1.json>)只含分账类别及计数，不公开内部执行信息。[公开验证器](<verify-public-ledger-v1.py>)只验证投影的结构与固定字节 SHA-256；`PUBLIC_SUMMARY_VERIFIED` 意味着公开摘要字节符合此版本，不是作者签名，也不能独立证明私有原件的存在、真实性、完整性或摘要与原件一致。公开测试始终报告 `PRIVATE_UNAVAILABLE`、`all_originals_verified=false`；缺失或篡改摘要须失败，不作豁免。

```sh
python3 4-打分细则/可信冻结-2026-10-29-v3/verify-public-ledger-v1.py
```

原始记录已私下保全；公开摘要不能代替对原始记录的独立复核。凡需要原件才能验证的判断，公开复核状态均应列为未知，不能以豁免代替验证。

旧 [封印测试](<test_freeze.py>) 和旧 [对账工具](<ledger_reconcile.py>) 依赖公开侧已撤出的原账或私有来源，因此在公开副本不可完成历史全量对账；其原行为及封印不改，不能将失败算作全部通过。离线实测旧测试 49 项中 47 通过、1 失败、1 错误（后两项均因旧账不在公开路径）。另 `freeze.py verify` 在检查本文注记之前已因 `test_freeze.py` contract pin 漂移而失败：lock 为 `dd941b449c70e91ac438ad6aead3b3403cdae069a5ac1d247e52018832235213`，现有文件为 `3fa7197ae8bdd767ce0107f94f28de093c965a9764c3a13f3afd24c5c3f29c3e`；本次未修改该文件或锁，不能声称冻结验证通过。旧 README 的说明加注也使其 live_doc pin 与锁不符，但上述 contract 错误阻止本次 verify 报告后续漂移。摘要不代替老师要求的判卷器修前/修后代码、正例、近似错误例、独立验收与历史复算影响；这些适用的评测依据仍应各自保留和审查。
