# 响应双条目交错：判定门在合成交错全域的预注册复算

[上页](<../Responses生命周期与同源副本-2026-11-27/README.md>)固定了单响应生命周期能补的缺口。本页检验其判定门在**两条 message 条目并发交错**时的行为：同一份锁定门实现，枚举全部两条目×各 7 段的到达交错与三种索引方案，验证预注册预期逐格成立。纯合成构造，不新增产品运行，不读取判卷材料。

## 固定构造

- 两条合成条目 A（`msg_aaa`）与 B（`msg_bbb`），各 7 帧：`output_item.added`、`content_part.added`、5 个文本帧（delta×3、text.done、item done 前置的 3 阶段信封按序）；A 增量声明为 `AA0AA1`，B 为 `BB0BB1`。
- 三种索引方案各在全枚举下过门：**s1** 固定索引+快照按索引序；**s2** 固定索引+快照交换序；**s3** 首现动态重编号。每方案交错数 = C(14,7) = 3,432，共 10,296 次门调用，另加 9 次对照/探针调用。

## 预注册预期与逐格结果（全部成立）

| 方案×首现 | 3,432 交错结果 | 预期 | 成立 |
| --- | --- | --- | :---: |
| s1·A 先现 | 唯一格：1716 全过 | 恰 1716 过 | ✅ |
| s1·B 先现 | 唯一格：1716 拒，标签恰 `(ITEM_START)` | 同 | ✅ |
| s2·A 先现 | 唯一格：1716 拒，恰 `SNAPSHOT_DISAGREEMENT` | 快照错序为独立原因 | ✅ |
| s2·B 先现 | 唯一格：1716 拒，`(ITEM_START, SNAPSHOT_DISAGREEMENT)` | 同 | ✅ |
| s3·A 先现 | 1716 全过 | 全过 | ✅ |
| s3·B 先现 | 1716 全过（重编号恰 1716） | 过门但**非**回放等价：索引与终序改变 | ✅ |

5 条预注册判定 C1–C5 全部成立（C5 覆盖真阴性对照，见下）。穷举级别的事实：s1 下 B 先现的 1,716 条交错**仅**产生 `ITEM_START` 一种格子，无第三种标签；固定索引下条目到达顺序即判定结果，B 先现必拒——门忠实暴露了「两条目共享一套索引账」的语义，而非将其掩盖为随机失败。

## 对照与探针（9 项全绿）

- **P0 基线**：A 块后 B 块的规范序必须全过。
- **N1 非等 delta 交换**：拒，`TEXT_DISAGREEMENT`——门检查文本账，不只是结构。
- **N2a 外来片段移植**（B 身份 delta 插在 A 首增量后）：拒，恰 `ITEM_NOT_OPEN_OR_WRONG_ID`；门短路该帧、不入正文账，故无后续文本标签。本页冻结构造的预期按此口径；作者侧另一变体（改标真实 A 增量）会多报文本标签——同一门机制、不同构造，已在内部独审中分账登记，不隐藏。
- **N2b 自身 text.done 先到**（近似错）：拒，`TEXT_AFTER_DONE_OR_DUPLICATE`，值本身无冲突。
- **N2c 同宽快照颠倒**：拒，仅 `SNAPSHOT_DISAGREEMENT`、扩展为空——正文仍由自身身份还原，快照错序可与其隔离。
- **N3 跨条目移植**、**P-equal/P1/P1b/P3 探针**（最小 B 先现、原地对调不属 C(14,7) 且门给更强标签、重编号重映射）均与预期一致。
