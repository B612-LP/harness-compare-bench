# 工具返回字符标记见证：探索性重建 v1.0

## 1. 问题、来源与先验

[此前四面分账](../工具返回渲染与裁剪分账-2026-11-16/README.md)固定的两种 `tokens truncated` 中间式得到93 EXACT、0标记边界见证、19 UNEXPLAINED。事后格式诊断看到这19条带Warning前缀且正文含 `chars truncated` 类标记，不能将规则未命中解释为产品无标记或无裁剪。

本页为**看过上述结果后的探索性机制重建**，不是盲前确认实验。固定前已知5槽112条关系、四面总量/反序差，以及19条Warning模板；仅用首例确认下面的Warning/Total前缀和Unicode省略号标记语法，尚未计算去帧后的全19边界或数字单位一致性。规则固定后不因失败扩匹配；旧协议、旧93/0/19分支保持。

范围仍为 exercism r1/r2/r3、dabstep r2/r3 共5个Codex原槽。硬绑定前包 `evidence.json` SHA-256 `0522591d24a088d90eeff62fce7bb7dc5f23107dfc88dab287e8f44b2bc6ed79`、前冻结页 SHA-256 `d828bfb8b573d6a0f0a42cba45c522c7447c2a42566f44f2e88b137469de3eb7`；原件身份/行号/四面P/O/B/A逐条硬等。112是记录数，不是112次新增运行。复用前包只读验证器 SHA-256 `052e55c67367876ccf472024c720d118426194822501d3d1dd3afd717d6fd683` 做旧源链核对；前包结果 SHA-256 `625d67726b8e99ebd325ea45ce045083ab016033e9d16b666e2bad7ef0887abc` 亦须硬等。新边界/单位规则另实现，非作者独审不得依赖这些作者辅助函数。

## 2. 固定的严格见证规则

A为CommandExecution的 `aggregated_output` 原字符串，B为模型工具返回去掉已固定包头后的正文；两者都不是最终HTTP请求。按原顺序全112条分类：

1. **EXACT**：B与A实字节相同，F=D=0。
2. **CHAR-MARKED-BOUNDARY-WITNESS**：B须以 `Warning: truncated output (original token count: [0-9]+)\n` 开始；随后可有且仅有 `Total output lines: [0-9]+\n\n`。不trim空白、换行或其他内容。剩余正文须恰含一个 `…([0-9]+) chars truncated…`（两边均U+2026）。标记两边分别为head/tail，两者非空；head须与A前缀、tail须与A后缀逐字节相同，位置不重叠，A内确有非空删除段。否则不得算见证。
3. **UNEXPLAINED**：其他全部，报告固定原因；不支持ASCII省略号、其他警告、无警告、多个标记、非边界匹配或重叠保留，不以相似度补配。

在第2类，F为Warning+可选Total+完整marker的UTF8字节，D为A中删除区间的UTF8字节，必须逐条满足 **B=A−D+F**（这里A/B表示字节量），故旧T=B−A=F−D。保留区间与删除区间的哈希/长度及端点分列；不公开正文。标记N仅是待核标签，**不是**模型token/usage真值。

## 3. 主要终点与反证分支

主要终点为旧19 UNEXPLAINED中获得新严格边界见证的数量/19；并列全112分类，不能只挑成功项。若0则只支持观察语法、不支持边界裁剪；若部分匹配则其余仍未知；即使19全匹配，也只支持这些日志内A→B呈现关系，不推受控干预效果、长期历史或普遍算法。

删除段分列UTF8字节、Unicode码点（Python字符串长度）、UTF16单元（UTF16-LE长度/2），比较marker N是否相等。三列可能重合，不把ASCII样本算成单位判别；先报告各自匹配数和三列不同的可区分子集，不通过多数票宣布实现单位。Warning中的original-token标签不作为usage。无法区分则如实写无法区分。

副终点为原主比较exercism r1减r2：**ΔT=ΔF−ΔD**，与旧ΔP=ΔJ+ΔH+ΔA+ΔT逐项硬等。不将各槽A当相同命令/相同状态下的反事实，不把真实输出变化全归模型随机，也不把T全当token减少。

## 4. 复核、隐私与边界

公档只放原件SHA/相对定位、行号、字节/字符量、哈希、匹配布尔、区间与分类，不发正文、命令、cwd/id/time实际值。公开模式验证安全投影一致性与算术，不认证缺失私档或真实边界；原档模式核5原SHA、独立定位112关系并重建所有见证。需用独立实现、等长错内容/错首尾/重叠/多marker/错误N单位/Unicode字节与码点差/未知格式等反例验收，普通/-O一致。无产品、模型或网络调用，不改正式25格、旧分、冻结原件。
