# 缺一层证据后，哪些主张还成立（11-23）

只用三条既有链的已核派生：DSH 参数缺项、Codex 参数在场，以及只有本地记录而缺客户端捕获的一条 DSH 链。逐层撤去工具声明、客户端响应、本地事件、续请求，形成 48 条掩码行。**480 个主张格里，112 格可确认，4 格可判假，364 格不可核。** 这些是同三条链的派生格，不是 480 个样本。用「缺任意一层就全撤」会多撤 96 格；用「只要还有一层就全补」会无证补 264 格。

全链可比需要响应、本地与续请求三方都在；但只要一条仍合格的边确有参数对象或结果正文差异，就能否定相应的一致性命题，不必假称全链可比。字段确实缺失、声明确实要求该字段、以及两者目标绑定，是三个不同判断。两条有客户端捕获的固定链中，一条必填字段遗漏可确认，另一条同命题可判假。缺捕获时仍可保留独立的本地判断。

内部非作者复算通过固定矩阵及两类失效收据反例。真实异源同值原件替入未做、未核；仅验证了撤销附着资格后的派生证书裁定。不据此判断实际执行或上游行为，也不宣称完整校准或第三方验收。旧分数与双线冻结状态不改。参见 [三层联合复核](../工具调用三层联合复核-2026-11-23/README.md)和[本地工具链与请求缺口](../本地工具链与请求缺口-2026-11-23/README.md)。
