# 同次 CLI 的任务来源、题源恢复与工具结算

对[同题归档](<../../3-表现现场/r20261125-five-lcb/README.md>)增核同次持久记录，回答三件不同的事：本地哪个记录保存了任务，哪段工具输出补到题源，什么字段表示工具已经结算。两原生载体与公开显示是同次运行的多种记录，不增加产品样本。以下仅公开聚合，不附原生私档、上下文正文、实际命令或私标识。

## 同任务不等于同上下文

两 CLI 的固定原生记录均保存 2292 字节共同任务的两份副本；同一次的副本不算两次提交。DSH 可从入队、出队和任务事件绑定同一对象，队列 1→0 与保留任务并存；标题的引用只指该任务。紧接的另一 `user` 角色记录长 629 字节并显式标为运行上下文。Codex 的另一 `user` 角色记录长 1180 字节，具有五种指定成对环境标签，但该条缺少同类消息来源字段；形态不证明作者身份。两者不能仅按角色合并。原生另有系统／开发者／基础指令记录；它们不是完整上游发送正文。共同任务一致不证明真实 stdin、最终上下文相同或模型实际摄入。

## 题源实际补到哪一字节

与[旧公开覆盖](<../同题源与可见输入覆盖-2026-11-27/README.md>)分账：DSH 同身份的 8192 字节公开工具结果，是 8718 字节原生工具文字的真前缀。去编号与包装后，源正文从 7461 补到 7883 字节，实际多见 422 字节。完整 JSON 值与现存题件相同，但 7884 字节题件的最后一个 LF 只能由现存题件补证，不能单凭编号行证明原始文件有该 LF。Codex 公共和原生工具包装不同，固定唯一内容候选中的 7884 字节题源已在两边完整出现，无新增题源字节。等宽改动旧截断以后的合法值，可以保留旧可见前缀却改变完整内容；两份本地内容相同也不证明实际读取真值或服务端收到了什么。

## 结算、退出与正文是三个轴

| 固定观察 | 证据 | 不推出 |
|---|---|---|
| DSH 14 工具结果、13 对应子作业 | 14 条公开均 `completed`，原生工具错误字段均假；13 个作业结构上均完成，生产者 detail 文本另报 11 个退出 0、2 个退出 1；另一条读取无此子作业 | detail 不是结构退出字段或 OS 传感器，缺证不填 0 |
| DSH 四条已定正文故障 | 对应 detail 退出为 1、0、1、0 | 四个正文故障不是四次非零，外层完成或零退出不证明所有内部阶段成功 |
| Codex 36 个调用／回包对、35 个命令终态 | 35 个最终回包去固定包装后与对应命令输出、退出同值；29 个完成／0、5 个失败／1、1 个失败／130 | 调用回包对不等于命令终态数；字段和句柄不认证 OS 进程或真实信号 |
| Codex 唯一继续链 | 首回包报仍运行且正文为空；后续是非空控制续写，相同本地句柄后见原命令终态及续写回包 | 空首回包不等于未执行，无法据此认证操作者或退出原因 |

三项固定分析已由内部非作者回源并加反例：同文字可换队列身份，同一显示可改原生结算字段，同一局部形态可无法补终态。它们不是新运行、外部受控第三方、独立 OS 传感器或判卷；不判断四题正确性、有效权限、过程因果或 Harness 排名。旧捕获、冻结规范、正式 25 格及旧分不改。
