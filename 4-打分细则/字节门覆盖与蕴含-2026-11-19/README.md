# 观测覆盖更广，不等于字节门逻辑更强

[历史 v2.1](<../机制序列口径v2-2026-11-16/README.md#L30-L44>)的 B2 查全部输入事件，原文称“比 B1 严格强”。**如果指事件覆盖，确实更广；如果指通过关系，两个字节门互不蕴含。** 本页事后区分这两种说法，不改旧版说明、规则、判定或正式评分。旧式历史 AND 仍为 6 不通过、4 不可核；另一版本 v2.1 的 DSH 合取仍为 **4/5**。

## 1. 固定档案复算

记每槽 `x = S3 选定事件字节`，`r = 全部输入事件字节 − x`，`y = x+r`。本页从 [v2.1 固定派生](<../机制序列口径v2-2026-11-16/result.json>)中重算 5 组各 3 槽，组内跨度以 `最大值−最小值` 计算。

| DSH 组 | `x` 跨度 | `r` 跨度 | `y` 跨度 | `B1 / S1 / B2` |
| --- | ---: | ---: | ---: | --- |
| bird、exercism、LCB、Cargo（各自） | 0 B | 0 B | 0 B | 过 / 过 / 过 |
| dabstep | 956 B | 1,284 B | 2,240 B | 不过 / 不过 / 不过 |

在 dabstep，r1 比另两次的 `x` 多 956 B、`r` 多 1,284 B，两项同向，因此 `y` 多 2,240 B；r2 与 r3 在这三项字节和相同。**实际五组里 B1/B2 判定均一致，没有观察到两门一个通过另一个失败。** 以上是规范 JSON 日志字节和，不是 HTTP body、模型输入、token、费用或干预效果。

## 2. 两个方向都能反证

固定阈值 100 B。合成三槽保持相同的类型顺序和计数，给五类分配的字节数均为正整数；这是算术实例，不宣称由合法的实际事件编辑可实现，也不算产品样本。

| 合成例 | `x` | `r` | `y` | B1 / B2 |
| --- | --- | --- | --- | --- |
| 只改补集 | 300, 300, 300 | 300, 300, 401 | 600, 600, 701 | 过 / 不过 |
| 补集抵消 | 300, 300, 401 | 401, 401, 300 | 701, 701, 701 | 不过 / 过 |
| 阈值边界 | 300, 300, 300 | 300, 300, 400 | 600, 600, 700 | 过 / 过 |

`r` 每槽非负，不代表它的**组内变化**总是同向。正确的普遍约束是 `|range(y)−range(x)| ≤ range(r)`：任意两个槽的 `y` 差绝对值最多是 `x` 和 `r` 两跨度之和，反用 `x=y−r` 得另一侧。`r` 恒定时两门等价；否则不能用一门代替另一门。极值也可能移到别的槽，不能默认两边由同一对重复产生。

## 3. 对历史数字的反事实，不是修复

保持 dabstep 三个 `x` 不变，只把原 `r` 调整成仍为非负整数的三个数，则要让 `y` 跨度降至 100 B，**最小最大单槽调整量为 1,070 B**。低于 1,070 B 时，相距 2,240 B 的两端合计最多靠近 `2×1,069 B`，仍差至少 102 B。一个可行三槽目标为 `y=[35830,35730,35730]`，即 `r=[7768,8624,8624]`。这一操作只改变数学投影的 B2；B1 与序列 S1 仍不过，合取不变。没有实际修改轨迹，也不推断存在可执行干预。
