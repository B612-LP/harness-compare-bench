## 反例：有明确跳过，也可能退出 0

六种情景对 27 个「入口 × 情景」条件分别做普通和优化两档。三源未改且 Node 可用时，六入口均完成各自限定的核对。删除一整个公开源，三真实源入口拒；少一条，R1 分母拒，R2 和精确数字文件针脚拒。用不同值的第一记录替第二记录但保持行数，或在第一记录末尾加一个合法 JSON 空格，R1 仍报 235 项解析比较完成；R2、精确数字按固定源针脚拒。后者拒的是**档案字节身份**，不是声称空白改变了 JSON 值。两种操作均在隔离副本做，不是实际归档污染。

无 Node 时，旧 R1 的输出包含 `SKIP C`，却仍有 `ALL PASS` 并退出 0；不能据此说跨解析器已完成。R2、精确数字及闭包返回 `INCOMPLETE`／退出 2，两个纯 Python 合成演示不依赖 Node。

## 另起一个严格完成入口，不改旧文件

自本目录运行：

```sh
python3 -IB verify.py
python3 -IBO verify.py
python3 -B test_verify.py
```

需可信本机 Python 3.9+ 和 Node 18+（实际复算 Python 3.9.6 / Node 24.22.0）。新入口固定两个旧测量器和三份公共源，严格 LF 覆盖并重算 78/84/73 共 235 个不同标识；逐份检查 Node 输出标识集合、唯一性和 verdict，普通及 `-O` 同。缺源或缺 Node 返回 `INCOMPLETE`／2；针脚、覆盖、结果格式或比对不符则拒绝／1。成功仅说明**固定公开 R1 切片**完成，不保证执行环境没被替换，也不使旧私有分析和合成范围变成新的公开原档。11 个控制包括空、缺、额外、重复、错裁定和已知源／依赖不合格。
