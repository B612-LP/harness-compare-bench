# Codex 同档案的客户端响应、原生日志与显示字节（11-23）

在一套既有 Codex 档案内分开核对三条代理转帧后的客户端侧 Responses、原生会话 JSONL，以及按同一历史档案归类的标准输出和标准错误。三条客户端响应均封口；两条响应的末输出项为工具调用，一条为受检 assistant 文本。该终末文本为 29 B，与三处选定原生文本逐字节等值；这不判定任务成功，本次也未使用独立的第二路上游捕获交叉确认。

| 真实载体 | 观察到的关系 |
|---|---|
| 标准输出 | 全部 30 B，恰等于 29 B 文本再加单个 LF；不剥除任意空白。 |
| 标准错误 | 全部 1,027 B，不与正文等值；其中仅一条以 LF 为界的完整行与正文等值，前后分别有 25/2 条非空行。 |

本次新增的是**同档案不同真实载体**的观察，不是对另一个运行做变体干预。两条离线反例保留完整字节子串：同一行添加前缀，或在命中文本末尾的 LF 前加 CR；二者均令独占 LF 行命中从 1 变 0。把字节子串当独占行，或在核原始行前归一化 CRLF，都会错判。

标准输出/标准错误按同次归档关系归类，本次未认证共同运行时标识。不能据正文等值推整份载体相同、工具已执行、服务端输入或跨运行机制。内部非作者从固定原件独审，未完成受控第三方核验；[双线试行冻结门](../观测规范冻结门清单-2026-11-23/README.md)仍未整体通过，历史成绩和冻结基线不改。
