# 不共享运行与端点标签：两种稳健性不能合并（11-23）

在[最大互斥比较](<../不共享运行的端点比较-2026-11-23/README.md>)和[端点标签敏感性](<../请求端点标签敏感性-2026-11-23/README.md>)的同一份公开账上，用两条约束同时复算：只取最大条数、且不共享运行的比较；每个运行只给一个假设性 E2 位置，限已有 E1–E3 之间的实际主包。既有比较方向固定，不挑对自己有利的边或位置，不重判任何真正的 E2。

原标签下，48 种最大匹配各有 5 条边，每一种的 5 条原始请求正文差都为正。放宽标签后，整张比较图的**原始正文**只有一条始终为正的边，只被 **12/48** 种最大匹配选中。

若每种匹配都枚举全图 864 个共享标签赋值，共 **41,472** 个组合，原始正文有 **576** 个组合五条全负。未入选运行的位置不影响该匹配，却会重复计入。改为每种匹配只枚举其涉及的运行，共 **2,880** 个组合，原始正文有 **36** 个组合五条全负；删除会话日志成员后的正文同为 36，主历史数组则为 360。原始正文的五条合计跨越正负，范围 **−113,183 到 +249,510 B**；总和为正不等于五条各自都为正。

这里的组合计数不是独立样本或概率。它只说明两项稳健性依赖不同前提，不能把「不共享同一运行」与「端点可换」合成稳健结论。公开逐包算术不能证明替换位置就是首次携带完整校验值的业务端点；不据此改旧端点、推断产品效果或计算费用。
