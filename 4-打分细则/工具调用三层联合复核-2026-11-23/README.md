# 工具调用三层联合复核：已知的边不随整条链变未知

本次从既有原档复核两条链：DSH Chat 一条、Codex Responses 一条。逐层分别看捕获响应 W、本地事件 L、预先固定的首个主任务续请求 H（缺正文不后移）；另查发出请求的工具声明和工具结果。**DSH 三处参数各 85 B，Codex 三处各 255 B，各链内部逐字节一致。DSH 的必填命令成员在三处均缺失，Codex 的命令成员三处均存在。** 这是两条原链的内容复核，不是五产品比较或实际工具执行验证。

| 离线对照（每类两条原链，除另标者） | 应改变的判断 | 不应顺带改变的判断 |
|---|---|---|
| 在 H 参数字符串末尾加一个 ASCII 空格 | W–H / L–H 原字节变，严格对象同 | W–L、结果、声明 |
| 等长改 H 参数 / 单改 H 结果 | 前者只改变涉及 H 的参数比对；后者只改变结果 | 另一轴，以及不涉及 H 的已知等值 |
| 去掉 W 闭合 | 无法确认目标，目标各边不可核 | 固定名称的源声明 |
| 改 L 结果的来源角色（DSH）或载体类型（Codex）；或去掉 H 正文 | 分别使依赖 L 或 H 的边不可核 | 其余合格端点的边；来源声明 |
| H 内同键重复（独立反例） | 严格对象不可核，已取出的 H 原字节仍能与其他端比较 | H 的结构与结果、W–L |
| W 外层仍闭合，但改为另一个已声明工具（Responses，独立反例） | 该 W 不再是固定目标；不把原声明挂给别的调用 | 固定名称的源声明、外层可解析性 |
| 源声明改用该口径未支持的字段类型（独立反例） | 受支持的声明与依赖结论不可核 | 已绑定目标、参数成员的可见事实和结果 |
