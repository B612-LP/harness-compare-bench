# 流门联合条件：自洽仍不等于原件

把[有限物理闭合](<../SSE终态与内容完备分账-2026-11-27/README.md>)、真整数连续序号、[生命周期与副本、部件开闭](<../Responses生命周期与同源副本-2026-11-27/README.md>)一起用，能否补足任一单门的缺口？只对**一个全新合成消息、两个文字分片**做全组合；不调产品，不读取原捕获，不得据此推真实错误率。

- 内容六位：前后两片各可替换，专门 done、部件 done、条目 done、最终快照四处全文各可同步或不同步替换。
- 五个物理形态：LF、CRLF、对象开括号后分成两行 `data`、双起始 BOM、末事件少派发空行。五个结构形态：原样、删第二阶段并重编序号、删部件开并重编、序号留缺、一个序号变同数值小数。
- T 是有限物理闭合；T 拒则后面不判。Q 检零起连续真整数；M 检生命周期和规定副本；E 是**独立**的部件额外门，联合时才与 M 一起应用。比较已知基线 SHA 另计。

| 有限问题 | 1,600 格里得到什么 |
|---|---:|
| T 拒、下层不可核 | 640 |
| T/Q/M/E 全过 | 6 |
| 联合通过且与固定基线原字节相同 | 1 |
| 去掉 Q／只在其余门过时新增放行 | 12 |
| 去掉 M／只在其余门过时新增放行 | 90 |
| 去掉 E／只在其余门过时新增放行 | 42 |

六个联合过由原内容的三种物理形态与同步改内容的三种形态组成。两种重表示与三种同步改写都不等原字节，但只有后者改了正文。`T` 失败不冒充下层也失败或已通过；时间、传输、来源和结束状态均不能用这份合成表补写。

额外类型反例把同宽的 `true`、`1.00` 放在合成条目副本的扩展元数据里：普通 Python 值相等，固定[数型比较器](<../精确数字与字符串域隔离-2026-11-27/README.md>)的严格比较不同。本页门仍能放行；这只是说明此处副本判据的范围，不主张供应商接受该扩展字段。内部非作者先用不同合成器符合同一有限方程，再重构全矩阵。共用已固定测量器，非独立传感器、外部第三方或统一协议冻结。
