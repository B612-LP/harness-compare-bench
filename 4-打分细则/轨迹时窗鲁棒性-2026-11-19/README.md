# Codex 公开轨迹：唯一入围与唯一最近的时窗余量

[轨迹归属对照](<../轨迹时窗与归属-2026-11-19/README.md>)比较了 0、10、30 秒几个时窗。本页用同样 **15 条 Codex 公布记录**，找齐在整数秒模型下可行的半径。问法是：若每个公布的 `start` 可偏移任意整数 `e`（`|e|≤E`），同一窗口半径 `R` 能否对所有槽仍只包含公布参照？若允许其他候选也进窗，但要求参照严格最近呢？这不是测量真实时钟误差或识别率。

| `E`（秒） | 让每槽只入围参照的 `R` | 让每槽参照进窗且严格最近的 `R` |
|---:|---|---|
| 0 | 1–22 | ≥1 |
| 10 | 11–12 | ≥11 |
| 11 | 无 | ≥12 |
| 12 | 无 | 无 |

两种候选域的表格相同：本槽公开名单（11 条非参照边）与把 15 个参照放同池的压力对照（210 条非参照边）。最大保障分别为 **10 秒（唯一入围）和 11 秒（唯一最近）**。到 11 秒时，保住全参照的最小半径会令至少一个槽可进其他条目（本槽名单 1/15；共池 2/15），但参照仍最近；到 12 秒时，这两域分别有 1/15、2/15 个槽可能出现其他条目比参照更近。若缩窄窗口把更近条目排除，参照也进不来。实际边界的否证是严格更近而不是平局；一般平局仍按未知处理。

**复算条件。** 所有半径同为非负整数，边界入围。记 `r,n` 为参照、竞争者各距该槽 `start` 的有符号秒数。要全纳参照，`R≥max|r|+E`；要排掉所有其他候选，同时需 `R≤min|n|−E−1`（存在其他候选时）。严格最近当且仅当每对都有 `n²−r²>2E|n−r|`。这是差平方在两端取极小值的结果；同钟面两条不同记录不因此成为一条。固定公开样本实际 `max|r|=1`、`min|n|=23`。

仓库根 `python3 -IB '4-打分细则/轨迹时窗鲁棒性-2026-11-19/verify.py' --check-sibling`（也可加 `-O`）仅重算固定基线一份公开投影，[摘要](<evidence.json>)记录范围与失败槽数量。以独立枚举核对公式；没有重扫目录、打开轨迹或推断历史 `files[0]`。共池不表示历史共现，公布参照不认证历史实际归属，结论不外推其他数据或修改旧裁定。
