# 首回包缩短之后：到同值时的请求字节不一定更少

[先前的四场复核](<../首回包与累计请求字节-2026-11-22/README.md>)只覆盖一组 DSH 轨迹；本页第一组（DSH 四种设置对同一内联场）就是那四场的重算，不是另外四场。本次从三组既有 ASCII 轨迹重算，并另列不作比较的四场。共 18 个历史场景、65 份捕获正文（52 主请求、13 标题请求）、34 条已绑定的新工具结果（每条绑定含其后继回包）。比较只在各组内部做，共 14 对；部分运行被多次使用，**不是 14 次独立重复，也不是新跑批**。

## 同值，不同阶段

E1 是首次成功目标读结果进入的主请求；E2 是成功的同对象新工具结果第一次在客户端捕获的主请求里携带完整校验值——这不是整个源文件，也不等于服务端实际摄入，并排除仅历史命中；E3 是最后一条主请求。短回包历史里的旧值、重复回包、计数输出及标题请求不算首次送达。下表累计主请求原始正文，方向为起初缩短回包侧减内联侧；各组是固定的并排比较，不求产品总体或显著性。

| 组（对数） | E1 累计字节变少／变多 | E2 累计字节变多 | E2 变多范围 |
|---|---:|---:|---:|
| DSH 四种设置对同一内联场（4） | 3 / 1 | 4 / 4 | +6,551…+61,736 B |
| Codex 两个截断场 × 三个内联场（6） | 6 / 0 | 6 / 6 | +36,394…+44,513 B |
| DSH 两个外溢场 × 两个内联场（4） | 4 / 0 | 4 / 4 | +8,033…+10,226 B |

**13/14** 从 E1 负差变为 E2 正差，剩余 1 对在 E1 已为正：首次可见工具回包解码后 **3,931 B 对 16,000 B**（解码工具结果字节，不是累计原始请求正文，也不是 JSON 原语法叶），但多了一个读取前的元数据查询及其后继主请求，E1 累计反而 **+18,363 B**。按共同请求序号截得前缀为 −26,563 B，多出的请求为 44,926 B；这只是该场记账分解，不把阶段相同说成所有包严格对应。Codex 组的客户端正文没有 DSH 的 `dsh_session_log`，E2 也出现方向逆转。

按真实 JSON 成员边界从每条正文删除 `dsh_session_log` 后重算长度，E2 仍为 14/14 正差；这是离线语法投影，并非不发送该字段的对照运行。仅计各家族自己的主历史数组（`messages` / `input`），E2 则 **9 正、5 负**：投影不同，结论也不同。E2 以后可能还有新请求；例如一场回传计数时历史仍含挑战值，但那一包不是新的首次同值送达。

## 能说明什么

这些记录反驳「首次工具回包变小，累计请求正文一定变小」；也反驳「这里的反向只由 DSL 字段造成」。没有认证两臂只有一个差异，也没有校准服务端实际摄入、缓存、实际思考、token、费用或产品排名。四个非比较场（两种不同的冒烟目的、一次初读失败和一个单臂 CJK 场）不作缺失补值。原始请求/响应由内部非作者独立核对，公开仅分母和字节派生，不是受控第三方原件核验。不改正式成绩，历史裁决保持原样。

## 11-23 补充：历史数组变大，主要增加的是新项还是重复项？

仍是上文 **14 个组内 E2 比较**，不是新样本。只取这 14 场截至各自 E2 的 **37 个主请求、148 个历史数组项出现槽**。对每个数组项，按它在当前请求的重复次序匹配先前同值项：前一主请求有对应槽是「连续重复」；前包没有、但更早主请求有是「间断重现」；此前都无是「首次」。历史数组项按其在当前请求中的**原始 JSON 字面字节**计，数组的括号、分隔符和空白另算。并行使用字面字节完全相同和严格 JSON 值等同两种配法；后者忽略对象键序和等值转义，但保留数组序及数字原拼写。相同值的多个槽不合并。

| 同一批 E2 比较：短回包侧减内联侧 | 正差 | 负差 |
| --- | ---: | ---: |
| 累计原始请求正文 | 14 | 0 |
| 累计主历史数组（含数组语法） | 9 | 5 |
| 累计历史数组项的连续重复字节 | 14 | 0 |
| 累计历史数组项的首次字节 | 1 | 13 |

两种配法对这批原资料的分类一致，未见间断重现；**7/14** 个比较的连续重复字节差超过原始正文净增的一半，另外 7 个没有超过。算账时扣除两侧的连续重复项后，历史数组差只剩 1 正、13 负，但原始正文差仍为 14/14 正。前者厘清了**历史数组净差**，后者表明重复项不是**整包净差**的全部。算术扣除没有改变已发送请求，不是可实现的省流量干预。

原档由内部非作者独立逐包重算；另从历史首对的六侧做了 18 个离线对照，分别核单空格、结构改值和重复槽数。严格可比不等于原始字节不变；重复的是这个捕获点的历史项，不是服务端摄入、缓存命中或计费次数。原样结论不外推到其他日志、产品或干预，历史判定不变。
