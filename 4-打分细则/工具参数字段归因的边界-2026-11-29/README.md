# 工具参数：对象变了，不能据此定位哪个字段先变

**结论。** 在同一次工具调用的三处采样中，看到参数对象先变，不等于看到目标字段先丢。两个已绑定端点可以证明字段状态不同；缺中层时，不能据此指定哪一段变了。下文复用一个旧公开派生并枚举合成对照，不增加运行样本，不改旧裁定。

## 1. 哪些结论有证

沿用[旧三层协议](<../响应侧工具参数源头-2026-11-17/README.md#L36-L61>)：W 是捕获响应中目标调用，L 是同次本地调用，H 是最早后续主请求历史中的同一调用，对应工具结果须以同次调用 ID 绑定；标题等辅助请求不能替代 H。只有同目标绑定且参数是可严格解析的对象，才登记顶层 `command`：**A**＝没有该键，**N**＝有键但非字符串（例如 `null`），**S**＝是字符串（含空串，不等于能执行），**?**＝这一层未核。整对象、键在不在、类型、具体值和原串表示分别比较。

| 合成近错 | 能说 | 不能说 |
| --- | --- | --- |
| `SAA` 与 `SSA`，两条边的整对象均改变 | 旧分类与对象级等值关系可以相同；前者在 W–L 丢键，后者在 L–H 丢键 | 把首次对象变动当作丢键位置，或据此判定内部模块或原因 |
| `S?A` | 已绑定的两端确有差。若中间可补为同目标严格对象，丢键和退出字符串态各恰一次；`SNA` 是先退出类型再丢键 | 把未知中层补成某个实际状态，或断言两件事必在同一边 |
| `S?S` | 在上述补全模型内，三值状态变化次数只有 **0 或 2**，不是从 0 到 2 的任意整数 | 证明中层保持字符串态或各层字符串相等 |
| 两端都是 S，且目标字符串的已核值不同 | 即使 L 也是 S，L 可等于左、等于右或与二者都不同；变化可只在一边，也可在两边，类型变化仍为零 | 用整对象摘要不同代替直接核目标字段；把字段值变化等同于缺参 |

其中「一边」指两个已指定采样点之间，不是期间的编辑次数或时刻。纯字节变化也不等于对象值变化：两端原串不同、规范对象相同，且假定未知中层可补为同目标严格对象时，可能的「原串变化边数 / 规范对象变化边数」为 `(1,0)、(2,0)、(2,2)`。实际中层错绑或不可解析时，不给两条边赋次数，仍保留可证的端点差。

## 2. 旧取证实际能看到多少

27 条三态完整路径各套 8 种保留层掩码，共 216 个带重复组合，去重是 64 种观察向量。对同一设计另行调用旧纯取证流程：108 个组合判流不可核，81 个判绑定不可核（54 个先缺 H、27 个缺 L），27 个三层可用。其入口依次核 W、H、L：缺 H 时，即使提供 L 输入也不等于已绑定 L；缺 L 时已合格的 W/H 差异可保留，但不能给相邻段归因。实际只出现 40 种向量，不是 64 种均可由旧入口取到。两次独立复算的是同一个合成设计，不相加成样本数，以上比例也不是产品故障率。

[旧公开单例](<../响应侧工具参数源头-2026-11-17/evidence.json>)三层都已核为 `AAA`，参数原串和规范编码各 85 B、摘要相同，旧 `SOURCE_MISSING_PRESERVED` 不改。它支持「捕获的 W 已缺、所见 L/H 仍缺」，不证明采样之间从未变化、请求背后的生成者身份或私有原档真实性。本次非作者复核属于项目内，不是受控第三方核验。

## 3. 公开复算

`python3 -B verify.py`（此目录）用合成状态重算方向、可能边、必有边与精确次数集合，也复算已声明的 W→H→L **取证顺序**下掩码覆盖。它只复算三态和掩码，不复算原串与规范对象的联合计数，不执行旧判定入口或工具参数，也不用合成例认证历史原档；旧入口的实际对照与单例回放结论见上。
