# DSH 等宽首包中的上下文残差（11-23）

只定位[四个等宽历史首包](../处理前首包平衡复核-2026-11-23/README.md)剔除嵌入日志后的正文差异。捕获请求里有一个承载两个文本块的 `user` 消息；同一份请求内嵌的事件记录有两个有序的 `user/message` 事件。四个包的第一个文本都等于登记提示词；第二个文本分别与同包对应事件原始 JSON 字符串 token 及解码 UTF-8 一致（4/4）。嵌入事件把第二个文本标为非用户来源。**消息角色是 `user`，不等于用户实际键入。**

跨包看，六对第二文本等宽却均不相同，每对有 1–3 个对应字符变化。按预先限定的带时区数字 ISO 语法，四个包的第二文本均没有合格时刻，六对均**无法判定是否为时钟差**，不能说排除了时间因素。已用独立合成对照检验语法、偏移日期转换和闭区间边界；合成例不进入四个原包的分母。

结论限于同包两处可见文本及其记录标签，不是两份独立原件，也不能确认生成者、服务端摄入或 Harness 干预效果。本次是内部非作者复投影，未修订原档、旧分或冻结状态。
