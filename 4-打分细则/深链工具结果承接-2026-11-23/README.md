# 两条深链里的工具结果：首次承接与后续历史携带（11-23）

固定复核既有两条 DSH 深链中的 29 份主请求与两个本地事件档。客户端响应流、本地逻辑角色与捕获后续请求的字段分别定界；闭合、身份/位置、原串、严格对象和结果文本分别判断。两个历史档分别有 **14、13** 个可核的源工具调用；各源最早符合时序的下一条主请求，均含唯一且有序的调用和结果对。工具名称、参数 UTF-8 原串与保留数字原字面的严格对象，在客户端响应、本地调用记录和首次历史中分别等值；本地与首次历史的结果正文也逐字等值。客户端响应里的工具调用不等于它已经生成了工具结果。

| 续请求里的出现位置 | 档案甲 | 档案乙 |
| --- | ---: | ---: |

这些是**同一工具调用在同一条历史中被带入的次数**，不等于独立调用或再次执行。可比较的晚对结果正文都与本地结果及首次历史一致。两条归档各有 14/13 对相邻主请求，后一包保留前一包的已解码历史前缀和非消息字段；不把整体前缀相等代作逐调用绑定。各档最后一个源调用只有首对，不能说它已有后续重复证据。

离线分别改动结果同宽文本、结果来源事件序号、删首对的调用、遮住首包，以及只改请求 JSON 表示。改变一端不抹去另一项可核证据；孤立同标识结果只支持该字段比较，不补判严格对或本地来源。较晚完整对不回填首次，时点并列也不强造先后。实际仅复核固定两档，客户端捕获经过代理转帧；未运行产品、不认证后端摄入/执行、不改单次得分或冻结门。内部非作者复算不是第三方原件核验。参见[工具历史首触](../工具历史首触复核-2026-11-23/README.md)。
