## 证明骨架（全文见私有 proof-abc388f/PROOF.md，预注册先于映射）

- **引理 A（可达递推）**：好格 x∈Reach ⟺ ∃d∈[A,B]，x−d∈Reach。
- **引理 B（滑窗表示）**：B 位掩码 bit i=[pos−i∈Reach]；尾部无关（pos−B 以前不可能是未来源）；好格一步=移位+窗口 OR 注入；坏段跳跃纯移位，≤R−B 的源不可能跨段（丢弃无损），段长≥B⇒全零。
- **引理 C（饱和/吸收，v1.1 修正界）**：好段上 0 与 FULL 均为吸收态；B>A 时记 k₀=⌈(A−1)/(B−A)⌉，段内可达源出发 ≤k₀A+B−1 步、任意非零状态出发 ≤k₀A+2B−1 步内 mask 达 FULL（可达块 [p+kA,p+kB] 在 k≥k₀ 连续拼接，窗口每小时仅进 1 格故整全需 k₀A+B−1 步；全 190 组 (A,B) 模拟校验零违反）。
- **引理 D（A==B 算术）**：路径唯一={1+kA}；N 可达 ⟺ (N−1)%A==0 且无坏段含 1+kA。
- 四映射：Codex C1–C6（环检测=有限状态函数终归周期，索引界内精确）；DSH D1–D7（P=j0·A+2B+5≥k₀A+2B−1 足过 (γ) 一般修正界；A==B 与豆包同点：⌈(L−1)/A⌉=L+((1−L)%A)）；豆包 B1–B7（反向位序镜像 + 早退皆吸收态等价）；元宝 Y1–Y9（mat_mul 复合语义=指数相加，mat_pow=Tgood^e 精确闭式；blen≥B 提前 print No 与 mask=0 终态等价）。
