# Chat 的停止信号与本地轮尾（11-23）

三组既有 DSH Chat 捕获各选择一个辅助标题响应和最后一个主响应。六份都各有一个 `stop` 和一个其后的已派发 `[DONE]`，也都有可比较的本地文本：主线 3/3 等值，标题 3/3 等值。**只有主线 3/3 具备两侧明确共享的响应键，并可在本地确认同轮结束；标题的直接响应键 3/3 不可核，不是 3/3 不等。** 因此既不能由 `stop` 判定任务结束，也不能由文本相同补出跨层身份。

离线把一段内容移到 `stop` 之后，仍保留一次 `stop`、一次 `[DONE]` 和同一响应键，正文仍逐字节相同；捕获流因 `stop` 后仍有内容更新而未通过闭合检查，但本地轮尾证据仍在。另分别切断请求绑定或替换本地键：前者让联合证据不可核，但不删除可见诊断；后者可让键不等而正文仍等。角色使用封存时的分组，键只证明指定归档和捕获的对应，不证运行时探针、界面送达、任务成功或独立上游身份。本轮仅完成内部非作者复核，不构成第三方受控核验；不改历史裁定。
