# M1 后继备稿：先区分字节回升发生在哪个端点，再核恢复路径

**未注册、未发射，不构成授权。** [历史备稿](<../机制单变量外溢呈现-PREREG-2026-11-29/README.md>)保留原样；不沿用其事后排除错绑门的前置写法。新结果必须正面通过适用的错绑和缺档反例，再谈冻结或发射；[历史 G4a](<../盲验错绑与终态覆盖复核-2026-11-28/README.md>)仍是未通过。项目内复核不替代老师要求的受控外部第三方核验。

## 1. 只改变呈现，不把呈现差从结果里扣掉

问题：同一 DSH CLI、同一来源字节和任务，若只改 `maxInlineTokens`（候选 A=12500、B=500），早期少的客户端正文字节是否在五事实送达时已消失，还是只在任务终局出现变化？事实又是从初始表示、外存派生物、原输入重读或其他来源进入请求的？这些是两个判断，不由一个比值同时回答。

- 未来如获授权，先钉 CLI 与插件构建、有效设置、模型/路由/可配思考档、同源 fixture 与五事实、任务/生成参数、工具与权限、工作区模板和捕获方式。逐项验明两臂相同，除唯一设置外不接受额外开关、不同提示或不同首个固定来源结果。两臂均保留新会话；真实后端思考、路由漂移或缓存不能假设等控，没有证据只写未知。
- 同一固定来源结果在两臂的原始对象版本与内容要能独立对账。实际展开/外溢表现是干预合规和中介观测，不能用等长可见文本把它抹去。首次未能到达来源、阈值未触发或捕获异常保留在原指派；不把一臂改标或换样。上线前若不足以只干预呈现，方案不得宣称 Harness 归因。
- 维持原预算量级，**提议五个固定配对、共十次尝试**，不是已批准预算。未来每对先后独立公平抽取并预先保留概率、指派和实序收据；不再每对 A 先，也不以交替表代替指派。约定结束/资源边界、捕获失败停线和预检预算须另版锁定。五对只作描述，不报显著、等效或稳定排序，见[先后与指派](<../外溢呈现的先后与指派-2026-11-29/README.md>)。

## 2. 同一次尝试的三个坐标，不用末包补端点

客户端主请求完整正文字节从开头累加，标题另记。**整包原字节 `W` 是主口径**；`W−L`、消息块、自报量是不同计量面，不互相替代，也不是 token、成本或服务端接收证明。每段须有接受的会话与槽绑定、正文摘要与长度、角色和缺口证据。

| 坐标 | 准入的观察 | 单列的缺口 |
| --- | --- | --- |
| **I：首次呈现** | 同一预定来源结果第一次交给主请求；可为内联值、外溢表示或已说明的其他形状 | 只见启动请求或同一字符串不算 |
| **Q：同事实送达** | 固定五事实分别在成功且可核归属的结果块内完整判值；截至某个主请求首次陆续交齐（`E_seen`） | 后包只够证明局部共现时不补首次；已终止未到与缺档未知分列 |
| **Z：尝试终局** | 同一次尝试有独立锚定的结束边界，并能核到截至该边界的主请求覆盖；成功/失败/资源结束不删 | 流闭合、最后可见主包或取消回执单独不足；缺覆盖则字节未知 |

**分别核对三项：**事实绑定的前缀、原始正文的前缀、同一次尝试的独立终止边界。事实前缀缺而正文一直完整到 Z，可以有 `W_Z`、没有 Q 首次；事实前缀完整而字节缺失，也可以知道 Q 首次在哪包却量不出 `W_Q`。只有终止前的事实支持完整、且确未见齐五事实，才填「已终止未到」；判卷通过也补不出 Q。同次尝试按主请求序核对 `I≤Q≤Z`；同一主包上的两锚累计 `W` 必相同。反序或冲突只保留有证的观察，不进入回升阶段比较，也不用未知补位。

同时报告 Q 对应的同包共现、新组齐备、单块齐备；如果这些诊断端点先后不同，分别保留位置，不从累计命中补同包，不把原始事实值跨块拼出来。首次一旦在完整前缀有证，不被后缺档倒抹。判卷须是冻结、隔离、同判据的独立任务结局，和 Z 的捕获覆盖分开；模型自述、正确字符串和轨迹终态均不能替代。

## 3. 只在证据支持时说“回升”与“回流”

每对在有证的 I、Q、Z 分别给 `d = W_B−W_A`。若 `d_I<0`、`d_Q≥0`，只说明**到同事实坐标时早期字节差已不在**。若 `d_I<0`、`d_Q<0`、`d_Z≥0`，在这三个坐标上到 Z 才观察到非负；中间可能已有反转又退回，不能说实际首次跨越发生在 Q 之后。缺 Q 的字节则不定位回升阶段。吞吐、费用和等效都不由此推出。

另按事实列首次供给路径：源结果与派生物需可指向同一内容版本，在相应主请求中核到第一个合格的结果 ID、原内容及新出现；归属前缀完整才说首次；先前缺证时只报有证的后续路径。相同路径名、全文命中或后续再读不能补首次。若首次同包有两条合格来源，并列，不按块序选唯一来源。**另外记录外存回流是否有证**：例如先由原输入重读送达，后续合格的外存结果仍可证回流，但不是首供。首供集合为空不表示没有回流。即使确定回流，也不能把整包的差量全归给这条路径。

| 合成对照（仅字节，非实跑） | 它推翻的捷径 |
| --- | --- |
| A 的 I/Q/Z=`100/150/180`，B=`70/160/180`；两臂都独立通过，分别给 B 外存回流、原输入重读、无可核路径 | 相同字节和相同成功不识别恢复来源 |
| 同一 A，B=`70/130/230`、且有外存回流 | 终局多字节加回流见证，不等于到同事实就已抵消早期差 |
| A=`100/150/300`，B=`70/170/180` | 到同事实已反转与终局仍少可以同时成立 |

锁定五对后不删失败、未启动或捕获缺失；分别列逐臂独立判卷、到达状态与字节。在 W 口径前后一致、比值定义且五对均有证时，才报固定五对中位和 `<0.90` / `[0.90,1.10]` / `>1.10` 描述带。若一臂到不了 Q，Q 比值未定义或未知，不用末包或另一次尝试替换；Z 仍可能完整且有字节，同时任务失败。独立证明某次尝试已经结束且未发主请求，才记真实 `W_Z=0`；未启动、缺档不填零。两臂字节可测与比值可算分列。各锚的 `W_B/W_A` 需要两值可测且 `W_A>0`，因此有证的 `W_B=0` 可以给比值零；`W_A=0` 只保留差值，比值不定义。

若假设同一次尝试随后确实到 Q，条件下界只取正文与事实绑定均完整、且证明尚未达到 Q 的同次前缀；不能用已知的整个 `W_Z` 越过事实缺口。证实已终止而未到 Q 时不定义端点，也不造区间。条件界另列，不给实际中位补值，见[固定五对缺档判定](<../固定五对的缺档判定-2026-11-28/README.md>)。项目内非作者以合成例先独立检验，再对照三锚、五对名单和两种覆盖缺口；不认证真实捕获或判卷。

3. **读取问题另做配对。** 外存路径、打开文件、返回值和物理实读不是一回事。读取检测若要报命中能力，须同一对象版本、同一有效采集窗，独立证实一臂读到内容、另一臂仅打开而不读。不存在的 inline 路径不是同对象真阴性；不能用方法上相同的任务窗口拼不同实际时间。配不上维持未知，不估召回或污染上界；见[读取真值准入](<../../5-评测报告/读取真值配对准入-2026-11-24/README.md>)。
