## 四归档共同算法与证明骨架（引理 G1–G8）

四份归档同构：d[x]=「x 右侧第一个 ≥2A[x] 的位置距离」+ RMQ 稀疏表 + 每询问在谓词 P(k)=max_{i<k} d[L+i] ≤ m−k 上二分（Codex/DSH/豆包搜 max k；元宝换元搜 min d=m−k）。

- **G1（need 单调）**：A 升序 ⇒ need(x)（首个合格顶位置）随 x 不减。
- **G2（充分性/右对齐构造）**：P(k) 且 k≤⌊m/2⌋ ⇒ bottom_t=L+t−1、top_t=L+m−k+t−1 合法（top−need = m−k−d[bottom] ≥ 0；m≥2k 保证底顶位置集分离）。
- **G3（必要性/鸽笼）**：任一 K=k 匹配中，对每个 t，底 x_t..x_k（k−t+1 个）的顶全部 ≥ need(x_t..x_k) ≥ need(L+t−1)（G1）；若 d[L+t−1]>m−k 则 need(L+t−1)>R−k+t，[need, R] 至多 k−t 个位置放不下 k−t+1 个互异顶——矛盾。
- **G4/G5**：P(k) 单调降 ⇒ 二分合法；K*=max{k≤⌊m/2⌋: P(k)}。
- **G6（d 计算与哨兵安全）**：bisect 全覆盖（0-index 半开区间不含虚拟位，无漏检）；哨兵分账——codex inf=10⁹、doubao n+10 恒大于界；dsh n−j 在「底仅取前 k 位」谓词域内 n−j ≥ gap+m−k+1 > m−k 恒判假（域限制子引理）；元宝双指针（G1 保序）+ N+1−i 哨兵（N+1≤R 恒假）。
- **G7（RMQ）**：标准稀疏表；元宝越界填充槽不可达、l>r 分支被短路不可达。
- **G8（等价）**：四实现谓词等价（k ↔ d=m−k 换元）、二分域一致（k∈[0,⌊m/2⌋]）。
