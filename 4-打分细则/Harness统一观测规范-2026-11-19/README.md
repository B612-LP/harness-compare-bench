## 1．观察对象、分段与绑定

| 层 | 观察单位与准入 | 不得替代 |
|---|---|---|
| L0 原载体 | 收录标识、角色、实际字节数与 SHA-256；原件、合法重编码副本及公开派生分开。解码前后分别计量。 | 相同摘要可证明相同字节，不能单独证明属于哪个运行、角色或时间。当前持有承诺不是历史独立见证。 |
| L1 本地事件账 | 按解码后的物理顺序保留事件与字段，禁止用时钟重新排序；区分容器字节、解码字节、行数及逐行规范值。 | 不是发送给模型的请求体；本地序列不同，不推出客户端首请求不同。 |
| L2 本地语义投影 | 用各格式的显式任务、轮、步骤及角色边界；本地工具调用和结果用同段、同类型、唯一标识绑定，辅助标题分开。披露选定字段与完整对象的分母。 | 本地事件闭合或产品标记完成，不等于正确执行、操作系统实读、任务成功或结果下游可达。 |
| W 客户端捕获 | 请求与响应分别登记；关联同一运行的元数据、任务、角色和身份，响应经相应流式终止门后才解释一个受检完整项。 | 客户端正文不是全网包、服务端实际摄入、token、计费、真实缓存或实际思考工作。自报用量另账。 |
| H 后续请求历史 | 指首个有证据承接该项的合格主请求；在相应格式下核同调用/结果、类型、顺序与后续阶段。 | 不是任意下一捕获序号或同名下一调用；没有后续捕获就不填 H。 |

关联的必要字段若缺失、矛盾、重复或跨段，先判归属不可核；同名、等时、等长或等字节不能补齐。冗余标识出现时须相符，不允许主 ID 对了就忽略矛盾副本。反过来，一端归属不可核不抹掉另一端独立成立的事实。完整请求重建另须有**绑定的请求正文本身**作参照、有非空全字段覆盖证明，且构造从独立的同目标输入开始，不能从目标捕获复制数值或序列化。报告选定字段命中、全值是否重建、原始字节是否重建三个不同结论。

## 3．计量与三个状态

- 报告注明格式配置版、角色/起止锚、视图及选择范围、算法/单位、分子/分母和证据层；容量单位是 B 而不是字符、token 或成本。原始载体或正文字节计实际 UTF-8/文件字节；原始值比较用实际字节或已核摘要，长度只作并列度量。压缩容器、解压日志和 SSE 包装不混算。参数字符串按从外层取出后的 UTF-8 计数，不含外层转义；若比较内嵌对象，再显式严格解析一次。
- 指定规范 JSON：对象按 Unicode 码点排键，无额外空白；数组原序、UTF-8，不做 Unicode 正规化、不删事件字段；逐行合计不含换行。重复键、非法 UTF-8、不成对 surrogate、非有限量及超过算法边界的输入不产值。相同结构的换行、空白、键序、Unicode 转义或合法重压缩可改变原始字节，不改变该算法下的受检值。字段筛选变化不是重编码。
- DSH 校准使用有界精确十进制（对象层整数、小数/指数分型，保留正负零，按固定系数/指数序列化）；Codex 已发布的是其旧对象实现上的局部字符串参数实例。不得跨算法宣称数值或规范字节等值。合成反例显示二进制浮点会合并两个等长但不同的十进制值。既不能据此假定产品接受这种数值，也不能把合成反例写成历史原件实际误判。
- **存在**：合格容器上的值，原始 `null` 或数值 `0` 均是值、两者不可替用。**确认缺失**：目标属于完整而已绑定的对象，字段确实不在其中；两个对象都无该字段也不产生数值等式。**不可核**：源缺、坏格式、错绑定、覆盖不足、比较单位/算法不兼容等；保留原因和必要的非空分母，受影响指标写 `null`（此处是结果账标记），不填 0。真实变化是两个可比较的已知值不同，不把不可核当失败或行为变化。

## 8．计量域、截断分层与存储分账（1.3 新增）

- 依据：2026-11-21 对 DSH 0.2.2-rc.3 本地包与 Codex rust-v0.163.0 tag 的源码级定源+双产品行为级交叉（逐环非作者独审；公开增量见[台账](<../../5-评测报告/检出率三元组台账-2026-11-20/README.md>)与 CHANGELOG，逐环登记归档私档）。规则如下，均限（产品 × 版本 × 配置档），不回填正式 25 格、不改 §1–§5 冻结语义。

- 检测面与 §6 的关系：§8 不改 §6 配对账，只为读取检测补计量语义；「检出⇒读取」主张仍须进程拓扑与请求面双证（FD 面=持有覆盖检测）。
