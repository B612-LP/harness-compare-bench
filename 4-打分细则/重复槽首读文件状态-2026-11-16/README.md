# 重复槽首读文件状态：单目标探索后固定分析

## 问题与身份

对照[Issue #16](<https://github.com/B612-LP/harness-compare-bench/issues/16>)的重复假设、控制变量与反证要求，检验“同一TASK/继承inputs清单足以认证重复槽遇到相同未解文件状态”这一解释。本件不是新产品试验：只分析r1109既有DSH exercism的r2/r3，一个目标 `inputs/exercises/dominoes/dominoes.py`、一对比较，不增加n，不改正式25格、历史分数或任何旧门。

**探索后固定**：立本规则前已观察全部源定位、首读内容2010B/2000B、名义骨架34B、两失败一成功Edit及替换关系；不是盲前预注册。规则与反例检验仅限制后续提取和判定，不能把已知阳性包装成确认性实验。[固定源](<SOURCES.json>) SHA-256：`89f3828a2b7facce2ff20fadc2dae11615fcbfcb93601907c73f72cf89282a39`。

共享a1工作区、后rep覆盖及meta继承早已在[现场](<../../3-表现现场/r1109-mech-n3/README.md>)披露，不算本件新发现。[原预注册](<../机制独立重复预注册-2026-11-08/README.md>)要求全新会话/上下文和固定inputs，未明写逐rep全树clean-reset；不捏造该项协议违约。比较对象是捕获日志首个目标读取处的返回内容，不是排他进程初态快照。

## 三项要求与验收

1. **来源与先后**：两压缩原件SHA、既有v1.1逐事件四列投影和其公共依赖均须硬等；slot/源覆盖固定。各槽所有首读前assistant tool-call块须与tool/call的id/name/解析arguments同序匹配，call/result按真实关联唯一联结。两槽首两调用分别是目录列举及for/echo/cat；固定参数哈希逐项等，不以`bash`工具名代替复合命令检查，不执行任何命令。seq25/26为首读，目标前不能存在别的已记录写调用；这只约束已捕获前缀，不排除外部活动或捕获外步骤。
2. **内容与编辑**：原返回按text块原序拼接，要求成功、唯一行首起标记`===== dominoes skeleton =====\n`及固定终标记（r2 bowling README、r3 forth README），原样切片，不strip、不补LF、不改编码行尾。完整首读S0/S1实字节比较。r2 seq49/50、55/56失败与67/68成功Edit全保留，固定参数哈希、实际isError、关联与目标路径归属均核；成功old_string必须只在S0出现一次，做一次精确替换得P，再实字节核P与S1。只报告替换相容，不认证唯一历史写入者或功能正确性。公共meta仅核目标在继承inputs清单及34B/骨架SHA，不当当次新门或真实文件快照。
3. **可反驳与独审**：普通/-O完整结果一致；公档复算、私档重建、缺失/错序/错误关联/等长异值/重复边界/截断/多次替换/失败冒成功/路径或JSON异常等近错检验；非作者从原档独立重建，不import作者helpers作科学真值。公档只含安全相对路径、序号、长度/哈希、结构和算术，不含正文/代码片段、原会话或调用ID、时间、cwd/私有绝对路径。公开PASS不认证私原真实性或文件/进程的真实历史。

## 预定裁定分支

主要终点：固定一对首次读取内容是否相同（0/1或1/1），不是污染率或独立实验次数。S0==S1则本候选反例不成立；S0!=S1而编辑关系不闭合，仅裁“首次受观测文件状态不同”；S0!=S1且P==S1，裁“状态不同且与上槽成功Edit的预测态相容”。关键来源/完整性/边界/关联失败则unknown或硬失败，不补0，不强判相同/不同。所有判定用显式运行门，不能靠assert在-O消失。

可改变的判断限于：至少此门内目标不能从名义骨架/同TASK推出当次未解内容相同。即使相容，也不认证排他继承、初始实现由谁写入、其他槽状态或状态差对thinking/cache、工具选择、答案、分数的因果贡献；不外推正式25格。L0/L2不覆盖tool/result，旧投影同一事实不由本反例撤销，旧门也不因此重判。真实launch全树快照仍缺。
