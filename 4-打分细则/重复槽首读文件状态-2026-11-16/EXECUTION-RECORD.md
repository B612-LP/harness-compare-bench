## 复算入口与输出约束

从仓库根执行。`NEW_OUTPUT` 必须明确设为**仓库外、父目录已存在、文件尚不存在**的 JSON 路径；`PRIVATE_SCRATCH` 为显式选择的既存私有临时目录。复算不会创建父目录或覆盖任何输出。

```sh
python3 -B '4-打分细则/重复槽首读文件状态-2026-11-16/verify.py' --output "$NEW_OUTPUT"
python3 -B -O '4-打分细则/重复槽首读文件状态-2026-11-16/verify.py' --output "$ANOTHER_NEW_OUTPUT"
python3 -B '4-打分细则/重复槽首读文件状态-2026-11-16/test_verify.py' --scratch "$PRIVATE_SCRATCH" -v
python3 -B -O '4-打分细则/重复槽首读文件状态-2026-11-16/test_verify.py' --scratch "$PRIVATE_SCRATCH" -v
```

CLI 的 `--root` 默认是复算器的 `parents[2]`（本次默认路径已实际验证）；独立镜像可显式 `--root "$REPO_ROOT"`，测试支持 `STATE_TEST_ROOT` 环境变量。原档拥有者另用 `--archive-root "$ARCHIVE_ROOT"`；附 `--build-evidence "$NEW_EVIDENCE"` 可独占重建安全证据。两输出必须不同；所有输出为**顺序、非事务**写入，后一个失败可能保留先前新建文件，不能声称自动回滚。错误只给通用拒绝，不回显敏感源值。
