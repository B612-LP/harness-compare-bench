# 样例标签和计时端点各证明什么

[11-25 同题档](<../../3-表现现场/r20261125-five-lcb/README.md>)留有被试自己的样例命令、结果和两 CLI 的收据。**外层退出 0 不保证样例全过；样例 OK 不保证编译阶段无故障；启动至已存 stdout 修改时间不是生成耗时。**本页静态核同 ID 对和既有记录，不运行候选、参考、历史命令或判卷，不出分。

## 同样的 OK 字样，判据并不相同

| 固定对（JSONL 物理行） | 所见 | 判据和上限 |
|---|---|---|
| [Codex 较早 50→51](<../../3-表现现场/r20261125-five-lcb/codex/stdout-r2.jsonl#L50-L51>) | 11 个逐例标签，8 OK、3 FAIL，外层退出 0 | 解码后比较两边 `.strip()`；判标签不要求子进程退出 0 |
| [Codex 较后 79→80](<../../3-表现现场/r20261125-five-lcb/codex/stdout-r2.jsonl#L79-L80>) | 同一回包有编译缓存目录 `PermissionError`、`ALL SAMPLES OK`、外层退出 0 | 样例步骤另有 `check=True`，正常完成的样例比较仍以归一文本为准；编译失败信息不能被样例汇总覆盖 |
| [DSH 70→71](<../../3-表现现场/r20261125-five-lcb/dsh/stdout-r2.jsonl#L70-L71>) | 11 个逐例 OK，工具 `completed`，未见外层数值退出码 | 文本模式解码及换行转换后再 `.strip()`，标签未要求子进程退出 0 |
| [豆包 69→70](<../../3-表现现场/r20261125-five-lcb/doubao/trajectory-38455827958268674-copy.jsonl#L69-L70>) | **四题级** `ALL SAMPLES OK` 和后续 `compile-ok`，外层回显退出 0 | 样例用归一文本，没对每个子进程验退出；编译标记有另一步链条件，不是 11 个独立退出码 |

固定题源有 4 题、11 个名义样例。标签本身不含这个分母：汇总在布尔上没有显式非空门，但这不是历史集合为空的证据。对未检查退出的三条流程，纯逻辑上“比较文本一样、子进程非零”仍满足比较式；不是本档 DSH 或豆包实际观察到的返回组合。归一文本相同也不能认证原 stdout 字节相同，原始字节及各子进程退出码未完整保留。前后版本不可互相补写标签；“未独立判卷”与归档仍可见被试自测相容，不是声称被试没执行。

## 端点只给总跨度，不给各环节占比

[Codex 启动／收据](<../../3-表现现场/r20261125-five-lcb/codex/launch-r2.json>)（[收据](<../../3-表现现场/r20261125-five-lcb/codex/postflight-r2.json>)）与 [DSH 启动](<../../3-表现现场/r20261125-five-lcb/dsh/launch-r2.json>)（[收据](<../../3-表现现场/r20261125-five-lcb/dsh/postflight-r2.json>)）分别绑定 PID、启动时间及本次归档终态。两份名义间隔为 548／328 秒，后端点都是【已存 stdout 的 mtime】，不是退出钟，也不为每个事件提供统一时间戳。选定的 shell `total` 21.977 秒和七个 `real` 7.577 秒只是两份归档各自的局部量，不是工具总量，也不能相减求推理时间。[Codex 两次顺序段](<../../3-表现现场/r20261125-five-lcb/codex/stdout-r2.jsonl#L74-L75>)另报约 17.547 秒，早先试拟把未选部分全塞进 1 秒的排程因此不相容；旧 profile 回显的重复数字也不能当作多次执行。

| 两个相容反例（秒） | Codex：工具间隔／其他 | DSH：工具间隔／其他 |
|---|---:|---:|
| A | 250／298 | 250／78 |
| B | 450／98 | 100／228 |

以整数毫秒给 84／78 行顺序排程，保留 35／14 个相邻同 ID 边、名义端点、已定位局部计时约束，并核 DSH 七个请求时间帽。所选局部报告需真实且适用于对应区间，这些是假设下的排程，不是历史复原。两家“工具间隔超过一半”都能翻转而不改变这些约束；其余桶含等待、调度、网络、模型等可能，不能标作思考时长。请求时间帽不是实耗时。即使有上述证据，仍不能估实际各阶段或产品速度差的来源；元宝的 [恢复观察区间](<../元宝恢复身份与观察区间-2026-11-27/README.md>)也不填补这组分母。
