1. 本页不冻结双线试行口径。当前门状态见上方「发布后状态」；G6 整套联合覆盖、G7 两线整体独立投影和 G8 受控第三方复验仍未完成。

3. 映射 v1 是首发时的建议名，不追改旧版。
4. 矩阵每格只登记已有证据的指针，不新造对照、不外推到其他批次或产品。
