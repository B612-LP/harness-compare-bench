## 主要终点（全部描述性）

- **P1（运行内前缀性）**：每次运行内，对相邻主任务请求对（req_k→req_{k+1}，k≥1），req_{k+1} 的消息列表以 req_k 的**全部消息**为严格内容级前缀，且仅追加新消息（不删除、不改写、不重排已有消息）；逐段字节 delta 分账（delta=追加消息字节和 + 顶层/采样参数字段差，两者分列）。
- **P2（全程无标记）**：链上全部请求无任何截断/摘要/重组见证（消息级前缀性已蕴含；另检查无截断类 marker 字符串进入消息文本）。
- **P3（跨 run 稳定性）**：req1 跨 run 逐字节恒等；辅助标题请求逐字节恒等；主任务链的轮数与每轮追加形状（role/kind 计数）如实记录。
- **P4（探索，不判定）**：每轮追加消息的 role/content_kind 构成；模型文本跨 run 差异只记不裁。
