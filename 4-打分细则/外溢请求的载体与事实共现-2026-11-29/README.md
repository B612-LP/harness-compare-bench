# 外溢请求：不同字节范围与不同事实端点不能混用

[既有同阈值复核](<../外溢字节端点敏感性-2026-11-28/README.md>)在同一旧任务里发现：首次送达一项事实和最后可见主请求给出不同阈带。这次在同一批固定证据上分别问：差量落在哪类正文成员？同一次任务拿到两项信息，是否等于某条请求同时带齐，或某个新结果一次带齐？**这两项都是旧证据的离线复核，不是新干预或判卷。**

## 1. 整包、扣会话日志、仅消息，三种读数都不同

锁定旧批 R38 的 23 个客户端捕获请求正文，逐份核 SHA-256 和原字节长度：17 个主请求、6 个标题请求。后者不纳入累计量，两个冒烟场不纳入比较边。用旧账的角色和端点：E1 为首个成功目标结果入包，E2 为首个新绑定的同一校验事实入包，E3 为最后可见主请求，**不是已判任务终局**。

- **W** 是完整捕获请求正文。**L** 和 **M** 分别为原 JSON 顶层 `dsh_session_log`、`messages`：从键的起始引号计至其值的最后一字节，含键、冒号及内部空白，不含外层逗号及值后的空白。**O** 为剩余原字节，因此 `W=L+M+O`；不做重序列化。`W−L` 是该口径下的账面差，不是重发或删除字段的反事实，也不等于旧账的另一种分隔符计法。
- 固定 2 内联 + 2 短侧构成四条共享运行的边，只有两种不共享配法。E2 四边的短侧 **W 均多 8,033–10,226 B，四条比值全在中带**。每边 L 和 M 反而都少，O 各多 27,611 B；这足以否定「E2 的账面净增来自会话日志变大」，并未给 O 内部的字节归因。

| 同一个 E2 端点，只改变统计范围 | 四条边的低 / 中 / 高 |
| --- | ---: |
| 按完整 W | 0 / 4 / 0 |
| 按 W−L | 0 / 0 / 4 |
| 仅按 M | 4 / 0 / 0 |

两种不共享配法的 W 中位数分别从 **1.071961→1.232457** 与 **1.071997→1.233597**。E3 的两条高带边共用同一短侧：它只多了一个主包，`40,860 = 7,238 L + 6,011 M + 27,611 O`（B）；不计入首次事实交付。全程用旧描述带 `<0.90 / [0.90,1.10] / >1.10`，不是等效或显著性检验。一项近错是把短侧一条真实标题请求误计为主请求：增加 34,133 B，足以把一条原为 `135326/126423` 的 E2 中带误判成高带。一个外层空格的合成例也能让贴在 1.10 边界的 `W−L` 判带翻转；不能把值外空白算给 L。

## 2. 陆续供给、同包共现、新组齐备、单块齐备

复算同批六场的既有匿名投影（17 主请求、11 个新增结果，含一次失败；该冒烟场其后恢复到旧单事实）。固定两个既已登记的锚：旧任务的一项中间值与另一个尾部覆盖标记。**两锚合用既不是旧任务的判卷合同，也不是新实验的五事实。** 只用成功且已绑定到同一来源的工具结果；历史的旧块稳定旁证来自既有原件复核，不由匿名布尔标记重证 ID 或来源。

| 已见支持的端点 | 4 场主批 | 2 场冒烟 |
| --- | ---: | ---: |
| 截至该主请求，成功新结果已一次或陆续交齐（`E_seen`） | 4 / 4 | 1 / 2 |
| 同一主请求的已核结果块同时带齐，允许旧块（`E_live`） | 4 / 4 | 1 / 2 |
| 同一主请求的已核**新**结果组带齐（`E_fresh_group`） | 2 / 4 | 0 / 2 |
| 单个已核新结果自己带齐（`E_one`） | 2 / 4 | 0 / 2 |

主批两场的首次共现在第 2 个主包，由单个新结果带齐；另两场在第 3 个主包，由新中值与已核旧尾标拼成**证据集合**（不跨块拼造值）。其中一场第 4 个主包仍携带两锚，但二者均来自旧块，不能再报一次新交付。该旧批每个主包至多新增一个块，后两行刚好相等；合成两块同组各供一值即可使两行分离。另一合成例先后送达且后包不再携带旧块，只够报陆续到齐，不够报同包共现。

缺了先前捕获可以核确切的后续共现，但不能补称首次；也不撤销缺口之前已证的首次。六场末响应都观察到笼统的 `end_turn`，并含旧单事实但不含尾标；**六场的独立任务判定均未知，不是 0/6 成功**，也不能因此判输旧任务。正文中的值、同一捕获窗的实际读取以及任务交付正确是三种证据。五事实的后继设计宜以 `E_seen` 衡量逐步供给、独立报 `E_live` 与终局；缺端点按[固定尝试分母](<../固定五对的缺档判定-2026-11-28/README.md>)记录，不用末包补齐。
