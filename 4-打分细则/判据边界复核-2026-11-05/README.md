# 判据边界复核：可见性、依据与覆盖范围

本页解决三个不同的证据问题，不是新跑批、判卷修订或产品排名。主报告见 [v1.9](<../../5-评测报告/竞品评测报告-v1.9.md>)；历史正式25格及 A / B / W 各轨 n=1、分数、gold、作废与替代均不改变。

| 问题 | 本次可核结果 | 不推出什么 |
|---|---|---|
| LCB “隐藏测试不公开”的旧措辞 | canonical输入11样例；公共truth有171完整测试，其中160标private | 不证明每场实际打包、未读取、训练去污或OS隔离 |
| DAB q49旧计数抽查依据 | 欺诈次数NL2955>BE2493；按手册金额率BE最高，原B.BE有支持 | 不改gold、不退出q49归因、不扩展q2697裁定、不重判 |
| Cargo航向语义覆盖 | 旧27条不数值核磁航向；新增纯合成真/磁航向关系诊断 | 不证明旧checker违约、历史错误PASS或产品航向实际错误 |

## 1. LCB：canonical输入不等于公共审计材料

- **观察**：[v1.8旧行](<../../5-评测报告/竞品评测报告-v1.8.md#L39>)把LCB隐藏测试写成“不公开”，表述不准确。
- **证据**：[固定truth](<../../2-用例/lcb-recent-hard-4/truth.json>)四题共43/43/42/43条，合计171=11个public样例+160个private标签测试，后者也有完整输入/输出。[canonical输入](<../../2-用例/lcb-recent-hard-4/inputs/problems.json>)为7,884 bytes、11个样例；[复制配置](<../../2-用例/lcb-recent-hard-4/case.json>)指向inputs目录。本次核目录exact仅该文件，拒额外文件、子目录和同字节符号链接。
- **解释**：canonical给题材料较窄，与public truth完整可读可以同时成立。`private`是测试标签，不是本仓访问控制。
- **未排除因素**：配置不证明每次历史运行的实际打包；公共材料可读不证明产品实际读过，也不认证未读、训练去污、环境隔离或私档原件。
- **可复现范围**：[lcb_visibility.py](<lcb_visibility.py>)固定六来源并解析结构、测试摘要及源码定位；不执行算法提交或旧checker，不复制测试正文到新派生件。

## 2. DAB q49：计数依据有误，原答案仍受金额率支持

- **观察**：[旧spec第143行](<../../2-用例/dabstep-payments-10/spec.md#L143>)以欺诈“笔数”抽查声称BE最高，遗漏了NL；这条依据记录不成立。
- **证据**：[手册第225行](<../../2-用例/dabstep-payments-10/inputs/manual.md#L225>)定义欺诈为fraudulent volume / total volume。[固定CSV](<../../2-用例/dabstep-payments-10/inputs/payments.csv>)共138,236行，True/False为10,765/127,471；按所有行的ip_country聚合，次数NL2955>BE2493，但金额率BE263833.85/2150473.54=12.2686396783%，高于NL329134.08/2701907.13=12.1815467432%，且BE在全部八国中最高。
- **解释**：纠正的是旧计数交叉检查，不是把[原B.BE](<../../2-用例/dabstep-payments-10/truth.json>)判成错误。按金额率可以独立支持该答案。
- **未排除因素**：本次不重开q2697裁定，也不因为这条记录错误就退出q49能力归因；不能据旧重复失败推断产品共因。
- **可复现范围**：[dab_q49.py](<dab_q49.py>)固定五来源，Decimal解析后用Fraction精确累加、比较和判并列；28位Decimal仅用于展示。无商户或拒付筛选，不输出逐行个人/交易字段，不读产品答案或重新评分。金额非负等是此canonical算术helper的支持域，不是新评分门。

## 3. Cargo：既定27条与更广自洽语义分开

- **观察**：[旧checker](<../../2-用例/tb-cargo-plan/checker.py>)只把magnetic_heading_deg列为必需键，固定evaluate函数内没有该字段字符串读取；true_heading只检查与course不同。[旧spec](<../../2-用例/tb-cargo-plan/spec.md>)本来就这样约定，不能据此说checker违反其合同。
- **证据**：[cargo_heading.py](<cargo_heading.py>)只对源码做AST解析，不导入或运行它。三个合成例分别展示一致、仅磁航向偏180度、真/磁同时偏30度；补充诊断可区分这些数学关系，不产生grade或reward。
- **解释**：任务的航向自洽语义比旧27条有限检查更广。新纯函数按wind FROM、真航迹和**出发地**东磁偏角，检查magnetic=(true−declination) mod 360；这是补充覆盖，不追改旧断言。
- **未排除因素**：这不是实际错误PASS实验，不读产品计划、候选或真实航向。未核TAS/ISA、天气选择、航路、重量燃油等，不能称完整航空验证器。正向地速须大于1e−12×max(TAS,风速,1) kt，刻意不支持接近零的微小正值；这是数值域，不是航空标准或精确近零物理分类。
- **可复现范围**：固定七来源；圆周角差比较单个一位小数角允许0.05度，真/磁关系允许0.1度，另有1e−9度浮点裕量。这些容差仅解释合成、精确输入与一位小数角，不改旧27/20阈值、五关键门或历史成绩。

## 4. 单一离线入口与信任边界

从仓库根目录运行（Python 3.9+标准库，无额外依赖）：

```bash
python3 4-打分细则/判据边界复核-2026-11-05/verify.py --root .
python3 4-打分细则/判据边界复核-2026-11-05/test_verify.py
python3 -O 4-打分细则/判据边界复核-2026-11-05/test_verify.py
```

[verify.py](<verify.py>)核三份新helper的固定SHA，再编译**同一批已核字节**；不使用可能读取缓存的导入loader。三项derive共核18个固定旧来源，生成聚合与非计分例，并核正式表全部单元格/理由在三版报告逐字节一致（现行[v1.10](<../../5-评测报告/竞品评测报告-v1.10.md>)==[v1.9](<../../5-评测报告/竞品评测报告-v1.9.md>)==冻结[v1.8](<../../5-评测报告/竞品评测报告-v1.8.md>)；2026-11-09 随 v1.10 发布更新对齐对象，v1.8 冻结链保留），最后逐字段比较[audit.json](<audit.json>)。`--rebuild`只打印重建结果，不写文件。

[test_verify.py](<test_verify.py>)显式装载本目录三个已列出的测试文件，不做目录发现。各helper测试把两层分开：直接给纯函数合成正负例检查语义；再检查固定来源hash、路径、重封/篡改拒绝。新派生件不是历史原件，不认证源材料的历史真实性；SHA层拒绝改源，不代表纯关系检查能识破所有同步伪造。

路径检查针对已解析canonical根内的固定来源及子路径；不提供任意主机路径的无符号链接保证，也不消除文件系统竞态。Python/标准库/运行环境仍需信任。只读软件测试、机器复算均不是真人见证、产品样本或OS沙箱证明。旧报告、spec、truth、checker与历史现场原样保留，公开历史依赖缺失和未知不因本页而关闭。
