# 原生自报用量：算式、累计闭合与覆盖分开

对 [11-25 同题批次](<../../3-表现现场/r20261125-five-lcb/README.md>) 的两次既有 CLI 运行做静态复核。DSH 的 15 条步用量由同会话、轮和步号绑定；Codex 的 37 条原生主记录由同一本地任务内的身份和位置绑定，每条另有同区间镜像。镜像和 stdout 是同一运行的不同记录面，不能加为新样本。以下说的是**留档自报**，不是固定供应商合同、账单或实际摄入。

## 算式只在选定候选族内可辨

| 固定档 | 候选搜索（系数 −1/0/+1，常数 0） | 全支持仍相容的三式 |
|---|---:|---|
| DSH 15 步 | 81 | `total = input + output + cacheRead + α×cacheWrite` |
| Codex 37 条 | 243 | `total = input + output + α×cacheWrite`；本候选族中 cached、reasoning 系数均为 0 |

两档原生 `cacheWrite` 都是严格整数 0，因此 α 可取 −1/0/+1；从任一条、删任一条得到同样结果。若构造非零写入，原来等价的公式可以分歧。缺失、布尔和小数零不是同一个计数；本候选族以外的规则也未排除。DSH 14/15 条的 cacheRead 大于记录里的 input，不宜把它解释为该列的子项；Codex 在这 37 条内 cached≤input、reasoning≤output，只是本档投影内的约束。

用本产品后位置减前位置，改变输入轴本身就能改变方向。DSH 把 `input` 换成 `input+cacheRead+cacheWrite`，105 对中 68 反向、37 同向；Codex 把 `input` 换成 `input−cached`，666 对中 400 反向、264 同向、2 对其中一轴持平。这些是归档位置的配对诊断，不是独立样本或跨产品 Token / 费用比较。两本地同名档位和窗口声明也不是运行时的同等约束。

## Codex：末显相等不能证明逐条齐备

在 37 个已绑定的原生组上，原生六分量逐条累计与本地轮内、线程内及镜像累计相合；公开末显只有五个共同字段。对派生分别判 **P** 保留组的主条与镜像是否配对，**R** 从零递推的保留累计是否相合，**F** 保留主条求和能否重算固定末显，**L** 最后一条主累计是否与固定末显相同，**O** 组位置与选定原投影是否相同。P 不支持时联合递推 R 记不可核，仍可做 F/L 的有限算术比较。

| 各 37 个单删派生 | 结果 |
|---|---|
| 删主条 | 固定末显示求和均不符；仅删最后一主条才让 L 不符，P 不支持 |
| 删镜像 | F/L 均相符，P 不支持，R 不补判 |
| 删整组，不重算 | 36 次中途累计断而 L 仍相符；删末组，R 相符而 L 不符 |
| 删整组，重算保留累计 | 37 次递推重新相合，但 F/L 都不能匹配固定末显 |

另做 666 种两位置交换，主逐条值和对应镜像同步互换，而位置身份不动。每项的六维全和、固定末显示仍相同，未重算时 R 全部报差；重算累计后 P/R/F/L 全过而 O 全异。等量跨组转移给出同样边界；合成零增量组若整体消失，连递推和固定末显示都看不出这项缺漏。**固定末值能约束某些非零缺条，但不能认证过程无遗漏、无错配或来自原件。**
