# 合成联接标签：一次交换敏感性闭式复算与组合预算反证

[上一页](<../Responses生命周期与同源副本-2026-11-27/README.md>)检查了生命周期门的结构盲点。本页回到更早提出的另一个问题：报告披露的联接统计在多大程度上仍能约束真值？固定一个纯合成两层四行模型，比较「零错误」「至多一次交换」「仅边际」三种可达值集，并独立复核 2026-11-27 作者级预注册的全部计数。不新增产品运行，不读取判卷材料。

## 固定模型

- 8 行无语义编号；层 1 = 行 0..3，层 2 = 行 4..7。行 (0,1) 与行 (4,5) 为报告已联接位，行值 (a1,a2)∈{0,1}²；真实联合表共 4⁸ = 65,536。
- 报告披露每个已联接位的两轴值，零错误报告键 K =（两层的联接对与残差对），键空间 = 16·9·16·9 = 20,736。
- 错误模式唯一：至多一次，且只能在某一层的两个已联接位之间交换第二轴披露标签。交换把该层联接交集从 ph+qj 变为 pj+qh，Δ=(p−q)(j−h)∈{−1,0,1}；两列和不变，故残差（由已知边际反推）在 65,536 个真值上全部不变。
- 三解集：SolSet0（零错误可达）、SolSet1（一次交换预算，闭式=SolSet0 平移 {0,Δ₁,Δ₂} 的并）、SolSetM（仅边际的 Fréchet 界区间）。总真实交集 J=Σ_L[ph+qj+t_L]。

SolSet1 闭式与逐真值可达集在 65,536/65,536 吻合，与逐键穷举在 20,736/20,736 吻合；平移并无洞违例 0；SolSet1⊆SolSetM 违例 0；仅边际闭式与按边际签名穷举在全部 625 个签名上吻合。

**见证例**：层 1 行 [[0,0],[1,1]]、层 2 行 [[0,1],[1,0]]，各层两未联接行全 (0,0)。J 零错误=1，交换层 1 标签后=0，交换层 2 后=2，同一报告键的可达集恰 {0,1,2}——一次标签交换足以翻转交集方向且数值超出零错误值两侧。

**组合预算反证（如实登记的否定结果）**：若把预算放宽为两层各允许一次交换（Δ₁+Δ₂ 可组合），648 个键出现预算外新值（见证键 Δ₁=Δ₂=+1 时单换可达 {0,1}、组合可达 {0,1,2}），「预算集恰为 {0,Δ₁,Δ₂}」在该放宽下不成立；但组合后平移并无洞违例仍为 0——按此方向构造可分辨性不成立，预注册错误模式的单次限制因此不可省略，如实记录。
