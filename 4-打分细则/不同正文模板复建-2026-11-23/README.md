# 借用不同正文的模板复建首请求（11-23）

在 [只用日志与借模板重建](../只用日志与借模板重建-2026-11-23/README.md) 的固定档案内换一个对照：用目标组的本地事件及另外两组的末个主请求来学习适配模板，离线复建目标组的首个主请求。每折的两份训练正文彼此不同，也都与该折目标正文不同。训练只借固定键序、已登记的适配字段与工具包装，不借训练消息正文或工具载荷，也不借目标请求做拟合。

每折在打开目标请求正文与配套捕获收据前，先锁定候选或拒绝结果。普通与优化模式的内部非作者复核均为 **3/3 严格整树及原始正文字节相同**；按同一口径只用目标本地事件则 **0/3**。三份目标归档按正文摘要和长度分为两类，收据各自绑定。只翻转一份训练请求的适配布尔值时，模板失去共识并提前锁定拒绝；两份都翻转时仍可构造，但整树和字节均不匹配。独审另将应学习的用户包装键改成别名，也在打开目标正文与收据前锁定拒绝。

这是把完全相同的训练正文排除后、在三份既有归档内得到的条件复建，不证明模板形态是新的，也不是未来运行的预测、原生日志独立完足或受控第三方原件核验。不更改既有分数和冻结规范。
