# DSH Chat 重复工具类型与同键分片复核（11-23）

三个既有归档共 34 个客户端侧 Chat 捕获，原样均在固定物理口径闭合。28 个工具响应共 29 个键，29 个首项以及 724 个后续项的类型均为 `function`；另 6 个响应以 `stop` 结束，不进工具对照分母。**物理帧、同键参数字节与严格对象、类型资格、原件绑定是不同证据。**

| 只在原档副本上改变一项 | 固定工具域结果 |
| --- | --- |
| 去掉预选的一处重复类型；或按离线规则把预选参数片分成两片 | 各 28/28 同键参数原串与严格对象保持；重分片改变物理派发与片数 |
| 将后续类型改成同宽错误字符串、删首项类型但保留后续声明、将后续类型改成显式 `null` | 各 28/28 保留物理闭合与所选原串/对象，但失去类型资格；允许省略重复声明，不等于填 `null` |
| 把一片移到另一键 | 无索引平拼 28/28 不变，原目标键的原串和严格对象 28/28 可比且不同；全键联合资格 0/28 |
| 末行可见但未派发 | 按预定每档一例：3/3 诊断仍可见，0/3 物理闭合 |

移片对照中，作者按整流找到一个后来绑定的邻键，独审按移片当时的键选择孤键；两法对原目标和联合资格的裁定一致，不能合并目的键类别。按作者固定选法，只有 1/28 的全键原串可比且不同，全键严格对象 0/28 可比。另一个独立近错只改包内标识复用，也会失去绑定资格，尽管内容不变。

这只校准已见载体的有限转换，不补判[早先纯分片对照](../SSE分片与参数投影-2026-11-23/README.md)，也不证明客户端会发送、上游会接受或产品会实际执行。原件、历史分数和[试行冻结状态](../观测规范冻结门清单-2026-11-23/README.md)不变；内部非作者原档复算不是外部第三方核验。
