# 同一题源，不等于相同的可见输入

对 [11-25 同题运行](<../../3-表现现场/r20261125-five-lcb/README.md>)做离线复核。共同 [任务说明](<../../2-用例/lcb-recent-hard-4/instruction.md>) 为 2,292 字节，[题源](<../../2-用例/lcb-recent-hard-4/inputs/problems.json>)为 7,884 字节。**在所选早期归档回包中，Codex 保留完整题源原字节，DSH 保留编号后的源前缀，豆包用多个输出覆盖所选字段。** 这区分的是归档里的证据，不是四个模型实际看到的上下文。WorkBuddy 未送达，不当作零字节的第五臂。

## 在截断点前，什么完整可见？

固定选取 73 个完整值，不是题源的所有 JSON 字段：每题任务正文、输入、输出共 12 值；约束项 20 值；样例输入、输出、说明各 11 值（空说明也计一个值）；公开／隐藏声明计数 8 值。后三题的键值输出按固定结构比对，不当作原 JSON 文档。

|归档端点|题义|约束|样例输入|样例输出|样例说明|声明计数|
|---|---:|---:|---:|---:|---:|---:|
|Codex 完整题源回包|12/12|20/20|11/11|11/11|11/11|8/8|
|DSH 编号回包|12/12|20/20|11/11|10 完整、1 部分|8/11|6/8|
|豆包仅重编码前缀|6/12|9/20|5 完整、1 部分|5/11|3/11|2/8|
|豆包三个题源回包合看|12/12|20/20|11/11|11/11|11/11|8/8|

DSH 这条回包中，四题的题义和约束均完整；第 4 题第 3 个样例的**预期输出**只保留前缀，该题三条样例说明及两个声明计数也未见。保持文件总字节数不变、只改变该输出在可见边界外的一位数字，会得到不同的合法 JSON 值，而固定可见前缀不变；在可见边界内改一位，前缀则会变。相反，对豆包的上述字段派生，只在源 JSON 末尾添加合法空白，派生内容可不变而原始字节不同。两者都是离线反例，不表示历史原档真的被修改。

[DSH 后续自测](<../../3-表现现场/r20261125-five-lcb/dsh/stdout-r2.jsonl#L70-L71>)和[豆包后续自测](<../../3-表现现场/r20261125-five-lcb/doubao/trajectory-38455827958268674-copy.jsonl#L69-L70>)的命令文本显示从本地题源读取样例；归档保存了前者的 11 条 `OK`（含上述样例）和后者 4 个题级 `ALL SAMPLES OK`。这是后续被试自测的可见证据，不验执行时文件身份或预期答案，也不能把完整样例补进早期回包。归档行的先后也不是模型看见或使用这些字符的证明。

本次由项目内非作者分别复核固定载体和字段端点；不代替受控第三方。结论只适用于选定的原归档端点，不用来估读取检测召回率、建立单变量等控、归因产品差别或判卷。未增加模型或产品运行，正式 25 格、旧分和冻结口径不变。
