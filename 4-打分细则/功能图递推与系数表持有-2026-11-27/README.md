# 功能图同一递推，不同系数表持有

对 [abc387_f 题面](<../../2-用例/lcb-recent-hard-4/inputs/problems.json#L8-L19>)和 11-25 的四份归档做静态复核：四份程序使用同一树前缀和／环上同值递推，但同一递推并不决定同时持有多少系数表。下面分别计算明确程序点或阶段的逻辑槽，**不把这些值当全流程峰、RSS、时限或产品排名**。

## 共同计数依据

沿每个 `i→A_i` 的唯一出边走，必到一个环。同一弱连通分量内，相邻两点终到同一环，故每个分量恰一环。环上 `x_1≤…≤x_1` 迫使环点值相同（包含自环）。从环删去环边，给节点 `v` 固定值 `k`，每个树孩子 `u` 可独立取不超过 `k` 的值。令 `F_v(k)=∏_u S_u(k)`、`S_v(k)=Σ_{j≤k}F_v(j)`，叶 `F=1`；环分量贡献 `Σ_k ∏_{v∈环} F_v(k)`，不同分量乘积后取模。下表只检验四份可见源码与该递推、表持有路径的对应，不等于独立判卷。

| 归档 | 持有机制及局部差别 |
|---|---|
| [Codex](<../../3-表现现场/r20261125-five-lcb/codex/solutions/abc387_f.py#L18-L71>) | 叶复制缓存；子向唯一父传递或乘入聚合表。处理过的后代可留同一表的引用，不能按 `agg` 非空元素数计不同表。不同小组件的表则不会因子链复用而合一。 |
| [DSH](<../../3-表现现场/r20261125-five-lcb/dsh/solutions/abc387_f.py#L34-L71>) | 为每个非环点保存其 `pref`，另有一张未取前缀的 `arr`。环内前驱不参与树乘积。纯环没有这类系数表，但仍有其它数组与工作。 |
| [豆包](<../../3-表现现场/r20261125-five-lcb/doubao/solutions/abc387_f.py#L30-L81>) | 递归帧持 `prod`，叶新前缀形成短时重叠；星形还可持旧兄弟 `pu`，跨组件求新 `prods` 时旧 `prods/pd` 仍可能指向同一旧表。纯环没有深递归，仍集中保存每个环点的 `prod`。 |
| [元宝](<../../3-表现现场/r20261125-five-lcb/yuanbao/abc387_f.py#L27-L83>) | 一开始为所有点分配 `prod`；外层置空不立刻消除 `arr` 等局部引用；计算下一张 `pref` 时旧、新右侧求值可重叠。 |

## 固定图形与统计口径

`N=M=2025`。链为 `1→2→…→N` 且 `N→N`；星为各非环点指向 `N`；纯环为 `1→2→…→N→1`；最后一列为 `1→2→2`, `3→4→4`, …, `2023→2024→2024` 加 `2025→2025`。**系数表是不同的列表对象，别名只算一次；只乘列表长度，不计整型对象、解释器、其它数组和外层引用槽。** DSH表长度`M`，其它三份`M+1`。

| 指定程序点／阶段 | 链：对象／槽 | 星：对象／槽 | 纯环：对象／槽 | 1012 个二点组件 + 末编号单点：对象／槽 |
|---|---:|---:|---:|---:|
| Codex 拓扑后 `agg`+缓存（不是全程峰） | 2 / 4,052 | 2 / 4,052 | 0 / 0 | 1,013 / 2,052,338 |
| DSH 建表阶段峰，含临时 `arr`／右侧 | 2,025 / 4,100,625 | 2,025 / 4,100,625 | 0 / 0 | 1,013 / 2,051,325 |
| 豆包组件构造及求和阶段峰，含右侧 | 2,026 / 4,104,676 | 4 / 8,104 | 2,025 / 4,102,650 | 4 / 8,104 |
| 元宝分配及剥离阶段峰，含右侧 | 2,026 / 4,104,676 | 2,026 / 4,104,676 | 2,027 / 4,106,702 | 2,026 / 4,104,676 |

几个可反驳边界：Codex 链上别名与二点分量独立复制互为对照；环阶段 `prod` 和其切片不在 Codex 表行的统计点，0 不等于全程序无表。豆包星的 4 包含根表、旧兄弟前缀、新叶 `prod` 与新叶前缀。元宝纯环第二次算 `pref` 右侧时仍有 `N` 张 `prod`，另有旧、新 `pref`，共 `N+2`。二点组成即使同为无标号形状，若把末位自环单点重编号为首位，剥离队列首点不释放任何 `prod`，同一阶段也可达到 `N+2`；本表 `N+1` 只适用于固定编号，不能当拓扑不变量。

## 复查和限制

仅运行独立编写的 [图形与整数校准](<calibration.py>)：`python3 -IB calibration.py` 或 `python3 -IBO calibration.py`。脚本计环、非环、深度，并核表中槽数，不模拟候选的系数 DP，也不读取或执行归档题解、历史命令、参考解、隐藏答案或判卷器。两档输出字节一致；项目内非作者另核四份源码、阶段边界以及重标号反例，不代替受控第三方核验。

结论限于固定四份归档和固定程序点：相同递推可有不同持有机制，是否造成实际内存压力、时限变化或得分差异仍未知。没有新的产品运行，不回填正式 25 格或旧分，也不解除 11-25 的判卷隔离限制。
