# 工具标识可改名，普通正文不能一并归一（11-23）

取既有两条 DSH 深链的 29 个主请求，只比较前次固定的 13 个跨档后继位置。两条链都保留原样；定界的一段额外错误调用及结果，只在比较投影中移除。移除前新旧两种比较各为 13/13 不等；移除后，旧全局字符串替换与新角色绑定比较各为 13/13 等值；未经归一的严格字段仍 13/13 不等。另列的非消息字段在 13/13 等值。这是固定客户端请求的内容对照，不是实际客户端或服务端删了一段。

新比较只将 **助手工具调用标识 ↔ 工具结果引用**按位置一致改名，并保留对应顺序、每个调用的唯一性和其余字段。两个角色的位置和边均有效才比较；缺引用、引用错绑或调用标识重复时标为不可核，而不由字符串替换补证。12 条合格真实格式基底的五类离线对照显示：两种方法都保留有效的成对改名；旧方法对正文里仅看似标识的改值仍判等，新法 12/12 判不同。旧方法也把错误引用及重复调用判等（各 12/12），新法不认证；缺结果引用时旧法判不等，新法保留为绑定不可核。独审另构造两张同样有效、结果正文相同但结果父调用次序相反的双调用图：旧法判等，新法判不同。

这并未推翻旧 13 对的有限等值结果，只说明它不能靠全局替换推广。没有重新运行产品、改历史裁决、或据此认证工具实际执行、后端上下文与跨产品机制；内部非作者从钉定归档复核，不是受控第三方原件核验。参见[原深链比较](../请求侧深链与轮间文本-2026-11-17/README.md)。
