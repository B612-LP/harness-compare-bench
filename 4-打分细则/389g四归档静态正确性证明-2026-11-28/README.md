## 题意与主张范围

对每个 M = N−1 … C(N,2)，计数满足以下条件的连通简单标号图数量（mod 素数 P）：图中各点到点 1 的距离里，偶距离点数 = 奇距离点数（点 1 本身记入偶侧）。约束 2 ≤ N ≤ 30（偶）、P ∈ [1e8, 1e9] 素数。

**主张限定**：四份归档在契约合法输入（公开 problems.json 锁定的题面约束）上终止且逐字节输出真值 mod P。不主张运行时性能、隐藏测试、模型路由或其他题目。

## 核心引理（PROOF.md 第 1 部分）

- **H1（BFS 分层双射）**：连通图中 BFS 层是良定义的；跨层边只存在于相邻层，且每个非首层顶点至少有一条指向前一层的边。把「图」映射为「层划分 + 层内边集 + 相邻层跨边集」，是双射。
- **H2（转移计数，容斥）**：新一层 s 个点、上一层 a 个点时，跨边集须满足每新点至少一度；「每新点至少一」由容斥 Σ_j (−1)^{s−j} C(s,j) (1+x)^{aj} 计数，层内边自由取 (1+x)^{C(s,2)}。
- **H3（奇偶记账与门）**：平衡条件 ⟺ 偶层总尺寸 = 奇层总尺寸 = N/2。以 (末层大小 a, 已用点数 u, 奇偶记号, 偶侧已用数 ev) 为状态做 DP，可单调剪枝（任一侧已 > N/2 即弃）。
- **H4（直接边数 GF：DSH、元宝）**：两份归档以稠密多项式 (A−1)^s 形式累积边数生成函数，输出 [x^M]，即直接实现 H1–H3。
- **H5（平滑恒等式：Codex、豆包）**：两份归档以「势配对」薄多项式累积，输出 Σ_W T[W]·C(W,M)。由恒等式 Σ_j (−1)^{s−j} C(s,j) (1+x)^{C(s,2)+aj} = (1+x)^{C(s,2)} ((1+x)^a − 1)^s，薄形式与直接形式输出相同真值（H2 的容斥两侧等价）。
- **H6（肢打包安全界）**：dsh 以 9 字节整数打包「层长 + 两项 mod P 系数」乘积，最大 436·(P−1)² = 435999944192001785856 < 2^72；元宝同构 10 字节 < 2^80。均不溢出（N ≤ 30）。
- **H7（终止）**：DP 状态数有限（N ≤ 30、状态四元组有界），每转移严格消耗至少一个新点。

第 2–5 部分给四归档逐行映射：Codex C1–C8、DSH D1–D8、豆包 B1–B7、元宝 Y1–Y9。

## 诚实记录（verify 实现侧调试）

作者 verify 首跑 FAIL 后定位三处**实现侧 bug**（非引理/非归档错误），均已修复并如实记录：

1. 两路 GF 的终态携带写成了无条件覆盖（`nxt[key]=poly`），字典迭代顺序不利时会把同桶已合并的贡献覆盖丢失——N=4 顺序侥幸、N=6 恰好踩中（平衡树少 120）。改为合并式携带。
2. direct GF 累积时漏掉与已累积多项式的卷积（只合并了转移向量），thin GF 同结构故未暴露此错。补卷积。
3. GF 返回未剔除零计数键，字典相等性被零键污染；样例比对处对 GF 字典裸索引 `d[m]` 改 `.get(m,0)`。

修复后三路交叉全绿；此过程再次验证「独立真值轨 + 官方样例锚」对作者侧实现错误的捕获能力。
