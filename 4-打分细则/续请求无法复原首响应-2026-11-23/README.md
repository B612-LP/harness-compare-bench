固定复核 DSH 五份既有归档的首主请求、其客户端捕获响应和既有登记选定、经本次绑定的主续请求。中间的登记包仅查元数据，不对正文判角色。五个首请求两两 **10/10 原字节相同**；五份响应均在固定口径闭合，各自两个工具槽均能对到续请求。从十个重叠配对看，续请求中的工具图在限定标识重命名后均相同；但首响应原字节和工具标识十对都不同，物理记录形状和实参分片各四对不同。工具名、重组实参 UTF-8、严格对象及所选直接载体的值均两两保持。用规范化续请求反查首响应，不能恢复原表示差异；五档不能当成十次独立试验。
