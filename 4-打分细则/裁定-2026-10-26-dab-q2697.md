# 裁定：DAB q2697 判分与归因口径（2026-10-26）

> 裁定编号：ADJ-DAB-2697-20261026-r1 ｜ 状态：**生效** ｜ 对象：`dabstep-payments-10` 题 q2697（一题，不外推其他 9 题）
> 性质：证据性裁定。只约束该题的判分口径解释、能力归因使用与后续复核触发条件；**不修改 checker / truth / 金标 / 任何已记录分数**。
> 本裁定为[第 2 期周报](<../6-周报/2026-10-24-第2期.md>)§三目标 2 的交付物，固化[判卷审计](<判卷审计-2026-10-24/README.md>)与[补充材料](<../5-评测报告/补充材料/2026-10-24/README.md>)已完成的调查结论。证据索引见 §7（正文以 [E#] 引用）。

## 0. 裁定要点（速览）

1. q2697 **维持官方兼容分口径**（official-compat，scorer `dabstep-official-port-v0.1`），不强制精确匹配冻结金标 `E:13.57`，也不为该题加严阈值。
2. q2697 及其两轨分差**不用于产品能力归因**：不得因该题失分判定任何产品/模型/Harness 能力弱，也不得因通过判定能力强。
3. 输出字段按 **ACI**（Authorization Characteristics Indicator，A–G 枚举）理解；guidelines 中 `{card_scheme}` 为题面笔误占位。
4. 无匹配费率交易**不得静默按 0 计**；须显式披露覆盖率并标注未定价。
5. 多规则聚合 min/mean/max/sum 四种**显式声明**的口径等价可接受；不得为凑金标反向选择聚合。历史分数影响为零，历史批次不重判（§4）。

## 1. 现象

**题面自相矛盾**（[E1]，`inputs/questions.jsonl` task_id=2697，sha256 `d99d3109…` 与 [E2] truth 记录一致）。题干要求选 ACI：

> "For Belles_cookbook_store in January, if we were to move the fraudulent transactions towards a different **Authorization Characteristics Indicator (ACI)** … what would be the preferred choice considering the lowest possible fees?"

guidelines 却把答案格式写成卡组织字段：

> "Answer must be just the selected ACI … in this format: **{card_scheme}:{fee}**. If a question does not have a relevant or applicable answer …, please respond with 'Not Applicable'"

两个取值域互不重叠：ACI 按 manual §4 为单字母 A–G（[E8]）；`card_scheme` 按 manual §5 与 `fees.json` 实际取值为 GlobalCard / NexPay / SwiftCharge / TransactPlus（[E8][E3]）。同一题存在「ACI 字母」与「卡组织名」两个合法输出维度。

**冻结金标**：`E:13.57`（[E2] `truth.json` gold["2697"]，truth sha256 `9e6e395f…`，与调查冻结件 [E3] `dab-q2697/frozen-truth.json` 同哈希）。

**历史预测**：Codex 首跑 `E:41.66`；Codex-r3 / DSH-r2 `E:16.63`；DSH-r3 `C:131.20`；豆包 `NexPay:3.45`；另有一场未被复算选中的早期 DSH 答案文本恰为 `E:13.57`（[E3][E6]）。八场选定场在两轨下 q2697 均判不通过（[E3] receipt-sensitivity）。

## 2. 原因线索（各附当时验证证据）

**线索一：输出字段歧义。** 题干 ACI vs guidelines `{card_scheme}` 是两个不同字段；豆包实际提交了 `NexPay:3.45`，说明该歧义可被真实运行踩中（[E1][E3]）。兼容 scorer 只抽取答案中第一个数值，字段维度完全不参与判定（§3.1、§6）。

**线索二：50 笔欺诈交易无匹配费率。** 独立计算（不导入产品脚本/checker，协议先行固定，[E3] protocol.md）：Belles_cookbook_store 2023-01 共 1201 笔 / €113,260.42，欺诈 94 笔 / €11,680.62（月欺诈金额率 10.313064%）。逐笔只替换 ACI 后：**E 仅 44/94 笔有适用费用规则，50 笔未定价**（D 44/94，F/G 30/94，A/B/C 94/94）。E 已覆盖部分的 min=16.630562、mean=41.6610305、max=66.691499、sum=77.681576——历史预测 `E:41.66` 恰为 covered mean、`E:16.63` 恰为 covered min 的数值解释（数值吻合不证明作者采用同一算法，[E3]）。manual 对**空列表是否通配**（fees.json 含 112 条 `aci:[]` 规则）无明确契约；把缺失当 0 计会系统性低估成本（[E8][E3]）。

**线索三：多规则聚合方式不唯一。** manual 未定义一笔交易同时匹配多条规则时的优先级/合并规则（[E8] 无 precedence/combination 表述）。完整覆盖 94 笔的 A/B/C 在四种显式聚合下总值（[E3] results.json）：

| 聚合（每笔取…后求总） | A | B | C | 最优 |
|---|---:|---:|---:|---|
| min | 81.810213 | **54.208933** | 81.044602 | B |
| mean | 89.82079225 | **77.87079725** | 88.70913825 | B |
| max | 95.809080 | 99.144012 | **93.833023** | C |
| sum | 132.005593 | 202.972264 | **131.197293** | C |

**最优 ACI 随聚合口径改变**；所测各口径（含排除 refused、按笔数欺诈率、按 scheme 分区、空列表不通配等敏感性）均未得到 `E:13.57`。结论边界：这仅说明**冻结金标未被唯一复现**，不证明 gold 已证错，也不构造替代金标（[E3][E5]）。

## 3. 裁定

### 3.1 判分口径：维持兼容分，通过条件如下（自 [E9] checker.py 逐行读出，非转述）

**整场** `reward = 1` 当且仅当三条件同时成立：① `answers_format` 结构门（10 个 task_id 各恰好一行、answer 为 JSON 字符串、UTF-8、≤2 MB）；② `input_integrity` 门（附带的输入副本若存在须与 canonical SHA-256 相同，未附不扣分）；③ 10 题官方 scorer 得分率 ≥ 0.8。

**q2697 单题兼容通过条件**（`question_scorer(pred, "E:13.57")` 的实际执行路径）：pred 双方 strip/lower 后——①任一侧匹配千分位/纯小数模式才走数值分支，`E:13.57` 类含字母前缀串不匹配，跳过；②任一侧含 `;` 或 `,` 才走列表分支，跳过；③ `extract_numeric` 以正则 `(\d*\.\d+|\d+\.?\d*)%?` 取**第一个数值**——**负号不在正则内、字母前缀被忽略**（`NexPay:13.57`→13.57，`E:-13.57`→13.57）；④ `compare_numeric`：相等，或双方 <1 时 `isclose(rel/abs=1e-4)`，或**按较少小数位四舍五入后相等**（`13.6`≈`13.57`），否则回退 `isclose(rel/abs=1e-4)`；⑤双方均无数值才退化为字符串归一/包含/相似度>0.95。

即：**兼容分只看答案中第一个数值是否在上述容差内等于 13.57；ACI 字母、卡组织名、正负号、前后缀文字一律不参与**。严格轨 `signed-aci-v1`（[E4][E9]）对 q2697 另要求全串 `ACI:fee`（正则 `([A-Za-z]+)\s*:\s*([+-]?数)`）、ACI 大小写归一相同、金额保留符号、`isclose(rel/abs=1e-4)` 且无较少小数位捷径；但单题拒绝不否决整场（9/10=0.9 仍过线），且严格轨只是**格式契约**，通过不等于业务推导正确。该题两轨分数均照旧记录，不互换、不覆盖。

### 3.2 能力归因口径

q2697 的通过与失分（含 official-compat 与 strict-contract 的分差）**不得作为任何产品能力归因依据**：不得因该题失分判定产品/模型/Harness 能力弱（题面合同三重不唯一——字段、覆盖、聚合——之下，失分只证明与未唯一验证的金标不一致）；也不得因通过判定能力强（兼容分通过可由照抄金标数字达成，见 §6）。冻结分数保留用于审计与敏感性，不参与能力结论（与 [E6] §1「已确认的 q2697 格式歧义单列，不将冻结失分自动解释为能力错误」及 [E10]「归因按证据推进」一致）。八场选定场剔除 q2697 后 headline 二值均不变（70→77.78 一类 weighted 变化不改变 0/0），佐证撤出该题不损失判别信息（[E3]）。

### 3.3 输出字段口径

按 **ACI** 理解：manual §4「The Authorization Characteristics Indicator is a field that facilitates the identification of the transaction flow submitted to the acquirer」，枚举 A–G（[E8]）。合法答案形态为 `{ACI字母}:{费用}`（如 `E:13.57`）；guidelines 的 `{card_scheme}` 视为官方题面笔误占位，卡组织名（NexPay 等）不是本题答案字段。该口径只约束「正确理解」的定义，不回头改判已提交的 `NexPay:…` 答案（仍按 §3.1 兼容分记录）。

### 3.4 未匹配交易处理口径

无匹配费率的交易**不得静默按 0 计入成本**。可接受处理：①显式披露覆盖率（如 44/94），仅对已匹配部分计算并标注 covered-only；②或声明该 ACI 方案不完整、不参与最优比较（full-cost 记未知，不以 0 代替）。把 50 笔缺失当 0 后宣布某 ACI 最优 = 不可接受（依据：[E3] protocol「Unmatched transactions must NOT silently cost zero」及 [E8] 无缺失定价契约）。

### 3.5 多规则聚合口径

一笔交易匹配多条费用规则时，**min / mean / max / sum 四种聚合在显式声明的前提下视为等价可接受的口径**（manual 无优先级/合并契约，[E8]）；采用任一种均须同时披露最优结论对聚合方式的敏感性（min/mean 下 B 最优、max/sum 下 C 最优，§2 线索三）。不可接受：未声明聚合方式；或以逼近金标 13.57 为目标反向选择聚合/假设。本裁定不指定唯一聚合，不据此改金标（依据 [E3]）。

## 5. 停止追查条件与下一步

本裁定生效后，q2697 调查**关闭为「受控未知」**，不投入无限假设穷举，不为凑答案选算法（对齐 [E10]「未知需要管理：说明下一步及停止追查条件」）。满足任一条件时重新打开：

1. **官方口径到手**：Adyen/Hugging Face 发布数据字典、题解或评分口径说明，能唯一复现 `E:13.57` 的完整推导（字段定义 + 未匹配处理 + 聚合规则三要素齐备）；
2. **官方修正题面**：questions/guidelines 更新，消除 ACI vs `{card_scheme}` 矛盾；
3. **新独立证据**：出现能唯一复现或证错冻结金标的新证据。

下一步（有限动作）：向官方公开渠道求证上述口径；期间该题分数照常按 §3.1 记录、按 §3.2 隔离于能力归因。若重新打开后金标变更，按 §4「未来版本约束」走版本化修订，历史批次处理另行裁定。
