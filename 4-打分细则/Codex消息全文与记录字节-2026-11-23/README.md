# Codex 消息全文与记录字节复核（11-23）

只复核此前五组原生归档与 12 份代理转帧后的客户端侧 Responses 捕获，没有独立第二路上游原档。选取有完整终末端点与段序列的 assistant 消息文本（不等同任务最终答复），并在同组原生完成项按内容做双向有限匹配。**六对均有逐字全文等值，但六对都不是同一份记录字节。** 客户端捕获的原始 item 对本地整行（计或不计尾换行）、以及对本地内嵌 item，均为 0/6 字节相等；单段文本字段的原始 JSON token 和解码后全文均为 6/6 相等。这是同组、固定观察面内的一一对应，不是跨层共享身份或时序的证明。

离线在五组同时拆开全部六个合格单段，原有全文匹配仍为 6/6，旧「任一叶等于本地全文」判法降至 0/6。反向对照把两种段结束事件分别错接到另一实际条目：两个控制各有 5 个合格场景，均不再确认严格配对。独审又把该段首个增量移到段开启之前，维持其余内容和连续序号；6/6 不再确认段链，但该端点所见全文及本地值均未被抹掉。

这不是新的客户端捕获，不能据此判断屏幕渲染、跨版本复现或 Harness 因果。现有 [双线冻结门](../观测规范冻结门清单-2026-11-23/README.md) 保持未冻结；本次为内部非作者从封内材料独立复投影，不是第三方受控原件核验。历史得分与冻结材料不改。
