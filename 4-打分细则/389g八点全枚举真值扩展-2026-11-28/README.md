# abc389_g N=8 全枚举真值扩展（2026-11-28）

[三题小实例四归档真值复算](<../三题小实例四归档真值复算-2026-11-28/README.md>)（页4）对 abc389_g（Odd Even Graph）的穷举真值仅覆盖 N≤6；389_g 也是五题现场四题中唯一未给静态正确性证明的题（完整层图 DP+边数多项式证明经两轮评估均留未来窗）。本页用 C 全枚举把真值覆盖扩到 **N=8**（2^28≈2.7×10^8 图），四归档实跑对账。零新增产品运行；归档执行属既有固定档案离线复算。

## 方法与校准链

`brute.c`（本目录）：K_N 边子集全枚举 → 邻接位图 → FIFO BFS 连通性 + 距离奇偶计数（点 1 算偶侧）→ 按 M=N−1..C(N,2) 直方。`cc -O2` 编译（默认 SDK 损坏时自动回退 `-isysroot MacOSX15.4.sdk`），N=8 实测 9.2 s。

校准（verify.py 内建，任一失败即 FAIL）：

1. **C N=4 = 官方样例1** `12 9 3 0`；
2. **C N=6 = 官方样例2** 全 11 值 `810 2100 3060 3030 2230 1210 450 100 10 0 0`；
3. **独立 Python N=6 全枚举（FIFO BFS，未参考 brute.c）= C 逐值一致**。

说明：奇 N 的平衡图恒为零（偶距点数+奇距点数=N 为奇，不可能相等），故奇数尺度对校准无信息量；校准取偶 N=4、6。

- 作者校准用 Python 初版用栈序 `pop()`（DFS 化）取 dist，非最短距离导致 N=6 与 C 不一致（逐桶漏计 0/−60/−150/−200/−260/−240/−110/−20/0/0/0，合计 1040；60 为首失配桶 M=6 的差值——独审复核更正）——**bug 在作者的 Python 校准件**，C 与官方样例2 逐值一致；改 FIFO 后三方一致。交叉校准再次证明其价值（第三例，继页3 sample1、页6 (2,31)）。
