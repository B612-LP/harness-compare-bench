# DSH Chat 工具声明：字节、顺序、基体和 `strict`（11-23）

复核三组既有 DSH Chat 归档的 34 个绑定请求，不读响应正文。31 个主任务请求各有 22 个具名工具声明；所选 `tools` 数组的原始 JSON token 都为 20,527 B，且 31/31 逐字节相同。682 个声明位置的直属 `function.strict` 都是 JSON 布尔 `false`；另 3 个已标定的辅助标题请求均无 `tools`，不把“没有数组”记成“空数组”。取前两组各自首个合格主请求作有限参照，第三组 14 个主请求同时匹配两份参照：它们并不构成 14 个独立复制，也不能靠声明识别来自哪组。

离线对照分别改空白、数组次序、直属 `strict` 的值或存在性、名称唯一性，以及声明其他内容。改空白只改变原 token；数组换序不改具名声明及基体；在按名各轴中，单改直属 `strict` 的值会改变整份声明及该字段的值比较，不改名称集与移除它后的基体；名称重复时不能做按名比较。独立近错验证：两个不受支持的值即使类型一致，也不能因此判等；嵌套同名字段不能冒充直属 `strict`。这些对照不作为产品运行。

这里只能确认已捕获的请求声明。不能从 `false` 推断服务端行为、参数校验是否启用、运行时策略或未来版本。参见 [Chat 捕获支持域](../支持域与漂移判定-2026-11-23/README.md)。
