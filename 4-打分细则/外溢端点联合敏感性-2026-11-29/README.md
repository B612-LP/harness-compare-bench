# 外溢字节：分开看都判高，合起来仍可能未知

同一批旧客户端捕获，**缺同事实端点**和**先后影响未知**不能分开判过、再当作一起判过。对每套固定五对的回放，单看任一不确定性都判「短回包侧累计字节偏多」时，合起来仍可能跨回中带。这里的「偏多」指五对 `B/A` 中位 **严格大于 1.10**，不是实际漂移、成本或设置效果；B 是目标结果呈现起初较短的一侧。

## 固定范围与结果

用[旧公开逐包账](<../端点支持与请求字节-2026-11-23/evidence.json>)既有同事实端点 E2 和主包标注。14 条旧比较边跨三组，能组成 48 套各含五条、互不共享运行的最大组合；组合间仍可共享运行。对每套穷举只遮一对或两对，分别遮 A、B、或两侧，从 E2 起隐藏受遮臂的主包后缀；每种侧别分母分别为 240、480。比较小于 `0.90`、闭区间 `[0.90,1.10]`、大于 `1.10` 三带；不能排除跨带就报未知。

| 假定先后乘子范围的上限 Γ | 遮一对 B：两单项均高、联合未知 | 遮两对 B：两单项均高、联合未知 |
| ---: | ---: | ---: |
| 1.00 | 0 / 240 | 0 / 480 |
| 1.02 | 0 / 240 | 0 / 480 |
| 1.05 | 12 / 240 | 24 / 480 |
| 1.10 | 12 / 240 | 24 / 480 |

这四档下，遮 A、遮两侧或无遮蔽均没有这种「单项同带、联合未知」例。以 `Γ=1.05`、只遮 B 为例，联合模型在单遮中判高 72、未知 168，在双遮中判高 36、未知 444；表中只是其中因联合判定失去高判的子集，**不是全部未知数或缺档率**。逐对独立和假定共享带符号乘子的两套结果在这批旧回放中逐案相同，不能说两模型普遍等价。

## 怎么判，以及一个反例

- **遮蔽不是补值。** 只有当已绑定的同次前缀完整、能证明此前未到 E2，且**假设同一次最终确到 E2**时，已见字节 `p` 才给末值区间 `[p+1,∞)`。未遮用已核点值。两臂给每对的比值包络；五对的第三个下界及第三个上界约束中位。错绑前缀不能用，已结束但未到 E2 则目标比值未定义，不放进这个模型。
- **先后只作条件。** Γ 是预设敏感性上界，不是估出来的。逐对独立，允许各对净比乘子在 `[1/Γ,Γ]` 内分别取值；共享模型假设一个 `f` 同域，按旧主包编号 A 先取 `r/f`、B 先取 `r·f`。编号先后不是启动顺序、真实指派或实测漂移。共享模型要查临界点和间隙：例如四对恰 `1.10`，两对各为 A 或 B 先，另有一对 `1.20`，`Γ=1.05` 时两端都高，但 `f=1` 落闭中带。
- **旧账见证：** 五边按旧账出场顺序编号为 `2,5,9,11,14`，只遮第 2 边 B，`Γ=1.05`。只遮蔽和只扰动的中位下界分别为 `72973/63791`、`673150/515739`，均高于 `1.10`；一起算，逐对独立模型闭包络为 `[1459460/1339611,282723/196472]`，横跨中、高。共享模型也不知道：`f=1` 时整段高，但 `f=729730/701701` 时第三个下界恰为 `1.10`。换成只遮第 11 边 A，同一套边在 `Γ=1.10` 下仍可判高；不是加一个缺口就一律无法判断。

这些是按旧账标签、给定乘子形式和范围的**条件回放**。遮后所问的实际中位仍未知；界只限所设模型，既不估真实先后影响，也不声称某条漂移路径真的会发生。五对不删整对、不用末包补；模型或标签没有先验凭据时不据此调整新实验的判带。
