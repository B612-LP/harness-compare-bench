| 主任务跨组 | 比较的包对 | 完全同字节 |
| --- | ---: | ---: |
| DSH Chat | 268 | 1 |

| 合计（同家族） | 325 | 1 |

按组对计也是 1/13，不把重复枚举当作独立试验。唯一主对即[已公开的首个分叉](../等请求的首个分叉-2026-11-23/README.md)，两份客户端响应都完成边界，工具名称与参数均不同；辅助对的文本不同，但辅助请求不补主对分母。没有 Codex 等字节主对，故没有该侧的合格响应比较，不记为“不分叉”。
