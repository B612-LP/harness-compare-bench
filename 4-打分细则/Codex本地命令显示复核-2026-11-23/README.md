# Codex 本地命令显示：同值候选不等于原生绑定

在五个已有原生会话、12 个 Responses 捕获包中，7 个响应捕获中的工具调用参数值与 7 个本地完成条目按同一运行分桶。旧检查找到 5 个同值项，另有 2 个引号形态不可核。按限定的文字解码和双向计数复核后，**3 条在本次已捕获窗口内是唯一值对，2 条只在可解码记录中唯一，另 2 条仍无法解码**。后两条不能归为不同值、缺失或未执行。即使最强一层也没有共享调用标识证实事件身份。

## 离线对照

只检查预声明的文字包裹和两种固定缝合形式，要求解码后能逐字节重建原显示；混用、重叠和未覆盖的引号拒收。不用 shell 解释或执行。

| 对照 | 完整覆盖层 | 仅可见层 | 裁定 |
|---|---:|---:|---|
| 同值切换已支持的原始缝合形式 | 0 个符合条件 | 0 个符合条件 | 不用合成样本充当原始正例 |
| 只切换两种显示前缀 | 3/3 | 2/2 | 解码值相同，覆盖层级不变；不说明 shell 选项等价 |
| 等长替换一个字节 | 3/3 | 2/2 | 值已改变，不匹配原值 |
| 仅在本地侧／仅在捕获侧添一个相同值 | 各 3/3 | 各 2/2 | 仍有候选，但不是一对一 |
| 移除显示末尾闭合引号 | 3/3 | 2/2 | 无法解码，不判值改变 |

内部非作者复核从原件得到相同分层，并发现初版误收重叠缝合；修订后，在两种显示前缀中均拒绝该反例，且不误拒仅相接、不重叠的合成样本。原样本的裁定未变。

只对照有限窗口里的文字值，不证明原生渲染算法、实际 argv、进程执行或跨会话唯一；不替代受控第三方原件核验。既有 [Responses 观测口径](<../CodexResponses观测口径-2026-11-23/README.md>) 和[未知处置表](<../未知处置表-2026-11-23/README.md>)的两条引号未知不升级；不改正式 25 格或历史成绩。无新增运行。
