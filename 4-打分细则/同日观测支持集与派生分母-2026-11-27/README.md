# 同日观测支持集：哪些分母可以合并

**结论：** [R1](<../规范不产值实现一致性与跨解析器-2026-11-27/README.md>) 与 [R2](<../wire请求面扩展-2026-11-27/README.md>) 的 820 与 1804 个归档位置，有 235 个是重复使用的同一批公开原行。按归档位置取并集是 **2389**，不是 2624，更不是 2389 次独立运行。相同字节、相同位置和派生案例应分别记账。

## 原位置、原字节和整份原档

| 单位 | R1 | R2（含公开核查） | 同位置 | 联合位置 |
|---|---:|---:|---:|---:|
| 原档路径 | 41 | 61 | 3 | 99 |
| 私有请求正文 | 19 | 29 | 0 | 48 |
| 私有响应 JSON 帧 | 566 | 1540 | 0 | 2106 |
| 公开导出行 | 235 | 235 | 235 | 235 |
| 归档观测位置（三行正文／帧／行相加） | 820 | 1804 | 235 | 2389 |

3 个公开档在两次分析中是同一路径、同存档文件且逐行字节相同。对其它位置再按原始投影字节分组：另有 3 个私有请求等字节类，从较早一侧各 1 份对较新一侧的 1、5、5 份（11 个跨组等字节配对）；私有响应 JSON 帧没有跨组等字节。全体总计 238 个跨组等字节类、246 个跨组配对；整个联合位置集在按字节去重后有 2286 类。整份原档则是不同单位：6 个跨组等字节类，14 个跨组配对，合计去重后 86 类。字节相同不能断言同一次捕获；路径不同也不能证为独立运行。较早组有一批请求和响应来自不同目录，不按共享编号配对。

**使用方法：**说明你在数归档位置、等字节类，还是以给定父支持施加的变换。一个父档可以检验多个观测门，但不能给产品样本量叠加。内部非作者从固定材料重建关键计数；这里只公开聚合，不放私有原件或摘要。独立真实运行总数、第三方原件核验、服务端实际收到的字节及保持其它条件相同的机制效果，仍不能由这些分母推出。未重跑产品、未改正式 25 格或分数。
