# 原生压缩流能恢复分片与本地坐标，不等于网络到达记录

在[同次 CLI 持久记录复核](<../同次CLI持久会话与计时边界-2026-11-27/README.md>)的 DSH 固定档上，另从原生消息的压缩分组重建内容与整数时间轨道。它与既有公开显示、原生计时属于同次证据，不增加产品样本，也并非对网络帧、服务端计时或实际执行的独立观测。

| 固定对象 | 回构结果 |
|---|---|
| 15 个原生助手消息 | 30 对块首／末，15 份流内用量与消息字段逐值同；14 个工具收尾、1 个文本收尾。回放描述字段不是另一份正文，也不认证其中签名。 |
| 压缩组 | 43 组共 38,251 个片段、38,208 个相对整数差，其中 26,853 个零差。14 个推理组、28 个工具组和 1 个文本组；另有一个明确为空的推理块，不是缺失。 |
| 工具与显示 | 14 次工具各由有名的空参数起锚和同 ID 续组构成。逐块拼接和块尾及消息字段相同；显示绑定同一步工具 ID、名称和参数规范值。推理为 13 项非空同文、1 项有显式截断标记的真前缀、1 项明确空行。 |
| 15 步本地可见端点 | 步首→首块、首块→收尾、收尾→助手消息、消息→步尾的差值和分别是 4,828、210,248、42、111,512 毫秒坐标单位；同一日志内次序满足这些锚点，不将划分命名为模型或工具工时。 |

**端点相同，不代表内部时序相同。** 对组内 `k` 个非负整数差、总宽 `D`，若 `k≥1`，有 `C(D+k−1,k−1)` 种分配；若 `k=0`，只在 `D=0` 时有空解。固定实际组宽、内容和顺序下，43 组中 29 组可另配，38,179 个内部点各可取至少另一个位置，不保证能同时各自独立任选。对这 29 组分别把总宽放到首差或末差，58 种内存变体都保组两端、语义及组间顺序；内部非作者还发现交换两个不同时间差可保持差值多重集，却改变内点。小域枚举 42 格仅校验计数式。都不是物理到达或产品重放。

**内容同值也不是来源认证。** 片位不动只删正文、错绑定续片、时间差长度错时，固定谓词可察觉；三份原生内容同步改写可重新相等，但不再是锁定投影，不说公开层也过。内部非作者复核发现普通块索引使用的相等关系可混同 `0` 和 `false`；固定 60 个普通块索引实际均为整数。这一版只给固定范围结论，不宣布通用类型验收或统一规范冻结。未披露原始文本、参数或身份，不影响正式 25 格、历史分数或受控外部复核缺口。
