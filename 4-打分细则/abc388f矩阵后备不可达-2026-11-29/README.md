# ABC388 F：固定元宝归档的矩阵幂分支为何不可达

**结论：11-25 元宝归档的矩阵幂调用在题目允许的输入下不可达。** 当 `A<B`，任意非零起始掩码在连续 `H=⌈(A−1)/(B−A)⌉·A+B` 个好格后已成为满窗；实际分支要求好段长于 `H+5`，且模拟 `H+5` 步仍未满或归零。`A=B` 则走旋转，不经过该后备。`A<B` 的上界有合法输入达到；不是没找到足够长的样例。只补答[旧静态复核](<../abc388f四归档静态正确性证明-2026-11-28/README.md>)保留的路径问题，不测时、不改分、不重新判卷。

## 为什么再长也进不去

[固定归档](<../../3-表现现场/r20261125-five-lcb/yuanbao/abc388_f.py#L58-L95>)以提交 `f658ffd` 中的源码为准（SHA-256 前缀 `6da7914ee993`），在 `A=B` 走旋转，`A<B` 才有矩阵后备。对后一种，设 `D=B−A>0`、`k₀=⌈(A−1)/D⌉`、`T=k₀A`。把好段开始前的窗表示为位置 `0,−1,…,−(B−1)`，新好格是 `1,2,…`。任选一个可达旧位 `−i`，**第一跳必须直接落在新好格**，不利用未知的旧格作中转。

- `i<A`：首跳必进好段。走 `k≥1` 步的末点覆盖整个整数区间 `[kA−i, kB−i]`。`kD≥A−1` 时相邻区间无缺格；`A>1` 从 `k=k₀` 开始、`A=1` 从 `k=1` 开始，就覆盖所有 `t≥T+1`。
- `i≥A`：首落点是 `[1,B−i]`，再走 `r≥0` 步得到 `[1+rA,B−i+rB]`。相邻区间无缺格的条件为 `rD≥A+i−B`；右侧至多 `A−1`，从 `r=k₀` 起也覆盖 `t≥T+1`。

以上区间中的整数都可由各步在 `A` 到 `B` 内分配增量取得；路径单向推进，若末点在有限好段内，第一跳以后各中间格也在同一好段。因此处理到 `H=T+B` 时，窗口 `T+1,…,T+B` 的各位全可达；有多个种子只会增多可达点。空窗和满窗已有立即返回；若连续段长度不超过模拟限，源码也不会调用矩阵。长段至迟在第 `H` 步满，而 `LIMIT=T+B+5`，同样直接返回。

## 最晚确能达到，不是把模拟限估小了

按[题面约束](<../../2-用例/lcb-recent-hard-4/inputs/problems.json#L44-L59>)取一个坏段 `[2,B]`、`N=2B+T+6`。处理完坏段时只剩最旧的种子 `i=B−1`，首步只能落在新坐标 `1`。若 `A>1`，`1+(k₀−1)B<T<1+k₀A`，所以 `T` 不可达；若 `A=1`，`T=0` 本来就是空位。第 `H−1` 步的窗口还含 `T`，尚不全满；满后保持，故**第一次**满恰好是 `H`。例如 `A=19,B=20,N=388`、坏段 `[2,20]`，第 362 步才满；源码限是 367。把限**只在合成模型里**改到 361 会触发后备，改为 362 则不会；真实归档没改。相同坏段下，若终点改成 381，终点已可达而末窗仍缺一格；判定终点与判定满窗不是一回事。

非作者用落点集合独立重建，与逐位置布尔递推的 190 对 `A<B`、2,660 个单种子和 190 个合法尖点逐项一致；另有较小掩码穷举及 `A=B` 校准。一个负控是 `N=5,A=2,B=3`、坏段 `[2,3]`：只到格 1 和 4；若证明允许首跳落回旧格 3，就会伪造 `1→3→5`，所以首跳约束不可省。全域结论来自上面的证明，不是靠有限样例穷举全部输入；它不评价解释器开销、隐藏测试、其他版本或其他产品。若要测试独立矩阵函数，只应另标为合成单元测试，而不把长 `N` 当成实际覆盖的证据。项目内非作者复核不是受控第三方，也不改变独立判卷尚未放行的事实。
