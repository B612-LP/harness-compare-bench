# 从字节重放首轮工具组：同值、改值、不可核

对照[第五周验收条款 1](<../../反馈/2026-11-18-第五轮/验收条款-公开版.md>)。11-23 的[公开核验](<../首轮工具组双线校准-2026-11-23/README.md#复核入口与限界>)重算已填写的结论；本页的[参考实现](<replay.py>)直接读 **SSE 字节和请求 JSON 字节**，不接受预填「等值／已绑定」标签。仍是同一批既有原件的事后校准，没有新增运行或改变既有冻结。两种格式是同一裁定的样本适配，不是声称覆盖两个 API 的全部语法。

## 公开复算：不需要原件或账号

在本目录运行（Python 3.9+、仅标准库）：

```sh
python3 -IB verify.py
python3 -IBO verify.py
```

[夹具与检验](<verify.py>)在内存构造真实承载形状的**合成**收据；两种模式均通过 15 个测试方法，含两线和多种表内反例。公开端能复核转换和裁定，不能由这些夹具认证未公开原件；合成数据不计入产品样本数。

| 保持或修改了什么 | 应保留的判断 |
| --- | --- |
| 外层重排键、改空白、等价转义及 LF→CRLF（夹具含实际 U+2028 字符） | 载体原字节改变；拼接参数串和严格值均不变。U+2028 不作 SSE 换行。 |
| H 的参数串改用等价转义、小数写法、键序 | 参数串不同；严格值仍同。 |
| H 同字节长度改一个实参字符 | 严格值不同；不能只比较长度。 |
| W 缺闭合，或 H 时钟／调用 ID／承接组不符 | 整组不可核。只保留已核实的物理包长度或 W 层，不捞更晚续请求补洞。 |
| H 参数文本在、对象有重复键或非法值 | L1 字节仍可知，L2 不可核；不能把对象未知说成「有差异」。 |

## 裁定合同（本页范围）

1. **身份与分段。** `W=001` 的闭合 SSE 工具组；`H` 为预定首主续包（Chat `003`，中间编号 `002` 是更早的无工具辅助包；Responses `002`）。先对照独立来源登记的长度与 SHA-256、包元数据/body 承诺、请求形状及 `W.done ≤ H.start`。只凭包及元数据彼此相符不能认证其是那个固定档，派生另设自己的摘要，不冒用原件。Responses 加验捕获头与请求的 thread/session，以及两包直接请求体的 turn/root。捕获头或请求体内若带 `x-codex-turn-metadata`，其四个身份字段都必须与直接请求体一致。
2. **分别重放。** Chat 仅单 choice、单工具片、同 response 身份，完整 `tool_calls` + `[DONE]` 且封口无实质附加正文。Responses 的初始/进行包不含输出；辅助帧只能在其 reasoning 项生命期内；工具片须逐项落在 `added → delta(s) → arguments.done → item.done`，最后与 `response.completed` 的整组副本相符。H 必须保留固定前缀、已声明工具及完整有序调用—结果关系。它不是对结果文本、实际执行、推理内容的认证。
3. **三种字节不混算。** 载体字节原样算；参数字符串拼接后按 UTF-8 算；严格对象的规范字节按 Unicode 键序、无额外空白的 UTF-8 JSON 算，数组、字符、类型和有符号零保持。整数与小数／指数分型（`1`≠`1.0`），小数／指数用精确十进制系数和指数（`1.50`=`1.5e0`），不经过浮点。拒绝重复键、非法 UTF-8／孤立代理项、非有限数、超过范围的数值字面量或嵌套层级。只比有序的工具名与规范参数对象，不用规范长度代替值，也不把生成 ID 当跨档内容差异。`replay(profile, source, pins)` 接收 `W/A/H → q/w/m` 的捕获字节和已登记摘要，返回数值与原因码；`signature` 仅投影载体，不验证来源或 H。

## 固定四档的离线回放

下表是原件经同一实现算出的**派生数值**，不是公开夹具的输出。范围与[11-23 来源登记](<../首轮工具组双线校准-2026-11-23/README.md#先绑来源再比较内容>)相同：Codex r2 的包正文摘要有旧依据，包元数据由 11-23 校准才固定。参数长度按调用顺序列出；W 与 H 在四档都同原串、同严格值。

| 原档 | 首请求 / 首响应 / 首续请求字节 | 参数串 UTF-8 | 规范参数 UTF-8 |
| --- | ---: | ---: | ---: |
| DSH t3 r1 | 32,937 / 6,811 / 33,319 | 85 | 85 |
| DSH t3 r2 | 32,937 / 5,399 / 33,797 | 66 | 66 |
| Codex t1 r1 | 37,568 / 106,252 / 39,102 | 255 | 236 |
| Codex t1 r2 | 37,568 / 110,715 / 39,423 | 254 / 284 | 235 / 265 |

两条线的各自跨档比较均见 W 与 H 工具组变化（2/2 对，非跨产品）：DSH 两档首请求同字节，Codex 两档首请求只是同长。DSH r1 的 `command` 在同包工具声明中是必填，但 85 B 完整参数对象无此键，故是「响应已确认缺参」，并非「没看到整个响应而不可核」。

**新增四类近错，八个派生对照**：在各自两个原档副本中，Chat 封口换 model 或塞正文；Responses 把 reasoning 片移到该项关闭后（ID、序号仍对）或在 `created` 中提前塞入后来真实出现的输出项。旧解析能重放出和原档相同的 W 工具组（8/8）；按本页合同均报不可核（8/8），仍保留已钉住的物理长度。原件摘要也拒绝所有替身。它们是对照，不是八次实际协议事故。

**非作者复核与修订。** 项目内非作者从 Codex t1 r2 原件独立拼接并核对续包，重得 `254 / 284 B` 原串和 `235 / 265 B` 规范参数。非作者另将 H 捕获头的 `turn_id` 作等长替换；初版在派生摘要下仍误判同值。修订后，原来的四档数值不变，替身判 H 不可核并保留 W、H 物理包长；嵌套 body 冲突和不完整见证也纳入公开回归。

不支持其他事件层、完整请求重建或产品因果。保留[冻结门与外推边界](<../观测规范冻结门清单-2026-11-23/README.md>)；这两线仍未冻结。本页原件回放与[三条历史原始链的核验登记](<../Harness统一观测规范-2026-11-19/README.md>)分开：公开复跑、内部非作者重投影、外部第三方从原件核验是三回事。本次没有新增外部第三方原件核验。
