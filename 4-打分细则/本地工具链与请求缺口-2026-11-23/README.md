# 本地有工具证据，请求层仍未知（11-23）

选一条此前没有可用客户端请求捕获的 DSH 归档，封内复投影 120 个压缩帧、189 条记录和 29 个本地步骤。29 条本地调用记录按各自局部角色和标识复核，均有唯一的两份本地参数；名称、参数 UTF-8 原串和严格 JSON 对象各 29/29 等值。合计 23,749 B 是**本地参数原串**，不是客户端请求正文字节。29 条绑定结果均可见单一文本块。步骤与调用不是一一对应：1 步无调用，27 步各一，1 步两条；结果记录的计数分布相同。

同宽改值让一条局部调用的原串与对象都不同；只改结果记录外层的来源事件序号后，旧解析器拒绝整份链式裁定，独立复投影仍保留 189 条记录和 29 个步边界，但不认证失配结果。新增近错使一份参数原串不是对象，仍保留已见角色绑定与结果：原串可判不同，严格对象等值不可核。变体不改原件，且不会生成客户端记录。

这条归档只支持上述**本地可见性与绑定**，不能补上客户端响应、请求正文、工具实际执行或续请求。客户侧与续请求始终不可核，不把未知记零；原评分、冻结规范与外部核验状态不变。参见 [此前 DSH 归档校准](../DSH观测口径校准-2026-11-19/README.md)。
